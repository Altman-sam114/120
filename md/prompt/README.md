# 历史方案与提示词归档

本目录保存过去的实现提示词和人工方案，供追溯设计意图；不是当前任务的强制入口。

- 当前由一个模型直接按用户目标规划、开发、云端验证并收口，规则见 [AGENTS.md](../../AGENTS.md)。
- 当前计划、步骤状态、验收标准和压缩后的恢复点统一写入根目录 [work.md](../../work.md)，任务完成后清掉活动内容。
- 不再要求角色召唤、身份首行、分工交接、主控循环或每轮新建版本提示词。
- 旧提示词的角色、旧分支、本地检查和固定测试数量仅为历史语境，不能覆盖当前规则和源码。
- 模型必须检查真实实现、风险和依赖，自主调整过时方案；只在需要人工决策时提问。
- 只有用户明确要求方案文档，或复杂任务确需长期设计说明时才新增文件；写目标/非目标、架构依据、边界、验收与相关云端验证，不恢复强制交接模板。
- 版本记录、commit/run/artifact 和调查结论写入 [update_log.md](../../update_log.md)，长期架构与测试分别维护 [flow](../flow/flow.md) 和 [test](../test/test.md)。
- 既有文件保持归档，不批量删除、不改写历史证据，不触碰其他任务尚未提交的草稿。

# v2.86 原生 iOS 紧凑快捷操作与生产指标分层

## 轮次定位

- 版本：`v2.86`
- 基线：`origin/main` 的 v2.85 最终文档 commit `617303408b3a93ee9542e2ecd1b109f6314d67c8`
- 目标：继续向 Rusted Warfare 风格的移动 RTS 操作靠拢，修复紧凑横屏 command dock 中高频选择操作需要滚动才能发现、生产卡成本/人口/时间挤成一行，以及相机在触摸序列中改变后旧屏幕坐标被错误重新解释的问题。
- 云端规则：只认 `origin/main` 最新完整 SHA 对应的 Actions artifact；本机禁止测试、build、typecheck、Simulator、Preview、截图、Node/browser smoke、测试脚本和 `git diff --check`。

## 背景与目标

v2.85 的静态 artifact 复看确认战斗单位的 Quick Orders 已固定在紧凑 dock 顶部，但 `Select Area` 与 `Same Type` 仍只在滚动 Commands 区；固定 production fixture 中三列紧凑生产卡把 `Heavy` 的 `420M · 4P · 14s` 压成一条窄行并出现截断。移动 RTS 的高频选择与生产决策都必须在拇指可达区域快速读懂。

本轮必须：

1. 在普通字号的紧凑横屏/底部路径中，让 `TacticalCommandsSectionView` 的二级命令网格至少使用两列，使 `Select Area` 与 `Same Type` 在 Commands 首行并列可见；辅助功能 Dynamic Type 继续使用一列完整标签。
2. 保持现有 `TacticalQuickCommandRail` 的四个固定首要操作不变；Patrol、Guard、stance、Repair、Reclaim 等二级命令继续保留在滚动区，不能因重排而隐藏或重复。
3. 紧凑三列生产卡将成本/人口与建造时间拆成两行，完整显示数值；不得用隐藏、错误缩放或改变 `productionAvailability` 语义来换空间。普通/regular/accessibility Dynamic Type 仍保持完整标签路径。
4. 为单指触摸序列绑定 seed 时的相机 revision；若外部 Tactical Map、键盘、Reset 或 Focus 改变相机，tap/preview/long press/未开始的 pan 必须 fail closed。当前 Battlefield 手势自身的 pan/pinch 仍可正常改变相机并收尾，不得把自身相机更新误判为外部变化。
5. 保留现有 `queueUnit` action、Shift+1-9、VoiceOver、至少 44pt、生产队列/Cancel/Repeat/Rally、Replace/Add、直接点按 Move/Attack-Move/Attack、两指框选、触控 epoch、Core、存档、战斗模型/效果和 Web 版。

## 验收与证据边界

- 源码复核确认二级网格在普通字号下使用至少两列、accessibility Dynamic Type 使用一列；Quick Orders 的 Move/A-Move/Attack/Stop 不变，Select Area 的等待/取消、Same Type 的 action 和 Patrol/Guard/stance/Repair/Reclaim 均保持。
- 源码复核确认紧凑生产卡仍使用 `productionOptions`、`productionAvailability` 和有效 build time，只改变 presentation 排版，成本、人口、时间及不可用 badge 可读，按钮仍为至少 44pt。
- 源码复核确认 `battlefieldCameraRevision` 只属于 iOS camera/input 生命周期，不进入 Core/save/JSON；外部相机变更会立即清理未 claim 的 preview/owner/lease 并使迟到 callback 失效，而当前 pan/pinch 的自有相机更新不会截断自身手势。
- Agent C 只验收最新 `origin/main` 完整 SHA 对应的未加密 artifact，下载到 `/private/tmp/rustwar-c-review-<run_id>/`；核对 manifest branch/SHA/run/attempt、JUnit、主日志、失败摘要、repo state、固定 Xcode 26.5 / iOS 26.5 / Swift 6.3.2 / iPhone 17 Pro。
- artifact 必须证明 Core 至少 `344 tests`、本轮实际修改的 iOS Swift 文件双架构编译、Xcode list/build、production/combat 双场景启动、横屏归一化和双 PNG probe 全成功；既有 headless-browser skip 如仍存在必须如实记录。
- 人工查看 `ios-home.png`：Heavy/Arty/AA 等紧凑生产卡成本/人口/时间不再横向截断，生产 header、management rail、Factory Tech、队列和 Tactical Map 无回退。查看 `ios-combat.png`：Commands 首行并列显示 Select Area 与 Same Type（若 predicate 可用），Quick Orders 的 Move/A-Move/Attack/Stop、其余 Commands、单位模型、武器、selection/HP、v2.78 marker、terminal/impact、Tactical Map 和状态栏无回退。
- 固定 PNG 不能证明真实点击、两指手势、VoiceOver、Dynamic Type 全档位、所有屏幕宽度、滚动惯性或真机手感。
- 即使 camera lease 通过静态复核，当前 CI 没有跨线程/跨手势 XCUITest；相机改变期间的真实触摸 callback 顺序仍需真机或后续自动化证据。

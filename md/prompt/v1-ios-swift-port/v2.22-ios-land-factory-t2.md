# v2.22 iOS Land Factory T2

## 目标

本轮由 Agent X 主线程直接执行，不调用子 Agent。让玩家点开完成状态己方 Land Factory 后，在 Production 首屏直接看到并操作真实 T2 升级；升级必须带来可测试的防护、视野和未来生产速度收益，并具有可辨 T2 原生模型。

## Core 与模型

- Land Factory T2：900 metal、24 秒、1200 HP、360 vision、1.25x production speed；只保留一个 T2 upgrade。
- `BuildingUpgradeDefinition` 增加 optional/default nil `productionSpeedMultiplier`，既有 Extractor/Radar initializer 与 Codable 语义保持。
- `GameDefinitions.productionSpeedMultiplier(for:)` 只读取已完成 upgrade level；`productionBuildTime(for:at:)` 用 unit base buildTime 除以 multiplier。
- `enqueueUnit` 创建新 `ProductionQueueItem` 时捕获 effective buildTime；升级与当前生产队列并行推进，升级前已入队项目不改写。Repeat 在升级后自然复用新速度。
- 继续复用通用升级入队、进度、完成 HP 补差、取消退款和 `BuildingSnapshot` 存档；不新增第二套 tech 状态，不让 AI 自动升级工厂。
- SpriteKit T2 工厂增加屋顶装甲导轨与科技核心，结构差异不能只靠颜色；不新增纹理、网络素材、动画任务或 Core 渲染状态。

## iOS 操作与视觉

- Factory Tech 位于 Production section header 后、Build Queue 前，显示当前 T1/T2 与真实 production multiplier。
- T1 显示 `Upgrade T2 - 900 Metal` prominent 44pt 控件和 `1.25x production | 1200 HP`；金属不足仍可见但 disabled。
- 升级中显示真实百分比、ProgressView 和 Cancel Factory Upgrade；T2 显示 MAX TECH。
- 生产按钮的秒数和 VoiceOver 必须读取当前选中 producer 的 effective buildTime；费用、人口、Shift 快捷键、Repeat、Rally、Cancel Last 保持。
- production cloud fixture 保持 T1、1050 metal 与 v2.21 四项队列，让 `ios-home.png` 同时覆盖升级入口与完整队列；普通启动和 combat fixture 不变。
- 实际观看公开 “Rusted Warfare Guide Units and Factories” 0:02 帧，只借鉴右侧紧凑生产网格、右上小地图、顶部资源与选中建筑的高密度布局；该帧未显示升级按钮，具体 T2 UI/模型为原创。

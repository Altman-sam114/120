# v2.66 Destruction armor debris presentation

## 版本背景

- 版本：`v2.66`。
- 原生 iOS 已有命中火花、烟尘、焦痕和 `addImpactDebris` 装甲碎片，但真实 `spawnDestructionEffect` 没有复用碎片；固定 combat smoke 也没有摧毁爆炸样本。
- 本轮强化 Rusted Warfare 风格的战斗反馈：摧毁时出现更明确的装甲碎片、火焰、烟尘和焦痕，同时让云端静态 combat fixture 能检查这一层 presentation。

## 目标

1. `spawnDestructionEffect` 复用既有 `addImpactDebris`，保持 5 个确定性碎片、现有动作/生命周期和效果容器。
2. 普通摧毁保留水面/陆地分流、Reduce Motion 透明度退化、fog/visibility 与 64 effect / 32 decal 上限。
3. 为冻结 combat visual smoke 增加一次不修改 Core 状态的静态陆地摧毁样本；冻结路径不运行移动/旋转/淡出动作，并复用既有 persistent bounded effect。
4. 不改变 Core、伤害/死亡、AI、命令、残骸、存档/JSON、生产、HUD 或 Web 版。

## 允许修改范围

- `ios/RustwarIOS/RustwarIOS/BattlefieldScene.swift`
- 如需同步记录：`README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md`、`update_log.md`

## 非目标与不变量

- 不伪造实体死亡，不改变 `GameState`、战斗数值或普通消失实体触发条件。
- 不新增 effect root 上限、decal 上限、Core 字段、存档字段或第三方依赖。
- Reduce Motion 下 `addImpactDebris` 仍不产生飞散碎片；冻结 fixture 不能被当作 Reduce Motion 覆盖。
- `.wp` 必须保持未跟踪，不得进入提交。

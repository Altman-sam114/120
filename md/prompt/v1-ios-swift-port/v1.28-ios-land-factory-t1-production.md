# v1.28 / iOS native Land Factory T1 production expansion

## Agent B 任务

在 v1.2 原生陆军工厂生产队列、v1.25 Repeat 和 v1.27 Builder 建造 Land Factory 的基础上，把 iOS 原生 Land Factory 的 T1 生产列表从 Scout / Light Tank 扩展到 Web T1 对齐的 Scout / Light Tank / Hover Tank / Artillery / AA Tank。保持现有生产队列、取消生产、Repeat、Rally 和云端 CI 验收流程。

## 背景依据

- Web `buildingTypes.landFactory.produces` 的 T1 列表是 `scout`、`tank`、`hover`、`artillery`、`aaTank`。
- Swift `UnitType` 和 `GameDefinitions.units` 已经存在 `.hover`、`.artillery`、`.aaTank` 定义。
- iOS HUD 的生产按钮来源是 `GameController.productionOptions`，它读取 `GameDefinitions.building(building.type).produces`；Repeat 循环也读取同一列表。
- 当前 `GameHUDView` 用单行 `HStack` 渲染生产按钮。扩展到 5 个按钮后，应改为可换行/自适应布局，避免窄屏文字挤压或溢出。

## 目标

1. Swift core：
   - 将 `GameDefinitions.building(.landFactory).produces` 扩展为 `[.scout, .tank, .hover, .artillery, .aaTank]`。
   - 不改变这些单位已有数值，不新增 T2 单位或升级系统。
   - 保持 `.gunboat` 仍不受 Land Factory 支持。
2. iOS App：
   - 选中完成状态己方 Land Factory 时，HUD 应显示五个生产按钮。
   - 生产按钮区域改为自适应换行布局，每个按钮保留文字 label、系统图标和至少 44pt 触控高度。
   - Repeat 按钮继续按生产列表顺序循环：Off -> Scout -> Light Tank -> Hover Tank -> Artillery -> AA Tank -> Off。
   - 不新增独立生产面板、分页、筛选或 T2 升级 UI。
3. Tests：
   - 验证 Land Factory `produces` 列表与 Web T1 顺序一致。
   - 验证 `.hover`、`.artillery`、`.aaTank` 可通过 `queueUnit` 入队、扣金属，并按各自 `buildTime` 完成生成。
   - 验证 `.gunboat` 仍返回 `.unsupportedUnit`。
   - 验证 Repeat 可设置到新单位，例如 `.aaTank`，并在队列清空后自动续造该单位。
   - 现有取消生产、资源不足、人口不足和恢复模拟测试不得回退。
4. 文档：
   - 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。
   - 在 `update_log.md` 同步记录 v1.27 云端 artifact 验收结果：run `28735567681`、attempt `1`、artifact `rustwar-ci-v1.0-main-80ab550-run28735567681-attempt1`、commit `80ab5508bb40246c4fb51a3c184a77c572fcf68e`，以及 Swift tests 103 项通过。

## 非目标

- 不新增 Heavy Tank、Heavy Hover、Missile Tank、Laser Tank、Repair Tank、Shield Tank。
- 不新增 Mech / Air / Sea / Experimental Factory 建造或生产。
- 不新增空军、海军、运输、护盾、维修光环或防空专用目标规则。

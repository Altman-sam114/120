# v2.34 iOS seamless terrain fill

## 目标

移除 v2.33 云端 Home/Combat PNG 中仍贯穿基础地形的逐 tile 暗色 hairline，让水域和同材质陆地成为连续表面，同时保持不同地形边界、海岸、深度线和战斗视觉层级。

## 实现

- 保留既有按 `TerrainKind` / 色阶聚合的 compound fill path 和 tile 轻微重叠。
- 基础材质节点使用与 fill 完全相同的 1pt stroke 覆盖像素栅格接缝，替代可能退化为设备 hairline 的零宽 stroke。
- 保持 antialias 关闭、节点数量、地图 revision 重建路径和 terrain/fog/entity/effect 层级。

## 非目标

- 不移除不同 `TerrainKind` 的可辨识色阶、海岸泡沫、water/deep 深度线或熔岩焦岸。
- 不修改 fog 真实可见性、Core 地形/通行、战斗、AI、命令、存档、Web 或 Tactical Map。
- 不新增 texture、shader、动画、timer、Task、随机数、第三方依赖或逐 tile SpriteKit node。

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 只提交本轮 SpriteKit 源码、提示词和同步文档，直接 push `origin/main`。

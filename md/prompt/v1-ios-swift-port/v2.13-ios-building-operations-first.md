# v2.13 iOS Building Operations First

## 角色与目标

本轮由主线程按 Agent A -> Agent B -> Agent C 边界直接执行，不调用子 Agent。

目标是让玩家点选 Command Center、Land Factory、Extractor 或 Radar Station 后，无需在紧凑横屏 command dock 中向下寻找，立即看到当前建筑的生产或升级操作。行为应接近触屏 RTS 的“选中对象后第一屏就是对象动作”，同时保持通用选择、命令、编队和会话入口完整。

## 已有事实

- `TacticalCommandDockView` 当前固定按 Commands -> Build & Upgrade -> Production -> Selection -> Groups -> Session 排列。
- `ScrollView` 会保留旧 offset，切换选择后仅重排 section 仍不能保证玩家看到顶部操作。
- Command Center / Land Factory 的 `productionOptions`、queue、repeat、cancel 和 rally 已完整存在。
- Extractor / Radar 的升级和取消升级 action 已存在，但 `canUpgradeSelected...` 同时承担 visibility 与 affordability；金属不足时升级入口完全消失。
- v2.12 commit `4a1c8c775a3eb4072aa4015f3d3a20cdb2950b3f` 已通过 run `29224227790`、attempt `1`、artifact `rustwar-ci-v1.2-main-4a1c8c7-run29224227790-attempt1` 验收。
- 用户的 `project.pbxproj` 修改与 `.wp` 必须保持未暂存。

## 实现范围

### `GameController.swift`

1. 暴露稳定的 dock selection identity，优先使用 `selectedEntityIDs`，兼容旧单选 `selectedEntityID` fallback。
2. 为 Radar / Extractor 分离“应显示升级入口”和“当前资源允许升级”：完成、未在升级、仍有 next upgrade 时显示；`canUpgrade...` 继续负责 affordability。
3. 不增加 Core 状态或第二套选择/升级真源。

### `TacticalCommandDockView.swift`

1. 生产建筑有 production controls 时，Production section 排第一。
2. 当前建筑有 Radar/Extractor upgrade 或 cancel control 时，Build & Upgrade section 排在 Commands 前。
3. Builder 的普通建造 section 仍在 Commands 后，避免把建造行为误当成所选建筑操作。
4. 使用 `ScrollViewReader` 在 dock selection identity 改变后无动画回到内容顶部，确保从任意旧 offset 点建筑都能看到首要操作。
5. Selection / Groups / Session 保持原顺序，所有 section 最多渲染一次。

### `TacticalBuildSectionView.swift`

1. Radar / Extractor 有 next upgrade 时始终渲染升级按钮。
2. 金属不足时按钮 disabled，而不是消失；标题继续显示升级费用。
3. 正在升级时仍显示既有 Cancel Upgrade；满级时不显示无效按钮。
4. action、样式、accessibility label/hint 不变。

## 非目标

- 不修改生产、升级、退款、经济、战斗、AI、存档或 Core。
- 不新增建筑类型、单位、队列拖拽、批量队列或升级树。
- 不创建卡片套卡片、modal、tab、UIKit 或第三方依赖。
- 不改 HUD 尺寸断点、Tactical Map、战场手势或 v2.12 多指框选。
- 不声称默认 `No selection` 云端截图能展示建筑选中态。

## 验收矩阵

- Command Center / Land Factory：Production 第一，选择变化后 offset 回顶。
- Extractor / Radar 可升级且金属足：Build & Upgrade 第一，按钮 enabled。
- Extractor / Radar 可升级但金属不足：Build & Upgrade 第一，费用按钮 visible + disabled。
- Extractor / Radar upgrading：Cancel Upgrade 第一屏可见。
- 满级建筑：不显示无效 upgrade；通用 sections 保持。
- Builder：Commands 在 Build & Upgrade 前，旧建造按钮和快捷键保持。
- 单位/无选择：没有建筑特定 section 前置，现有 Commands/Selection 顺序保持。

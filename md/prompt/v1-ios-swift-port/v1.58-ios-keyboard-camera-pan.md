# v1.58 / iOS native keyboard camera pan

## 目标

把 Web 版 `WASD / 方向键` 移动视野迁移到原生 iOS 外接键盘路径。v1.58 只新增原生相机平移输入，不改变 `RustwarCore` 游戏状态、选择、命令或渲染模型。

## 行为范围

- 外接键盘 `W` / Up Arrow：相机向上移动。
- 外接键盘 `S` / Down Arrow：相机向下移动。
- 外接键盘 `A` / Left Arrow：相机向左移动。
- 外接键盘 `D` / Right Arrow：相机向右移动。
- 按住按键时持续移动，松开后停止；斜向组合会归一化，避免移动更快。
- 移动速度按 Web 基线使用 680 屏幕点每秒，并按当前 zoom 换算为世界坐标位移。
- 暂停时仍允许移动相机；运行时相机键盘平移与当前 simulation speed 一起缩放，对齐 Web 侧 `updateCamera(dt * speed)` 行为。

## 非目标

- 不修改 Web `app.js`。
- 不修改 `RustwarCore` 命令模型、单位订单、生产、AI 或存档 schema。
- 不改变触屏拖拽、捏合缩放、战术小地图点按居中或 Base / Reset 行为。
- 不新增 UIKit bridge、第三方依赖、后台服务或构建链。
- 不新增屏幕范围作战单位选择、攻击姿态、生产/建造热键或完整 Web 热键 parity。

## 实现边界

- `ios/RustwarIOS/RustwarIOS/RootGameView.swift`：使用 SwiftUI `focusable` / `FocusState` / `onKeyPress` 在全屏 root 级接收键盘 down/repeat/up，维护按键按下状态。
- `ios/RustwarIOS/RustwarIOS/GameController.swift`：保存当前键盘相机方向集合，并在 `advance(deltaTime:)` 每帧按当前方向推进相机。
- `ios/RustwarIOS/RustwarIOS/CameraState.swift`：新增世界坐标 delta 平移 helper，集中保留 map clamp。
- `ios/RustwarIOS/RustwarIOS/KeyboardCameraDirection.swift`：新增方向枚举。
- `ios/RustwarIOS/RustwarIOS.xcodeproj/project.pbxproj`：把新增 Swift 文件加入 iOS target Sources。

## 兼容要求

- `A` 和 `S` 仍需保留现有 Attack Move / Stop 快捷键副作用；相机按键处理不能吞掉这些 HUD button shortcuts。
- 键盘相机平移不改变选择、不取消等待态、不下达 Stop、不选择基地、不改变 zoom。
- 触屏拖拽平移仍复用 `GameController.pan(by:)`，Select Area 拖拽仍优先显示框选。

# v1.37 / iOS native enemy AI toggle

## 角色

本提示词交给 Agent B 执行。Agent B 必须遵守 `AGENTS.md` 的 main 直推、轻量本地检查、GitHub Actions artifact 和 Agent C 复判流程。

## 背景

原生 iOS 版已经在 `GameEngine` 中保存 `enemyAIEnabled`，`GameController.saveGame()` / `loadGame()` 也会保存和恢复该 flag，但玩家目前无法在 HUD 中切换红方 AI。Web 版顶部有 `AI` 控制入口，本轮先补原生版最小 On / Off 开关，让玩家能暂停红方自动行为，便于调试、观察和向 Web 控制能力靠近。

## 目标

- 在 `RustwarCore` 增加公开、可测试的红方 AI 开关 API，例如 `setEnemyAIEnabled(_:)` 或等价方法。
- iOS HUD 增加一个有文字和系统图标的 Enemy AI 开关按钮，显示当前 On / Off 状态。
- 点按开关后只改变 `GameEngine.enemyAIEnabled`，不重置地图、相机、选择、队列、待选命令、暂停状态或速度。
- `Save / Load` 继续保存并恢复当前 AI 开关状态。
- 同步 README、flow、flowchart、test 和 update_log。

## 非目标

- 不修改 Web `index.html` / `styles.css` / `app.js`。
- 不实现 Web 六档 AI 难度，不改变红方收入、建造、训练或进攻倍率。
- 不新增新 AI 行为、进攻波、目标评分、生产权重或单位类型。
- 不新增设置页、弹窗、持久化 schema 迁移或多存档。
- 不改变 `GameState` Codable 结构；AI 开关仍由 iOS save payload / `GameEngine` 持有。
- 不用 `WKWebView` 或网页包装。

## 建议实现

- 修改 `swift/RustwarCore/Sources/RustwarCore/GameEngine.swift`：
  - 保留 `public private(set) var enemyAIEnabled`。
  - 新增公开 mutating setter，例如：

```swift
public mutating func setEnemyAIEnabled(_ isEnabled: Bool) {
    enemyAIEnabled = isEnabled
}
```

- 修改 `ios/RustwarIOS/RustwarIOS/GameController.swift`：
  - 增加 `enemyAIButtonTitle`、`enemyAIButtonSystemImage`、必要的 accessibility value 派生属性。
  - 增加 `toggleEnemyAI()`，内部调用 core setter，更新 `commandStatus` 和 `renderRevision`。
  - `restartBattle` / 切图重建 `GameEngine(mapID:)` 的行为可以保持默认 AI 开启；`loadGame()` 必须继续恢复 payload 中的 `enemyAIEnabled`。

- 修改 `ios/RustwarIOS/RustwarIOS/GameHUDView.swift`：
  - 在顶部控制区或 Save/Load 附近增加 `Button(controller.enemyAIButtonTitle, systemImage: controller.enemyAIButtonSystemImage, action: controller.toggleEnemyAI)`。
  - 保持 44pt 以上点击高度。
  - 使用文字按钮，不做 icon-only；为 VoiceOver 提供明确 label / value。

## 测试要求

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加 Swift tests，至少覆盖：

- 默认 `GameEngine` AI 开启，调用 setter 后 flag 可切换为 false，再切回 true。
- AI 关闭时推进 update 不会给空闲红方战斗单位下新攻击订单。
- AI 重新开启后，同一状态继续推进会恢复红方攻击下单。
- setter 不重置 `GameState` 的当前选择、实体数量或 elapsed 等非 AI flag 状态。

如有合适位置，也可更新现有 `restoredEnginePreservesEnemyAIFlagWhenRequested` 测试，但不要只依赖 init 覆盖。

# v1.99 / iOS HUD ownership refactor

## 目标

使用现代 SwiftUI 组件边界重构 695 行 `GameHUDView`，降低后续 Rusted Warfare 风格视觉、操作和命令扩展的修改耦合，同时保持现有 UI 行为。

## 实现要求

- `GameHUDView` 只保留 status bar / command dock presentation 分派。
- 独立状态栏、dock shell、dock header 和 Commands / Build & Upgrade / Production / Selection / Groups / Session 六个 section，每个 top-level View 单独 Swift 文件并显式加入 Xcode target。
- dock shell 继续集中 Dynamic Type/compact role 的 1/2 列规则，以及 Commands/Build/Production visibility gate。
- 每个 section 只拥有本域按钮、显示条件、快捷键和 accessibility modifiers；不新增第二套状态或 action wrapper。
- 保持所有 controller action、disabled 条件、键盘快捷键、VoiceOver label/value/hint、44pt 触控目标、eager layout、三档布局和 Tactical Map 边界。
- 生产选项使用 iOS 26 可直接遍历的 `enumerated()`，以稳定 `UnitType` element 作为 identity。
- 把过小的 HUD `caption2` 标签提升为 Dynamic Type `caption.bold()`；除此之外不重做视觉主题。

## 非目标

- 不修改 `GameController`、Core、战斗、AI、存档、SpriteKit、Web 或素材。
- 不新增第三方依赖、Navigation、UIKit、timer 或异步状态。
- 不运行任何本地测试、build、parse、Simulator、Preview 或浏览器验证。

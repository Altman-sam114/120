# v2.3 / iOS tactical control contrast

## 版本

- 版本号：`v2.3`
- 分配依据：Agent A 自动递增；接续 v2.2 遗留的按钮/控件对比收紧。

## 背景

v2.2 已提高 metric/section/panel 对比并减少 letterbox。云端首屏中 command dock 按钮仍偏系统 `.bordered` 灰底，在深战术面板上不够醒目。

## 目标

1. 用 theme 驱动的战术 control style 替代 dock 主路径上的系统灰 bordered 控件外观。
2. 保持 44pt 最小触控、既有 action / disabled / 快捷键 / VoiceOver / 三档布局。
3. 顺带把 v2.2 Agent C 通过证据写入 `update_log.md`。
4. push `origin/main`，用 v1.2 CI visual smoke 验收。

## 非目标

- 不改命令语义、Core、AI、存档、Web、layout metrics 数值。
- 不引入第三方、UIKit 自定义 hit testing、新 section。
- 不跑本机 Xcode / Simulator。

## 实现步骤

1. `TacticalHUDTheme` 增加 control 背景/描边/前景 token。
2. 在 `TacticalHUDComponents` 增加 `TacticalBorderedButtonStyle` / `TacticalProminentButtonStyle`（或等价），并让 `tacticalControl()` / `tacticalProminentControl()` 使用它们。
3. `TacticalCommandsSectionView` attack stance 按钮、`TacticalGroupsSectionView` icon 按钮改用同一风格。
4. 可选：status bar Pause 使用 accent tint，不改行为。
5. 更新 README / flow / flowchart / test / update_log；补记 v2.2 验收。

## 验收

- CI v1.2 success；人工看 `ios-home.png` 中 dock 按钮应明显深于系统灰，文字/图标更清晰。
- action 与 layout 行为不变。

# v1.30 / iOS native enemy Turret build AI

## 角色

本提示词交给 Agent B 执行。Agent B 必须遵守 `AGENTS.md` 的 main 直推、轻量本地检查、GitHub Actions artifact 和 Agent C 复判流程。

## 背景

v1.26 已让玩家 Builder 可以建造未完成 Turret；v1.19 / v1.24 已让完成状态 Turret 自动攻击敌方单位和建筑；v1.29 已让红方 Builder 建造 Land Factory。当前原生红方 AI 仍不会主动补防御建筑。Web 版红方 AI 会在基地周边建造防御塔，原生迁移应补一个小范围、可测试的红方炮塔建造 MVP。

## 目标

- 在 `RustwarCore` 的红方 AI 中新增 Turret 建造 MVP。
- 当红方有空闲 Builder、金属足够、Turret 数量低于小上限、基础经济已经成型、且能找到合法陆地点时，AI 应创建未完成的 enemy Turret，并给该 Builder 写入 `.build(targetID:)`。
- 新建 enemy Turret 必须复用现有点位建筑创建语义：扣除金属、`buildProgress = 0`、初始 HP 为 10%、`nodeID = nil`、`rally = position`。
- 未完成 enemy Turret 不应开火；完成后复用现有 Turret 自动防御逻辑，可攻击玩家单位或建筑。
- 不得改变玩家当前选择。
- 同步 README、flow、flowchart、test 和 update_log，并补写 v1.29 的真实云端验收记录。

## 非目标

- 不新增玩家 UI、SwiftUI HUD 按钮或战术小地图交互。
- 不修改 Web `index.html` / `styles.css` / `app.js`。
- 不新增 Fabricator、Command Center 生产 Builder、红方 AA Turret、炮塔升级、建造幽灵、多 Builder 协同或完整 Web AI parity。
- 不引入新框架、后端、网络依赖或 WKWebView。

## 建议实现

- 修改 `swift/RustwarCore/Sources/RustwarCore/GameEngine.swift`。
- 在 `updateEnemyAI()` 中保留现有红方建厂、扩张、生产和进攻顺序，并在 Land Factory 建造尝试之后、生产/进攻之前尝试 Turret 建造。
- 新增私有 helper，例如：
  - 统计 enemy 存活 Turret 数量，包含未完成建筑，避免重复堆叠。
  - 检查 enemy 金属是否至少达到 `GameDefinitions.building(.turret).metalCost`。
  - 要求 enemy Extractor 数量达到基础门槛，避免开局抢在资源扩张前堆塔。
  - 查找空闲 enemy Builder。
  - 在 enemy command / enemy base / enemy front turret / enemy builder 周边用确定性候选点搜索 `canPlaceBuilding(.turret, at:)`。
  - 成功后调用现有 `startPointBuildingBuild(.turret, builderIndex:position:)`。
- 建议设置小上限为 2 座 enemy Turret，保持 MVP 小范围。
- 候选点搜索必须确定性，不要用随机数；如果没有合法点，AI 不应扣资源、不应改 Builder order。

## 测试要求

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加 Swift tests，至少覆盖：

- enemy AI 在金属足够、Builder 空闲、Turret 数量低于上限、有合法点时建造未完成 Turret，并不改变玩家选择。
- 新建 enemy Turret 进入 `.build` 订单，扣除 enemy 金属，初始进度和 HP 正确，`nodeID == nil`，`rally == position`。
- 新建 enemy Turret 在三张原生地图上都能找到合法候选点。
- 未完成 enemy Turret 不开火；完成后可复用现有炮塔自动防御攻击玩家目标。
- AI 在金属不足、Builder 忙、Turret 数量达到上限或无合法点时不建塔。

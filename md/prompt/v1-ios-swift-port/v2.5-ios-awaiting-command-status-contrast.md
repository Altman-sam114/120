# v2.5 / iOS awaiting command status contrast

## 版本

- 版本号：`v2.5`
- 分配依据：Agent A 自动递增；接续 v2.4 后收紧等待命令/状态文字层级。

## 目标

1. 让 `TacticalCommandStatusView` 在 waiting / idle 两态对比更清晰：waiting 用更强 attention 底与粗描边、caption 标签；idle 保持次级信息。
2. dock header 在 waiting 时边框/分隔可提示目标选择模式。
3. 不改 commandStatus 文案来源、binding、命令语义。
4. 云端 v1.2 visual smoke 验收。

## 非目标

- 不改 Core、AI、存档、Web、layout metrics、按钮 action。
- 不跑本机 Xcode/Simulator。

## 实现

1. Theme：强化 `awaitingStatusBackground`，可加 `awaitingStatusStrokeWidth` 或复用 attention。
2. `TacticalCommandStatusView`：waiting 增加 “TARGET”/状态标签层级、更强 icon 与 stroke；idle 保持次级。
3. 可选：`TacticalCommandDockHeaderView` 在 `isAwaitingTargetCommand` 时底部/外描边用 attention。
4. 文档同步。

## 验收

- CI success；人工看代码/截图逻辑：waiting 态应明显于 idle。
- 无行为回归。

## 目标与方案

现有 dock 把六类内容串在长滚动区内，编队与 Session 只能越过全部生产/命令卡寻找；固定 header 和 Quick Orders 在大字号/短高度下还可能耗尽滚动空间。为 Orders（选中建筑时显示 Factory）、Select、Groups、Game 提供固定、至少 44pt 的直达导航。导航通过 ScrollViewReader 定位实际 section，保留完整 eager view tree，避免切换页面卸载既有 keyboardShortcut。新选择自动回到 Orders 顶部；等待命令开始也回顶部显示目标说明。导航只改变滚动，不修改选择、命令或存档。

将选择 header 与 Quick Orders 纳入同一个可滚动内容区域，使辅助功能字号和 compact bottom 的所有动作都能滚动访问。导航保留在滚动区外，普通字号四等分图标/文字，辅助功能字号改为可横向滚动的完整 Label，禁止缩字。保留 VoiceOver 标签、hint、生产 availability、升级、队列、双指选择与全部 Core 语义。

文件：TacticalCommandDockView.swift（滚动所有权/导航锚点）、新增 TacticalDockNavigationView.swift（导航组件）、Xcode project（注册源码），README、flow、flowchart、test、update_log。不修改 Core、Web、数值、存档、模型与战斗，后续轮次继续覆盖这些目标。

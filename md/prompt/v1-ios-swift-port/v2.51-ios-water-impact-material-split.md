## 实现范围

修改 `ios/RustwarIOS/RustwarIOS/BattlefieldScene.swift`：

1. 在 `spawnImpactEffect` 与 `spawnDestructionEffect` 入口读取现有 `controller?.engine.state.terrain.terrain(at:)`，只作为 presentation 分支条件。
2. `.water` / `.deep` 使用一个 bounded `SKNode`：蓝白水面椭圆/波纹、最多三条确定性 splash arc、最多两个水滴；禁止调用 `addScorchMark`、`addSmokePuffs`、`addImpactDebris` 或地面火焰路径。
3. 普通地面和熔岩保持当前 `spawnImpactEffect` / `spawnDestructionEffect` 表现，不改变现有颜色语义或上限。
4. 水面动态效果生命周期最多 `0.55` 秒；冻结 visual smoke 使用 `addPersistentBoundedEffect`；Reduce Motion 只淡出，不扩张或飞散。
5. 保持现有 `effectNode` root 上限 `64`、`decalNode` 上限 `32`，水面命中不创建 decal；保持 entity -> effect -> fog 的现有层级和真实可见性门控。

- `ios-combat.png` 中水面命中/摧毁不出现橙色地面焦痕、火焰、烟尘或碎片；蓝白水花在水面可辨。

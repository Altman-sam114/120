# v2.25 iOS production dock density and Factory Tech hierarchy

## 目标

- 参考 Rusted Warfare 公开截图与生产教学视频中“窄侧栏、图标优先、短标签、战场优先”的信息组织，精修原生 iOS Production 首屏。
- 修复窄 dock 中 `Factory T2` 被系统断为 `Facto- / ry T2` 的明显视觉缺陷，并强化 Factory Tech、当前生产、后续队列和可生产单位之间的层级。
- 保持 iOS 原生 Dynamic Type、VoiceOver、至少 44pt 触控目标和 Rustwar 自有战术视觉，不复制第三方素材、商标或过小触控尺寸。

## 非目标

- 不修改 Core、生产/升级数值、队列、退款、Repeat、Rally、AI、存档、战斗、触控手势、Web 原型或 Xcode project。
- 不引入图片资产、第三方依赖、SwiftUI Preview、XCUITest 或新的本地测试路径。
- 不运行任何本地测试、build、Simulator、Preview、截图或测试脚本。

## 实现要求

- 仅在既有 `TacticalProductionSectionView` 边界内重组视觉层级，继续读取现有 `GameController` presentation properties 和 `ProductionQueueItem`。
- Factory Tech 必须使用稳定图标锚点、独立且不可拆分的 `T1/T2` 大号等级、生产倍率和短状态 badge；窄宽度与辅助功能字号允许有意切换垂直布局，但禁止英文单词自动连字符断行。
- 可升级状态继续显示价格、下一等级、生产倍率和 HP benefit；资源不足保持 disabled，升级中保留百分比、真实 `ProgressView` 与 Cancel，满级显示 `MAX TECH`。
- Build Queue 的当前项必须拥有最高层级，明确显示图标、名称、百分比、剩余秒数和进度条；后续队列保持顺序、名称与 build time，至少 44pt 高并支持 Dynamic Type / VoiceOver。
- 生产按钮继续显示单位图标、名称、metal、supply、build time，保留 Shift+1-9、queue action、完整 VoiceOver label/hint 与两列/单列断点。
- `Cancel Last`、Repeat、Rally、v2.13 section priority、v2.14 production smoke、v2.21 queue fixture、v2.22 Factory T2 和 v2.23 Heavy Tank 语义保持不变。

# v2.2 / iOS tactical UI contrast and letterbox

## 版本

- 版本号：`v2.2`
- 分配依据：Agent A 自动递增；接续 v2.1 云端 visual smoke 遗留的战术界面精修目标。

## 背景

v2.1 已在固定 iPhone 17 Pro / iOS 26.5 Simulator 上得到可复判的横屏首屏证据。人工查看云端 `ios-home.png` 仍显示：

1. HUD 偏系统灰，metric / section / secondary 文案对比弱。
2. 战场左右有明显黑色留边（safe area / 黑底未铺满，或相机可见区贴边时露出 scene 黑底）。

本轮只做窄范围视觉精修，不扩玩法。

## 目标

1. 提高战术 HUD 可读对比：用集中 theme token 替代系统灰 secondary / 过淡 material。
2. 减少主战场左右黑色留边：水平铺满可用区域，并让相机按 viewport 夹紧/适配，避免两侧大块黑底。
3. 保持全部现有 action、disabled 条件、快捷键、VoiceOver、44pt 触控、三档 layout metrics、命令语义、Core、AI、存档与 Web。
4. 同步文档，push `origin/main`，由 v1.2 CI visual smoke 验收。

## 非目标

- 不新增玩法、单位、建筑、AI、Web 改动。
- 不引入第三方资源、渐变装饰堆叠、UIKit 重写、WKWebView。
- 不跑本机 Xcode / Simulator / Preview / 浏览器测试；验证只走 GitHub Actions。
- 不做 XCUITest 像素基线或完整 UI 自动化矩阵。

## 当前架构依据

- `TacticalHUDTheme` 已有 spacing/radius/accent，但 metric/section 仍用 `.secondary` 与浅黑透明底。
- `TacticalStatusBarView` / dock header 使用 `.ultraThinMaterial`，dock shell 使用 `.regularMaterial`。
- `RootGameView` 背景为 `.black`，未水平 `ignoresSafeArea`，横屏左右 safe area 易露黑边。
- `BattlefieldScene.backgroundColor = .black`；`CameraState.clampToMap` 只夹 center 到地图边界，不考虑 viewport 半宽，低缩放时可见区可越出地图露出黑底。

## 实现步骤

### 1. Theme tokens

在 `TacticalHUDTheme` 增加并消费：

- `primaryText`、`secondaryText`、`metricLabel`（高对比，非系统灰）。
- `panelBackground`、`chromeBackground`、`dockBackground`（深战术面板色，可叠加极薄 material）。
- `metricBackground` / `selectionBackground` / `neutralStatusBackground` 提高不透明度。
- 保持 cyan accent、yellow attention、6pt radius、44pt hit target。

### 2. HUD 对比应用

- `TacticalMetricView`、`TacticalSectionHeader`、`TacticalCommandStatusView`、`TacticalSelectionSummaryView`、生产队列摘要：secondary/primary 改 theme token。
- status bar、dock header、dock shell：改用 theme panel/chrome 背景；若保留 material，必须叠加更深底色，避免系统灰洗白。
- 不改 button action / keyboard shortcut / layout metrics。

### 3. Letterbox / 黑边

- `RootGameView`：内容在 leading/trailing（必要时 bottom）铺满，避免左右 safe area 黑条；status bar 仍保留顶部可读 padding。
- `CameraState`：按 viewport + zoom 夹紧 center，使地图大于可见区时尽量不露出地图外黑底；在 viewport 更新或 reset 时，若当前 zoom 会让可见宽/高明显大于地图，则提高到可填充的最小 zoom（仍受现有 zoom 上下限约束）。
- `GameController.updateBattlefieldViewportSize` / `resetCamera`：接入上述适配。
- 不改 map 尺寸、tile 逻辑或玩法坐标。

### 4. 文档

更新 `README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md`、`update_log.md`。

- 禁止扩大到特效/玩法 parity 大改。

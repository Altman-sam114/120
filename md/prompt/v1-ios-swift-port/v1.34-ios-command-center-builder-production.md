# v1.34 / iOS native Command Center Builder production

## 角色

本提示词交给 Agent B 执行。Agent B 必须遵守 `AGENTS.md` 的 main 直推、轻量本地检查、GitHub Actions artifact 和 Agent C 复判流程。

## 背景

原生 iOS 迁移版已经具备通用生产队列、生产取消、Repeat、Rally 和自适应生产按钮。当前只有 Land Factory 暴露生产列表；Command Center 仍不能补造 Builder。Web 原型已有工程单位建造/维修/回收主链路，原生版也已经依赖 Builder 建造 Extractor / Turret / Land Factory。让 Command Center 生产 Builder 是恢复建造链路和接近 Web/Rusted Warfare 基础经济循环的低风险小步。

## 目标

- 让完成状态的己方 Command Center 可通过现有原生生产体系排队生产 Builder。
- iOS HUD 在选中完成状态己方 Command Center 时自然显示 Builder 生产按钮，并继续复用现有 Queue / Cancel Production / Repeat / Rally 行为。
- 生产完成后 Builder 在 Command Center rally 点生成，并计入人口、金属和后续命令体系。
- 敌方 Command Center 若有资源和人口，也可通过既有红方生产 AI 排队 Builder；不新增专用 AI 策略，只复用通用 `produces` 和 `enqueueUnit`。
- 同步 README、flow、flowchart、test 和 update_log。

## 非目标

- 不新增 Web `index.html` / `styles.css` / `app.js` 改动。
- 不新增新的 SwiftUI 面板、SpriteKit 视觉系统、战术小地图交互或 WKWebView。
- 不新增多选生产面板、Command Center 升级、其它建筑生产、Builder 自动建造策略、敌方 Builder 数量上限、难度倍率或完整 Web 生产 parity。
- 不改变公开 `queueUnit(_:)`、`cancelLastProduction()`、`setRepeatProduction(_:)`、`setRally(to:)` 的语义，只通过建筑定义接入既有规则。

## 建议实现

- 修改 `swift/RustwarCore/Sources/RustwarCore/GameDefinitions.swift`：
  - 给 `.command` 的 `BuildingDefinition` 增加 `produces: [.builder]`。
  - 保持 Builder 现有 `metalCost`、`buildTime`、`supply`、命令和战斗参数不变。
- 预计 iOS HUD 无需新增按钮代码：
  - `GameController.productionOptions` 已从 `selectedPlayerProducer` 的 `produces` 读取。
  - `selectedPlayerProducer` 已要求建筑属于玩家、完成且 `produces` 非空。
  - `GameHUDView` 已按 `productionOptions` 渲染生产按钮。
- 若发现 Land Factory 专属文案或 accessibility 文案误导 Command Center，可做最小改文案，但不要做大 UI 重构。

## 测试要求

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加或更新 Swift tests，至少覆盖：

- `GameDefinitions.building(.command).produces == [.builder]`，并保持 Land Factory T1 顺序不退化。
- 选中己方 Command Center 后 `queueUnit(.builder)` 成功、扣除 Builder 金属成本并追加生产队列。
- Command Center 拒绝生产非 Builder 单位，例如 Scout。
- 生产完成后生成新的己方 Builder，位置等于 Command Center rally，并计入人口。
- Command Center 的 Repeat Builder 可在队列清空后尝试续造；资源或人口不足时沿用现有 repeat 规则。
- 敌方 Command Center 在缺少 Land Factory 或工厂忙碌时可由通用红方生产 AI 排队 Builder，且不污染玩家选择。

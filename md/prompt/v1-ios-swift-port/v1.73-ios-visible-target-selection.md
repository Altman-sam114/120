# v1.73 / iOS visible target selection

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.73。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

在 v1.70-v1.72 当前视野渲染地基上，让原生 iOS 主战场和战术小地图的实体命中不再绕过雾层直接点到当前玩家视野外敌方单位或建筑。

- 普通主战场 tap 选择：己方单位/建筑仍可被命中；敌方单位/建筑只有当前位置对玩家可见时才可被命中和选中。
- 主战场长按上下文命令：不可见敌方单位/建筑不应触发 Attack；应按现有顺序继续尝试残骸、资源点、Rally 或 Move。
- Attack / Guard / Repair 等待实体目标命令：命中 helper 必须过滤当前不可见敌方单位/建筑；友方目标不受影响。
- 战术小地图实体目标命令复用同一过滤规则，避免小地图视觉隐藏后仍能精确点到雾外敌方。
- 保持点位命令 Move / Attack Move / Patrol / Rally / Turret / Factory 不变；保持 Reclaim 残骸和 Build Extractor 资源点命中不变。

## 非目标

- 不修改 Web `app.js`。
- 不改变 `GameState.visibility(for:)` 的可见性算法和存档形状。
- 不实现已探索记忆、雷达信号、雷达点、AI 情报限制、自动索敌情报限制、资源点/残骸隐藏、HUD 敌军数量隐藏或弹道/粒子隐藏。
- 不改变 core `issueAttack(targetID:)` 的低层语义；本轮限制的是玩家 iOS 交互命中路径，不阻止已有订单继续追击已经获得的目标。
- 不新增 iOS HUD 按钮，不改变多选、控制编队、生产、建造、Save/Load 或敌方 AI 语义。

## 实现建议

- `swift/RustwarCore/Sources/RustwarCore/GameStateSelection.swift`
  - 新增只读 helper，例如 `selectionTargetVisibleToPlayer(at:includeEnemies:)`。
  - 语义：复用现有 `selectionTarget(at:includeEnemies:)` 的距离/优先级；若候选是己方实体直接返回；若候选是敌方实体，则需要 `visibility(for: .player).isVisible(at: target.position)`；不可见敌方返回 `nil`。
  - 不删除或改变现有 `selectionTarget(at:includeEnemies:)`，避免影响底层命令、测试和非 iOS 调用。

- `ios/RustwarIOS/RustwarIOS/GameController.swift`
  - 普通 `handleBattlefieldTap` 中用于双击同类记录、选择和 `engine.select` 的目标命中，改用可见性过滤 helper。
  - 若需要更新选择，优先保持现有 `engine.select` mutation 行为；可以新增/复用 core helper 后用 selection targets 更新，也可以让 `GameEngine` 增加一个 visible selection wrapper。关键是不让不可见敌方成为当前选择。
  - `issueContextCommand(at:)` 和 `handleSelectionTargetCommand(at:)` 改用可见性过滤 helper。
  - `handleBuilderTargetCommand`、`handlePointCommand`、area selection、Same Type、Screen Combat、Idle Builders、Combat Units、资源点和残骸命中不变。

- `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift`
  - 增加 helper 级测试：初始地图中敌方 Command Center / enemy unit 在玩家当前视野外时，普通 `selectionTarget` 可命中但 visible helper 不命中；移动 Scout 或构造状态让敌方进入视野后 visible helper 可命中。
  - 增加己方目标不受过滤测试。

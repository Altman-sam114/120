# v2.1 / cloud iOS visual smoke

## 目标

把原生 iOS 验证从“只证明能编译”推进到“云端真实启动并留下首屏视觉证据”：固定 iPhone 17 Pro / iOS 26.5 Simulator，安装并启动当前 App，抓取 PNG，并用可复判的像素指标拒绝透明图、尺寸异常图和近似黑屏。

## 实现要求

- CI flow / artifact schema 从 v1.1 升到 v1.2。
- 使用固定 Xcode 26.5 创建 `com.apple.CoreSimulator.SimDeviceType.iPhone-17-Pro` + `com.apple.CoreSimulator.SimRuntime.iOS-26-5` 设备，以其 UDID 作为 build destination。
- 使用独立 DerivedData 临时路径构建并保留 arm64/x86_64 双架构检查，安装并以 `--rustwar-ci-visual-smoke` 启动 `com.rustwar.prototype.ios`；该参数只让初始 `GameController` 进入暂停，不改变普通启动。稳定等待后确认 launch PID 仍存活，再抓取 `ci-results/ios-home.png`，并把固定 Simulator 的 portrait pixel buffer 规范化为可直接查看的 landscape PNG。
- 新增无第三方依赖的 Swift + ImageIO 探针，解码 PNG 并输出尺寸、透明像素比例、平均亮度、亮度标准差和亮度范围到 `ci-results/ios-screenshot-metrics.txt`。
- PNG 小于 640x300、不是 `width > height` 的横屏方向、透明像素超过 1%、亮度标准差小于 8 或亮度范围小于 40 时必须失败。
- JUnit 增加 `iOS Simulator launch and screenshot`，总数升为 8；browser smoke 仍是唯一预期 skipped。
- manifest 分别记录 simulator device/runtime/UDID、bundle id、launch、capture、pixel probe、截图及 metrics 路径；新增 `ios-simulator-info.txt`。
- 无论成功失败都尝试 shutdown/delete 临时 simulator；清理 exit 不得覆盖真实检查结果。
- artifact 只增加必要 PNG、metrics 和 simulator info，不上传 DerivedData、build cache、视频或 xcresult。

## 非目标

- 不新增 XCUITest target，不修改 Core/Web 玩法或 HUD，不加入第三方依赖；仅增加默认关闭的 CI 启动暂停参数。
- 本轮首屏证据不等于触摸、滚动、VoiceOver、Dynamic Type、Reduce Motion、旋转、战斗动画或帧率验收。
- 不运行任何本地测试、build、parse、Simulator、Preview 或浏览器验证。

## 文档与云端验收

同步 README、flow、flowchart、test 和 update log。提交并 push `origin/main` 后只使用 GitHub Actions 验证。Agent C 必须下载精确 SHA 的 v1.2 artifact，核对 8 项 JUnit、manifest、toolchain/simulator info、主日志、failure summary、PNG 和 metrics，并人工查看下载的云端 PNG；只有 launch/capture/probe 均为 success 且截图确实显示 Rustwar 首屏，才可通过 v2.1。

# v2.35 iOS coherent land materials

## 目标

移除 v2.34 云端 Home PNG 中仍明显的陆地三档逐 tile 色块，尤其是 Coast 交替 `grass` / `grass2` 造成的绿色棋盘；用连续基底与跨格低频纹理建立更接近 Rusted Warfare 公开战场画面的整体地表。

## 实现

- 8 种 `TerrainKind` 各自只保留一个基础 compound fill path，不再按稳定 hash 选择三档明暗。
- 表现层让 `grass` / `grass2` 共用同一草地基底和纹理 family；Core 类型、地图数据与通行语义保持独立。
- grass family、dirt、sand、rock 分别按连续 horizontal run 生成确定性的宽软纹与细高光，曲线端点和控制点留在对应材质行内。
- 每种 land family 的 soft/fine 细节各自聚合为 compound path；基础节点从最多 24 个降至最多 8 个，新增纹理后总节点上限仍不高于旧实现。
- 保留 v2.33 水面、v2.34 同色覆盖描边、短草痕/颗粒/裂线、海岸/深度/熔岩边界和雾层覆盖。

## 非目标

- 不修改直角地形逻辑边界或 Core tile；有机海岸/材质边界留给后续独立表现轮次。
- 不修改通行、建造、战斗、AI、命令、存档、Web 或 Tactical Map。
- 不新增 texture、shader、随机数、动画、timer、Task、第三方依赖或逐 tile SpriteKit node。

## 验证

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 只提交本轮 SpriteKit 源码、提示词和同步文档，直接 push `origin/main`。
- Agent C 下载最新精确 SHA artifact，核对 manifest、JUnit 8/0/1、至少 322 Core tests、arm64/x86_64 build、双 launch/orientation/probe 与双 PNG。
- 必须把云端 Home/Combat PNG 与 v2.34 并排复看：绿色与非水三档棋盘应显著减少，水面 hairline 不得恢复，单位、建筑、弹道、爆点和 HUD 层级不得回退。

# v2.38 iOS two-finger settle frame selection

## 背景

Rusted Warfare 移动版的多指框选不要求两指同向拖动：两指按住屏幕稍作停留，选择框直接框在两指之间，抬起即选。当前 Rustwar iOS 的 v2.30 分类器只接受"两指同向拖动"锁定框选，两指静置按住不会形成选择框，操作学习成本高。

## 目标

1. `MultitouchIntentClassifier.classify` 增加 `elapsed` 参数：两指静置（较忙手指位移 < 12pt、间距漂移 < 8pt）达到 0.22s dwell 后返回 `.selection`，选择框即为两指之间的包围矩形。
2. 保留既有拖动框选路径（同向、质心位移、间距稳定）与 pinch 判定完全不变；pending 命令仍只阻止 selection。
3. `BattlefieldView` 记录 `multitouchStartTime`，在 onChanged 和 onEnded（settle 后抬指）都尝试分类，静置达到 dwell 后显示预览框，抬指提交与拖动框选共用 `handleBattlefieldMultitouchAreaSelection`。
4. 新增 Core tests：settle 达到 dwell 锁定框选（含 ≤4pt 微抖）；不足 dwell、pending、单指位移超限（13pt / 9pt 间距漂移）、NaN elapsed 均拒绝。

## 非目标

- 不改 tap、双击同类、慢速循环、长按上下文、单指 pan、显式 Select Area。
- 不改 pinch 阈值和第三指/取消拒绝。
- 不改 Core 区域选择算法、Replace/Add、存档。

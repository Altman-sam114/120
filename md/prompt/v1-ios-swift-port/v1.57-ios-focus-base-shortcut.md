# v1.57 / iOS native focus-base shortcut

## 目标

把 Web 版 `Space` 回到己方指挥中心语义迁移到原生 iOS。v1.57 只新增原生 iOS 相机动作入口：HUD `Base` 按钮和外接键盘 Space 快捷键，复用当前 `GameState` 中存活己方 Command Center 的位置。

## 行为范围

- 查找 `engine.state.buildings` 中第一个 `team == .player`、`type == .command`、`hitPoints > 0` 的建筑。
- 找到目标时，将 `camera.center` 移到该建筑 `position`，并复用现有 clamp 行为。
- Space 快捷键和 HUD `Base` 按钮执行相同行为。
- 如果没有存活己方 Command Center，显示不可用状态并保持当前相机。

## 非目标

- 不修改 Web `app.js`。
- 不修改 `RustwarCore` 数据模型、存档 payload、地图 preset 或 SpriteKit 渲染层。
- 不改变 Reset camera 语义；Reset 仍回到地图 preset camera。
- 不改变 zoom。
- 不选择 Command Center。
- 不取消 Move / Attack / Build / Rally / Select Area 等等待态。
- 不下达 Stop，不改变单位命令、生产队列、集结点或控制编队。
- 不引入 UIKit key command、自定义焦点系统、第三方依赖、后端、构建链或网络依赖。

## 实现边界

- `ios/RustwarIOS/RustwarIOS/GameController.swift`：新增 `focusPlayerCommandCenter()`，从当前真实 `GameState` 查找存活己方 `.command`，调用已有 `centerCamera(on:)`。
- `ios/RustwarIOS/RustwarIOS/GameHUDView.swift`：在全局相机控制行新增 `Base` 按钮，使用 `Button("Base", systemImage: "house.fill", action:)`，声明 `.keyboardShortcut(.space, modifiers: [])`，保留 44pt 触摸目标和 VoiceOver 文案。

# v2.31 iOS dense unit tap cycling

## 目标

解决 v2.29 扩大到至少 44pt 后，密集己方单位只能反复选中最近实体的问题，同时保留 v2.11 直接命令和 v2.30 多指仲裁。

## 实现

- `GameState` 提供全部单点命中候选，按距离升序、再按 units-first 原始实体顺序稳定排序；可见版本继续拒绝真实视野外敌人。
- 原最近目标 API 复用候选第一项，默认几何半径和 `minimumHitRadius` 退化规则保持。
- `GameEngine` 提供按实体 ID 的精确 Replace/Add 选择。
- iOS 只在同一 44pt 屏幕区域、同一己方单位候选集合和 `0.38...1.4s` 间隔下循环；快速 `<=0.32s` 双击附近同类优先。
- 命令、区域选择、地图重置、读档、候选变化和超时清除瞬态循环状态。
- Core tests 覆盖稳定候选顺序、可见性过滤和按 ID mutation，suite 预期至少 319 tests。

## 非目标

- 不修改敌方直接 Attack、空地 Attack Move、Tactical Map、双指框选、战斗数值、AI、Core state/JSON 或存档。
- 不新增教程 UI、设置项、timer、Task、UIKit recognizer、第三方依赖或 XCUITest。

## 验证

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 只提交本轮源码、测试、提示词和同步文档，直接 push `origin/main`。
- Agent C 下载最新精确 SHA 的未加密 artifact，核对 manifest、JUnit 8/0/1、至少 319 Core tests、arm64/x86_64 build、双 launch/orientation/probe 与双 PNG。
- 静态截图和 Core tests 不能宣称证明真实重复点按手感。

# v1.52 / iOS native control groups MVP

## 目标

把 Web 版 `Ctrl + 1-9` 保存编队、`1-9` 召回编队的核心语义迁移到原生 Swift/iOS。v1.52 做触屏 MVP：Swift core 支持 1-9 号控制编队，iOS HUD 暴露 1-3 号 Save / Recall 按钮，用于快速保存和召回当前多选集合。

## 非目标

- 不实现 iPad / Mac 外接键盘快捷键。
- 不实现 4-9 号 HUD 按钮，避免当前 HUD 按钮爆炸；core 仍可支持 1-9。
- 不实现 Shift 追加/反选、队形保持、选择建筑混编框选、攻击姿态切换。
- 不修改 Web `app.js` 行为。
- 不新增第三方依赖、后端、构建工具或网络依赖。
- 不用 `WKWebView` 包装 Web 版。

## 实现边界

- Core owns control group state and recall filtering；iOS 只调用 core API 并显示按钮。
- 在 `GameState` 增加 `controlGroups: [Int: [String]]`，Codable 默认兼容旧存档：旧 JSON 无该字段时解码为空字典。
- `GameEngine.storeControlGroup(_:) -> [String]`：
  - 接受 1...9。
  - 保存当前选择中仍有效的己方单位或建筑 ID。
  - 按当前 selection 顺序保存。
  - 无有效选择时保存空数组，等价于清空该组。
- `GameEngine.recallControlGroup(_:) -> [String]`：
  - 接受 1...9。
  - 从保存 ID 中过滤当前仍存在、存活、己方的单位或建筑。
  - 写回 `selectedEntityIDs`，`selectedEntityID = ids.first`。
  - 召回空组或过滤后为空时清空选择并返回 `[]`。
  - 不改变单位订单。
- 存档恢复后 control groups 应继续可召回。
- iOS Save / Load 单槽存档自动随 `GameState` 保存/恢复 control groups。

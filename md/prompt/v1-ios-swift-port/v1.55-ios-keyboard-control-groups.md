# v1.55 / iOS native keyboard control groups

## 目标

把 Web 版控制编队快捷键迁移到原生 iOS 外接键盘路径。Web 当前是 `Ctrl + 1-9` 保存编队、`1-9` 召回编队；v1.55 要让 iOS HUD 中现有 1-9 编队按钮同时具备对应 SwiftUI keyboard shortcut。

## 非目标

- 不实现其它 Web 热键，例如 WASD、A/G/H/C/S、姿态 Z/X/V、Space 或 Ctrl+A。
- 不改变触屏 HUD 按钮布局。
- 不改变 `GameState.controlGroups` 数据结构。
- 不改变 `GameEngine.storeControlGroup(_:)` / `recallControlGroup(_:)` 的语义。
- 不新增编队追加、toggle、remove 或队形保持。
- 不修改 Web `app.js` 行为。
- 不新增第三方依赖、后端、构建工具或网络依赖。
- 不用 `WKWebView` 包装 Web 版。

## 实现边界

- Save control group `N` 使用外接键盘 `Control + N`。
- Recall control group `N` 使用外接键盘 `N`。
- 只给 `GameController.visibleControlGroupSlots` 中的 1-9 按钮挂载快捷键。
- 快捷键复用现有按钮 action，因此仍会执行 `clearPendingTargetCommands()`，仍受 `disabled` 状态约束。
- 保留现有 VoiceOver label、value、hint 和 44x44 触摸目标。
- 如果 SwiftUI 在某平台上不触发无修饰数字键，本轮也不引入自定义 UIKit key command；以云端 iOS build 通过和 SwiftUI 原生命令声明为验收范围。

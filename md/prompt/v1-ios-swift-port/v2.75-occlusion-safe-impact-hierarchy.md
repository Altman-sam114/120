## 背景与问题

v2.72 已让 Tank、Heavy Tank、Artillery 与 AA 具备不同 projectile profile，但当前 terminal flash 使用大实心白核和八角 starburst，陆地 impact 又叠加大白核、实心火球和两层实心 corona。固定 combat fixture 会在 `visual-enemy-tank`、`visual-enemy-artillery` 与 `visual-player-hover` 上同时放置 terminal 与 impact；反馈很醒目，却会吞没目标模型的关键轮廓。

Rusted Warfare 公开商店画面说明高密度单位、队伍色和弹道可以并存。本轮保留这种战场密度，同时用边缘化、断续化和偏心化几何提高信息层级，不降低命中反馈到难以察觉。

## 目标

1. Projectile terminal 只保留小接触点、真正断开的分段空心环和稀疏外向辐条；删除大面积实心爆心和星芒。
2. Generic land impact 降低贴地 bloom 遮挡，把双层实心 corona 改为外向辐条与分段环，把大白核改为小接触点，并用三枚偏心火瓣替代居中实心火球。
3. 所有新增几何必须确定、无随机数；不新增 effect root，保持一次 terminal 仍属于原 shot container、一次 impact 仍只占一个 bounded effect container。
4. 保持普通动画、Reduce Motion opacity-only 退化和 frozen combat tableau；不改变 64 effects / 32 decals 上限、生命周期或 fog/visibility 层级。
5. 新 Combat PNG 中 `visual-enemy-tank`、`visual-enemy-artillery`、`visual-player-hover` 在 terminal + impact 重叠后仍可辨 hull、炮塔/发射器、朝向和阵营标识。

## 实现要求

### Projectile terminal

- `addProjectileTerminalFlash` 继续复用既有 `point`、武器色、队色、radius、travel duration、frozen 与 Reduce Motion 参数。
- 中心接触点半径必须明显小于旧 core；外层使用四段空心环和六根左右的稀疏辐条，中心保持透明读图区。
- 分段 `CGPath` 的每段弧必须显式移动到起点，禁止让 Core Graphics 自动用弦线连接各段。
- 普通模式仍在 projectile travel 后显示并 fade/scale/rotate；Reduce Motion 只做短 opacity 反馈；frozen 路径保持静态可见。

### Generic land impact

- `spawnImpactEffect` 的水面分流、焦痕、烟尘、火花、碎片和 bounded lifetime 保持。
- 贴地 bloom 仅降低填充/描边存在感，不扩大尺寸。
- 外层 corona 使用确定性辐条，内层使用真正断开的分段空心环；中心只保留小接触点。
- 火焰主体使用三枚确定性偏心椭圆火瓣，围绕中心留孔；不得按攻击来源伪造方向性扇形。
- 普通模式继续执行短 fade/scale，Reduce Motion 不移动、旋转或扩张，frozen 继续持久加入既有有界 effect root。

### 不变量

- 保持 v2.72 四类武器层级：Tank 短 tracer、Heavy 宽热炮弹、Artillery 抬升弧线/地面影子/烟珠、AA 平行双线与一次 volley terminal。
- 不改变 `spawnDestructionEffect`、water impact、模型、伤害烟火、焦痕结构或 combat fixture 的单位/建筑/shot/impact 布局。
- Scene 仍由 cooldown 与 HP/entity-id 差分推导 presentation；Core 没有可靠 attacker impact event，因此不得宣称 generic HP impact 已知来袭方向或武器来源。
- 不改 Core 命中、伤害、冷却、射程、目标、AI、命令、生产、触控、HUD、Tactical Map、存档/JSON 或 Web 版。
- 不新增纹理、音频、第三方依赖、timer、Task、随机数、effect/decal 上限、Xcode project 文件或 workflow。
- `.wp` 保持未跟踪，不得编辑、暂存或提交。

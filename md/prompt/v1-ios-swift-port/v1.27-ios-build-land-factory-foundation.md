# v1.27 / iOS native Build Land Factory foundation

## Agent B 任务

在 v1.17 Build Extractor、v1.26 Build Turret 和 v1.2+ 原生生产队列基础上，给原生 iOS Builder 增加最小 `Build Factory` 点位建造入口：选中己方 Builder 后进入 Factory 放置等待态，tap 主战场或战术小地图点位扣除金属、创建未完成 Land Factory，并复用现有 `.build(targetID:)` 订单推进建造。完成后的 Land Factory 必须继续使用现有 Scout / Light Tank 生产、Cancel Production、Repeat 和 Rally 逻辑。

## 背景依据

- Web 原型支持工程单位建造生产建筑；当前 iOS Builder 只能建 Extractor 和 Turret。
- `BuildingDefinition.landFactory` 已有 HP、尺寸、金属成本、人口容量和 `produces` 列表。
- `BuildingSnapshot.buildProgress`、`UnitOrder.build(targetID:)` 和 `GameEngine.updateBuildOrder` 已能推进任意未完成建筑。
- iOS HUD 已有 Builder 等待态、点位命令、战术小地图 pending feedback 和 Stop 清理等待态。

## 目标

1. Swift core：
   - 为 Land Factory 设置 Web 对齐的 `buildTime = 22`，避免新建工厂沿用默认 1 秒完成。
   - 新增 `GameEngine.issueBuildLandFactory(at:) -> UnitCommandResult`。
   - 只允许当前选中的己方 Builder 下令。
   - 目标点 clamp 到地图内，并复用 v1.26 的最小建筑放置校验：不得在水/深水/岩浆上，不得贴近现有资源点、存活建筑或存活单位。
   - 成功时扣除 `GameDefinitions.building(.landFactory).metalCost`，创建 `buildProgress = 0`、初始 HP 为最大 HP 10% 的己方 Land Factory，并给 Builder 写入 `.build(targetID:)`。
   - 新建 Land Factory 的 `rally` 可先使用建筑位置；完成后沿用现有生产、集结点、取消生产和 repeat 行为。
2. iOS App：
   - 选中己方 Builder 时显示 `Factory` 按钮，使用文字 label、系统图标和 44pt 最小触控高度。
   - `Factory` 等待态与 Move / Attack Move / Patrol / Guard / Repair / Reclaim / Build Extractor / Turret / Attack / Rally 互斥。
   - 主战场 tap 和战术小地图 tap 均可作为 Factory 建造点位；成功或失败后清除等待态并显示状态文案。
   - Stop、Load、Restart 和切图应清除 Factory 等待态。
   - 战术小地图 pending command 标签、符号、图标和 VoiceOver hint 需要覆盖 Factory 等待态。
3. Tests：
   - 拒绝无选择、敌方 Builder、非 Builder、已选建筑、资源不足和非法/重叠点位。
   - 成功下令会扣金属、创建未完成 Land Factory、`nodeID == nil`、保留选择并给 Builder 写入 build 订单。
   - Builder 远距时会靠近 Factory 并保持订单；在范围内会推进建造直到完成、满 HP 并清除订单。
   - 完成后的新 Land Factory 可被选中并排队生产 Scout 或 Light Tank，证明它接入既有生产体系。
   - Stop 可清除 Land Factory build 订单。
4. 文档：
   - 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不新增完整建筑菜单、建造幽灵、拖拽放置、旋转、Shift 队列、多 Builder 协同或取消未完成建筑退款。
- 不实现 Command Center / Radar / Anti-Air / Mech / Air / Naval / Experimental 等其它建筑建造。
- 不让红方 AI 主动建 Land Factory。
- 不做完整 Web 版碰撞、地形、雾、资源和队列放置 parity。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不新增第三方依赖，不使用 `WKWebView`。

# v2.95 iOS HUD visual hierarchy

## Goal
Refine the native tactical HUD after v2.94 cloud screenshots: keep the selected-unit summary compact, preserve readable multi-line accessibility text, and let the battlefield remain visible beneath the command dock.

## Scope
- `TacticalSelectionSummaryView.swift`: constrain normal-size summary to two lines with tightening and retain a larger accessibility allowance.
- `TacticalHUDTheme.swift`: soften dock/metric opacity for stronger battlefield continuity while retaining contrast.
- `TacticalCommandDockHeaderView.swift`: reduce header vertical padding without changing controls or identifiers.

## Non-goals
No Core rules, touch routing, production costs, command semantics, SpriteKit models, save format, or Web behavior changes.

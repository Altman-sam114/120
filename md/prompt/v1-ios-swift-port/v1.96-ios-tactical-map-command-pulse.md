# v1.96 / iOS Tactical Map command pulse

## 目标

让 v1.95 的成功世界坐标命令同时在 Tactical Map 显示短生命周期落点脉冲，为离屏和战略缩放命令提供明确视觉确认；重构共享命令调色板，避免 SpriteKit 与 SwiftUI 各维护一套颜色。

## 实现范围

- `CommandConfirmation` 增加 monotonic uptime，并集中九类命令 RGB 调色板。
- `TacticalMapView` 使用现有 confirmation、SwiftUI Canvas 和短时 task 动画绘制小地图 marker。
- `BattlefieldScene` 改为读取共享调色板，不改变 v1.95 marker 路径和生命周期。
- 同步 README、flow、flowchart、test 和 update log。

## 必须满足

1. Tactical Map 复用同一个 `CommandConfirmation`，禁止新增第二套 controller 状态、Timer 或 Core 模型。
2. 事件记录 `ProcessInfo.processInfo.systemUptime`；View 重建时超过动画期限的旧事件不能重放，延迟观察的事件从真实年龄对应的进度继续。
3. 只在 revision 变化时启动可取消 SwiftUI task；不得使用永久运行的 `TimelineView` 或让静态小地图持续 30/60fps 重绘。
4. 普通 marker 在 0.78 秒内从约 5pt 扩至 9pt 并淡出；Reduce Motion 固定约 7pt，只做 0.3 秒淡出。
5. 九类命令继续同时用共享颜色和不同小型路径区分；Differentiate Without Color 不得只靠颜色。
6. marker 在小地图 fog 之后绘制，因为它只表示玩家刚发出的命令坐标，不是敌方状态；不得额外绘制隐藏单位、建筑或雷达外信息。
7. marker 必须在 camera viewport/pending command indicator 之间保持可见，不拦截 tap、drag、long press 或 VoiceOver。
8. `CommandConfirmationKind` 的 RGB components 只定义一次，SpriteKit 转为 `SKColor`，SwiftUI 转为 `Color`。
9. 不改变主战场 marker、触觉、命令结果、AI、存档、Core、HUD 尺寸或 Web。

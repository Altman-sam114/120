# v2.37 iOS slim tactical HUD chrome

## 背景

Rusted Warfare 移动版战场几乎满屏，HUD 只占极窄的顶栏与侧栏。当前 Rustwar iOS 的 command dock、状态栏和小地图占比偏大，selection summary 还带独立卡片底色，视觉重量高于战场本体。工作区已有一组未提交的 HUD 纤薄化改动，本轮将其收编、验证并入库。

## 目标

1. 状态栏改为恒定单行（metrics 左、Pause/Speed 右），垂直 padding 从 6pt 收到 2pt，metric 块垂直 padding 收到 2pt；compactBottom 角色直接用 menu 式速度选择器，不再整行铺开 Pause。
2. command dock 收窄：regular trailing 从 28% / 268-320pt 收到 24% / 240-280pt；compact trailing 从 30% / 224-260pt 收到 24% / 204-224pt；compact bottom 高度比例从 0.34 收到 0.30、范围 200-288pt（accessibility Dynamic Type 保留 0.42 / 216-320pt 独立档），极短容器最低 168pt。
3. 战术小地图同步缩小：regular trailing 176×118 → 160×106；compact trailing / bottom 常规档 144×96 → 132×88（最小档 120×80 保持）。
4. dock header 用 compactPadding；selection summary 去掉独立卡片底色/描边，只保留文本层级，降低 header 视觉重量。
5. 提交用户在 Xcode 中产生的 `project.pbxproj` 变更（objectVersion 60、DEVELOPMENT_TEAM），作为独立 chore commit 保留，不得回滚。

## 非目标

- 不改任何 controller action、disabled 条件、快捷键、VoiceOver 语义或 44pt 触控目标。
- 不改 BattlefieldScene 渲染、Core、存档、Web 版。
- 不改三档 layout role 判定断点。

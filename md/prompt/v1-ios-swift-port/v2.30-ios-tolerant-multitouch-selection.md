# v2.30 iOS tolerant multitouch selection

## 目标

改善 v2.12 双指框选对手指不同步过于敏感的问题，并把内联手势数学抽成可由云端 Swift tests 验证的纯分类器。

## 实现

- `RustwarCore` 新增 `MultitouchIntentClassifier`，有限坐标输入返回 selection、pinch 或 undecided。
- selection 要求总体同向、质心至少 8pt、领先手指至少 10pt、跟随至少 5pt且间距稳定。
- 明显 12pt 张合或反向移动返回 pinch；pending 命令只阻止 selection，非法坐标返回 undecided。
- `BattlefieldView` 只转换 CGPoint 并消费分类结果，不改变 touch id、第三指/cancel、preview、tap 抑制、MagnifyGesture 或区域选择提交。
- Core tests 覆盖上述边界，预期 suite 至少 316 tests。

## 非目标

- 不新增 UIKit recognizer、第三方依赖、持久状态、教程 UI 或手势设置面板。
- 不修改 tap、长按、单指平移、显式 Select Area、Replace/Add、Core selection 或 Tactical Map。

## 验证

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 仅提交本轮源码、测试、提示词和同步文档，直接 push `origin/main`。
- Agent C 下载最新精确 SHA 的未加密 artifact，核对 manifest、JUnit 8/0/1、至少 316 Core tests、双架构 build、双 launch/orientation/probe 与双 PNG。
- 静态截图和分类器单测不能宣称证明真实多指手感。

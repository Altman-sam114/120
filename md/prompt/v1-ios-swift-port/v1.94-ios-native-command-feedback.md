# v1.94 / iOS native command sensory feedback

## 目标

为原生 SwiftUI RTS 的离散选择、命令成功和无效操作增加系统级触觉反馈，改善触屏下令确认感；修复 v1.93 云端日志暴露的草地 detail gate pattern warning。不得把触觉接入每帧模拟、相机连续手势或文本猜测。

## 实现范围

- `GameController.swift`：新增 selection、command success、warning 三个事件 revision，并在明确的用户 action 结果处递增。
- `RootGameView.swift`：使用 SwiftUI `.sensoryFeedback` 绑定三个 revision。
- `BattlefieldScene.swift`：让 `.grass` 和 `.grass2` 共享同一个显式 detail gate，消除 `where` 只作用于第二个 pattern 的警告。
- 同步 README、flow、flowchart、test 和 update log。

## 反馈规则

1. 选择单位/建筑、批量选择、框选、同类选择、编队召回、选择模式和等待目标模式切换使用 `.selection`。
2. Move、Attack、Attack Move、Patrol、Guard、Repair、Reclaim、Build、Rally、Stop、升级、生产、取消、Repeat、存档/读档等真实成功结果使用 `.success`。
3. 空选择、无效目标、资源/人口不足、不支持操作、无存档和解码失败使用 `.warning`。
4. 结果分类必须读取具体 enum case 或明确布尔结果，禁止解析 `commandStatus` 字符串。
5. `advance`、AI tick、render/map revision、pan、zoom、Tactical Map drag、键盘 repeat 和战场特效不得触发触觉。
6. 不使用 UIKit feedback generator、音频模拟、第三方依赖或手写设备能力判断；系统负责尊重设备和用户触觉设置。
7. 不改变 Core 命令结果、战斗数值、存档格式、按钮 action、快捷键或触摸坐标映射。

## Terrain warning 修复

- `.grass` 与 `.grass2` 都必须先通过 `detailGate > 0.44` 才写入 grass detail path。
- 不能复制 detail path 绘制代码，也不能改变其它地形 gate、稳定 hash、节点上限或图层顺序。

# v2.39 iOS combat readability declutter

## 背景

Rusted Warfare 战场的一大精致感来源是低杂讯：满血单位不显示血条，命令线只画给当前选中的单位。当前 Rustwar iOS 给全部单位/建筑常驻血条（含满血），未选中单位还以 0.4-0.62 透明度画 Move/Attack/Patrol 等命令线与落点标记，战斗密集时层级混乱。

## 目标

1. 单位与建筑血条只在受损（`hitPoints < maxHitPoints`）时绘制；满血实体不再有血条。建造进度条与升级进度条不受影响。
2. 命令线与落点标记只为选中单位绘制：`drawUnit` 在 `!isSelected` 时跳过全部 order 绘制分支。选中单位的命令线保持既有 underlay + 高亮样式。
3. 血条本体精修：高度 6→4.5、去掉白描边改为黑色 0.75 透明底 + 1pt 深色内缩描边，颜色语义（绿/黄/红）不变。

## 非目标

- 不改 Core、命中、选择、命令、存档。
- 不改弹道、爆点、灼痕、残骸、雾、雷达层。
- 不改建筑 rally 线（仍只在选中生产建筑时绘制）。

# v1.18 / iOS native enemy Extractor expansion MVP

## Agent B 任务

在 v1.17 原生 Builder 建造 Extractor 地基之上，小步补齐红方 AI 的经济扩张：红方空闲 Builder 应能自动选择空闲资源点，扣除红方金属，创建未完成 enemy Extractor，并沿用现有 Build 订单靠近、建造、完成后产出收入。

## 背景依据

- Web 版红方 AI 会扩张资源点，是中后期经济和生产压力的核心闭环之一。
- 原生 v1.17 已经有 `UnitOrder.build(targetID:)`、Extractor 建造进度、资源点占用、完成收入门控、死亡释放资源点和建造线渲染。
- 当前原生 AI 只会让红方工厂排队生产、让红方作战单位攻击玩家目标；红方 Builder 不参与扩张。

## 目标

1. 在 `RustwarCore` 中让 `GameEngine.updateEnemyAI()` 增加红方 Builder 扩张步骤。
2. 只选择满足条件的 Builder：
   - team 是 `.enemy`
   - type 是 `.builder`
   - HP > 0
   - 当前 `order == nil`
3. 只选择满足条件的资源点：
   - `claimedBy == nil`
   - 没有存活 Extractor 占用该 `nodeID`
   - 优先选择离该 Builder 最近的空闲资源点
4. 成功扩张时：
   - 扣除 enemy 金属 260
   - 创建 team `.enemy`、type `.extractor`、`buildProgress=0` 的未完成 Extractor
   - 资源点立刻 `claimedBy = .enemy`
   - Builder 获得 `.build(targetID:)`
   - 不改变玩家当前选择
5. 未完成 enemy Extractor 不提供收入；完成后才增加 enemy income。
6. 资源不足、Builder 忙碌、没有空闲资源点、资源点已被占用时不得重复创建建筑。
7. 保持 Web 原型直接打开 `index.html` 可运行；本轮不改 Web 玩法。
8. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不迁移完整 Web AI 建造树、难度倍率、升级、基地防御规划或进攻波策略。
- 不让玩家 UI 改变，不新增按钮。
- 不做 AI 多 Builder 协同建造、队列建造、地形寻路或威胁规避。
- 不迁移其它建筑类型建造。
- 不引入第三方依赖，不使用 `WKWebView`。

## 测试要求

Swift tests 至少覆盖：

- AI 开启时，空闲 enemy Builder 会选择空闲资源点并创建未完成 enemy Extractor。
- 扩张会扣除 enemy 金属、认领资源点、给 Builder 写入 Build 订单，且不改变玩家选择。
- 未完成 enemy Extractor 不增加 income，完成后 enemy income 增加。
- enemy 金属不足时不会创建 Extractor，也不会给 Builder 写 Build 订单。
- enemy Builder 已有订单时不会被扩张逻辑覆盖。
- 没有空闲资源点时不会重复创建 Extractor。

# v1.63 / iOS native context command long press

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.63。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

为原生 iOS 主战场增加最小上下文命令入口，让触屏长按接近 Web 右键的高频语义：

- 长按敌方单位或建筑：若当前选择可攻击，则直接下达 Attack。
- 长按友方单位或建筑：若当前选择包含 Builder 且目标受损，则 Repair；否则若当前选择可护航，则 Guard。
- 长按残骸：若当前选择包含 Builder，则 Reclaim。
- 长按空闲资源点：若当前选择包含 Builder，则 Build Extractor。
- 长按空地点：若当前选择是生产建筑，则 Rally；否则若当前选择有己方单位，则 Move。

所有命令必须复用现有 `GameEngine` API、多选集合、合法性校验和状态文案。

## 非目标

- 不修改 Web `app.js`。
- 不实现完整 Web 右键语义、运输装载/接载、Shift 队列、连续建造、攻击移动右键模式、上下文菜单、可配置手势、触觉反馈或 UI 自动化。
- 不新增 Swift core 状态、命令类型、存档字段或 iOS target。
- 不改变普通 tap 选择、双击同类型选择、Select Area 拖拽、等待态点选、战术小地图点按或外接键盘行为。
- 不用 `WKWebView` 或网页包装。

## 实现建议

- `ios/RustwarIOS/RustwarIOS/BattlefieldView.swift`
  - 增加主战场长按空间手势，结束时把屏幕点和 viewport size 传给 controller。
  - 长按应只作为普通状态下的 context command；如果当前正在等待 Move / Attack / Build / Rally / Select Area 等目标，继续让现有 tap/drag 等待态负责，不要重复派发。
  - 保持现有 tap、drag、magnify 手势和选择框逻辑。
- `ios/RustwarIOS/RustwarIOS/GameController.swift`
  - 新增 `handleBattlefieldContextCommand(screenPoint:viewportSize:)` 或等价 public 方法。
  - 先把屏幕点换算成 `WorldPoint`。
  - 若 `isAwaitingTargetCommand` 为 true，给出轻量状态文案或直接忽略，但不要执行上下文命令。
  - 优先处理实体目标，再处理残骸/资源点，最后处理点位命令：
    - 敌方目标：`engine.issueAttack(targetID:)`。
    - 友方受损目标且有 Builder：`engine.issueRepair(targetID:)`。
    - 友方目标且有单位：`engine.issueGuard(targetID:)`。
    - 残骸：`engine.issueReclaim(wreckID:)`。
    - 资源点：`engine.issueBuildExtractor(on:)`。
    - 空点：优先 `engine.setRally(to:)`，若不是生产建筑则 `engine.issueMove(to:)`。
  - 成功或失败都沿用现有 `statusText(...)` helper，不复制新文案体系。
  - 清理 `lastBattlefieldTap`，避免长按后紧接 tap 被误判为双击同类型选择。
- `swift/RustwarCore/`
  - 本轮预期不改。现有 tests 已覆盖 Move / Attack / Guard / Repair / Reclaim / Build Extractor / Rally 的核心规则。

## 验收标准

- 主战场长按空地点能让当前选中己方单位 Move。
- 主战场长按敌方单位或建筑能让当前选中己方单位 Attack。
- 主战场长按友方受损单位或建筑能让选中 Builder Repair；长按友方健康单位或建筑能让选中单位 Guard。
- 主战场长按残骸能让选中 Builder Reclaim。
- 主战场长按空闲资源点能让选中 Builder Build Extractor。
- 主战场长按空地点且当前选中生产建筑时设置 Rally。
- 普通 tap 选择、等待态点选、Select Area 拖拽、战术小地图和外接键盘仍保持既有行为。

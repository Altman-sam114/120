# v2.43 iOS refined tracked unit models

## 背景

Rusted Warfare 的俯视单位依靠强轮廓、独立履带块和少量高对比机械细节，在远景仍能快速区分 Tank、Heavy Tank、AA Tank 与 Artillery。当前 iOS 版已有炮塔、炮管、后坐和阵营标识，但履带内部仍是重复线段，车体缺少统一的甲板拼缝与发动机格栅层。

## 参考

- [Rusted Warfare Tank profile](https://rustedwarfare.fandom.com/wiki/Tank)
- [Rusted Warfare Unit Overview: Artillery](https://www.youtube.com/watch?v=4ppi413tVv0)
- [Unit Profile: Artillery](https://www.youtube.com/watch?v=9yAgymz4cu0)

## 目标

1. `addTracks` 每侧保留外履带和内带，并把负重轮与履带齿分别聚合为 compound path；每侧常驻节点从 7 个降为 4 个。
2. Tank、Heavy Tank、AA Tank、Artillery 增加确定性的车体拼缝与发动机格栅，保持四种既有轮廓差异。
3. Tank 增加舱盖，AA Tank 增加双侧供弹箱，Artillery 增加炮闩与聚合驻锄；炮塔细节仍挂 `weaponMount`，炮管细节仍挂 `recoilMount`。
4. 全部细节继续是 SpriteKit 静态 path；不增加动画、随机数、texture、shader、计时器或 Core/JSON 字段。
5. 通过减少重复履带节点控制密集战斗中的渲染成本；每个履带单位的总常驻节点不得因本轮增加。

## 非目标

- 不改 Core、数值、命中半径、命令、AI、存档、雾、弹道、后坐、炮塔转向或战斗特效。
- 不修改 Builder、Scout、Hover、Gunboat、建筑模型、HUD、Tactical Map 或生产 fixture。
- 不引入新的资源文件、第三方依赖或 UIKit 路径。

## 实现边界

- `BattlefieldScene` 继续只读 `UnitSnapshot` 和 `UnitDefinition`，不得写回 Core。
- `weaponMount` 只接受炮塔/舱盖/供弹等随武器旋转的细节；`recoilMount` 只接受炮管、炮闩或发射器后坐层。
- compound path 只聚合同一种材质/描边语义，不用逐轮循环创建常驻 `SKShapeNode`。
- 保留 `.wp`，只提交本轮明确相关文件。

# v1.71 / iOS hide unseen enemy entities

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.71。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

在 v1.70 玩家当前视野 tile 地基上，让原生 iOS 主战场不再绘制当前玩家视野外的敌方单位和敌方建筑，进一步接近 Web 版战争迷雾体验。

- 只影响 SpriteKit 主战场渲染；`RustwarCore` 对局状态、AI、命令、选择和存档不变。
- 己方单位/建筑始终绘制。
- 敌方单位和敌方建筑只有当前位置所在 tile 对玩家可见时才绘制。
- 敌方炮塔火力线、敌方攻击目标线和敌方单位订单线不应在该敌方实体不可见时泄露目标位置。
- 玩家单位攻击一个不可见敌方目标时，不绘制到该不可见目标的攻击线；目标重新可见后自然恢复显示。
- v1.70 的雾层继续保留；本轮只是过滤主战场敌方实体与相关线条。

## 非目标

- 不修改 Web `app.js`。
- 不实现已探索记忆、雷达信号、战术小地图雾层、敌方小地图隐藏、雾内点选/命中限制、AI 情报限制、弹道/粒子隐藏或存档 explored grid。
- 不改变 `GameState.visibility(for:)` 的 API 和语义，除非为渲染可读性新增只读 helper。
- 不新增 iOS UI 按钮，不改变命令按钮、长按上下文、键盘快捷键、选择、多选或控制编队语义。

## 实现建议

- `ios/RustwarIOS/RustwarIOS/BattlefieldScene.swift`
  - 在 `renderNow()` 中计算一次 `let playerVisibility = state.visibility(for: .player)`，同时传给 `drawEntities(state, playerVisibility:)` 和 `drawFog(playerVisibility)`。
  - 为单位/建筑增加轻量可见性判断，例如 `isVisibleToPlayer(_ unit: UnitSnapshot, visibility: VisibilitySnapshot)` 和 building 版本：己方直接 true，敌方需要 `visibility.isVisible(at: position)`。
  - `drawEntities` 先绘制残骸，再只绘制通过可见性判断的建筑和单位。
  - `drawUnit` 中订单线绘制应避免泄露不可见敌方目标：`targetPosition(for:in:visibility:)` 对敌方单位/建筑目标要先检查目标是否对玩家可见；wreck 仍按旧行为返回。
  - `drawBuilding` 中敌方炮塔火力线只在该炮塔本身对玩家可见时才考虑绘制；其目标位置也要通过可见性 helper，避免火力线指向不可见目标。
  - 保持雾层在实体之上，避免大范围重排节点结构。

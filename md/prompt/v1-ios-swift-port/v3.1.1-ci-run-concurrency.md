# v3.1.1 CI runner concurrency

目标：避免同一 main commit 的重复重跑长期占用或排队竞争 macOS runner，保证最新结果包具有唯一权威 run。

实现：为 Rustwar CI 增加按 ref 分组的 GitHub Actions concurrency，新的 main run 自动取消旧的 queued/in-progress run；不改变任何产品代码、测试门控或 artifact 内容。

验收：仅使用 GitHub Actions；确认最新 main SHA 的 run 进入执行并生成 manifest、JUnit、失败摘要和必要截图。不得以本机测试替代。

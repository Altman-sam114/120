# v2.41 iOS refined extractor and radar models

## 背景

v2.40 精细化了 Command Center / Land Factory / Turret，遗留 Extractor / Radar。v2.40 Home 固定截图中己方 Extractor 仍是较平的双圆结构，固定 Home / Combat 场景均未包含 Radar，因此本轮还要补最小的 production-only Radar 视觉证据。

## 目标

1. Extractor：外环增加四个抽取臂夹持块与四颗独立螺栓，环与核心之间增加聚合齿圈刻痕，核心增加偏移高光；T2 青环与 T3 八点标记语义保持。
2. Radar：基座增加聚合格栅、聚合支架斜撑和两个支脚，天线杆增加横撑，主碟增加内圈、馈源臂与馈源点；T2 第二碟保持。
3. 全部细节为确定性静态 path；Extractor 新增常驻节点恰为 10，Radar 新增常驻节点不超过 8；不加动画、随机数或 texture。
4. production cloud fixture 增加一座完整露出的完成状态 T2 玩家 Radar，使固定 Home PNG 同时证明 Extractor 和 Radar；普通启动和 combat fixture 不变。

## 非目标

- 不改 Command Center / Land Factory / Turret（v2.40 已完成）。
- 不改 Core 定义、尺寸、命中、升级语义、建造帧、损伤烟、选择角标、血条。
- 不新增 Core/JSON 字段、模型资产、shader、计时器、`SKAction` 或玩法状态。

## 实现边界

- Scene 继续只读 `BuildingSnapshot`，不得写回 Core。
- 多道刻痕、格栅和斜撑必须聚合为 compound path，避免逐线节点增长。
- 追加的 T2 Radar 必须只存在于 `cloudVisualScenario == .production` 的状态构造路径；普通 `GameState`、普通 App 启动和战斗 fixture 不得改变。
- 保留 `.wp`，只提交本轮明确相关文件。

## 验证与验收

- 禁止运行任何本地测试、格式检查、Swift/Xcode build、Simulator、Preview 或截图。
- Agent B 只读确认 `main` / `origin/main` 和提交范围，提交本轮文件并直接 push 到 `origin/main`。
- 以实现提交的精确 SHA 定位 `Rustwar CI Results`；Agent C 下载唯一 artifact 到 `/private/tmp/rustwar-c-review-<run_id>/`，核对 manifest 的 `branch=main`、完整 `commitSha`、run id、run attempt、Xcode 26.5 / iOS 26.5、JUnit 8/0/1、至少 324 Core tests、arm64/x86_64 build、Home/Combat 双 launch/orientation/pixel probe。
- Agent C 必须人工对照 v2.40 双 PNG：Home 中 T1 Extractor 的夹臂、螺栓、齿圈和核心高光可辨；新增 T2 Radar 的基座支撑、碟面馈源和第二碟完整露出；Factory、Command Center、单位、资源点、HUD 和 Tactical Map 无遮挡或脏乱回退。Combat 模型、弹道、爆点和 HUD 层级不得回退。
- CI 绿色但目标模型不可辨、被遮挡或构图变差时，视觉验收仍不通过，必须追加修复提交并重新验收最新 SHA。
- 通过后把真实 commit、run、attempt、artifact、JUnit/Core/build/probe 和 PNG 结论写入 `update_log.md`，提交/push 该文档记录，再对最终文档 SHA 重走一次精确 artifact 验收。

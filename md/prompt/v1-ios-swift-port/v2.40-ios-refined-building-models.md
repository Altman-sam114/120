# v2.40 iOS refined building models

## 背景

对照 Rusted Warfare 截图，其建筑有清晰的机械细节：分层装甲板、舱门、通风口、警示条。当前 Rustwar iOS 的 Command Center / Land Factory / Turret 模型层次较平，缺少工业细节。

## 目标

1. Command Center：八角基座上叠加分层装甲板拼缝、四角螺栓、双通风口格栅、核心外圈队色能量环与中央指挥穹顶高光，让基地视觉密度接近参考。
2. Land Factory：主厂房增加出车口舱门（带黄黑警示条）、屋顶通风格栅、侧管线；保留 T2 扩建语义。
3. Turret：基座增加环形铆钉与阴影层，炮管加根部套筒和口部高光，提高立体感。
4. 全部细节为确定性静态 path，节点数量每建筑增加不超过 12 个；不加动画、随机、texture。

## 非目标

- 不改 Extractor / Radar（后续轮次）。
- 不改任何 Core 定义、尺寸、命中、turret 旋转/后坐、建造帧、损伤烟、选择角标、血条。

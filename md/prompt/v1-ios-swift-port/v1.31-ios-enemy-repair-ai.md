# v1.31 / iOS native enemy repair AI

## 角色

本提示词交给 Agent B 执行。Agent B 必须遵守 `AGENTS.md` 的 main 直推、轻量本地检查、GitHub Actions artifact 和 Agent C 复判流程。

## 背景

v1.15 已让玩家 Builder 可以维修受损友方单位或建筑；`UnitOrder.repair`、`updateRepairOrder()` 和 `applyRepair()` 已集中在 `RustwarCore`，且逻辑本身按队伍工作。v1.29 / v1.30 已让红方 Builder 可以自动建造 Land Factory 和 Turret。当前原生红方 AI 仍不会主动修复受损友军目标，导致红方防御建筑或核心建筑受损后没有维护闭环。Web 版已有维修单位、维修平台和支援行为，原生迁移应先补一个小范围、可测试的红方 Builder 自动维修 MVP。

## 目标

- 在 `RustwarCore` 的红方 AI 中新增 enemy Builder 自动维修 MVP。
- 当红方有空闲 Builder 且存在受损的红方单位或建筑时，AI 应给该 Builder 写入 `.repair(targetID:)`。
- 维修目标必须是存活、同队伍、非 Builder 自身、`hitPoints < maxHitPoints` 的实体。
- 维修执行必须复用现有 `updateRepairOrder()`：远距离移动到维修范围，范围内按 18 HP/s 修复，满血后清除订单。
- 不得改变玩家当前选择。
- 保持红方缺少 Land Factory 时的补建优先级高于维修，避免红方被维修行为拖住关键重建。
- 同步 README、flow、flowchart、test 和 update_log。

## 非目标

- 不新增玩家 UI、SwiftUI HUD 按钮、SpriteKit 视觉或战术小地图交互。
- 不修改 Web `index.html` / `styles.css` / `app.js`。
- 不新增维修平台、维修车、维修光环、自动维修玩家单位、金属消耗、维修优先级矩阵、多 Builder 协同或完整 Web 支援系统 parity。
- 不改变现有 `issueRepair(targetID:)` 的玩家选择语义。
- 不引入新框架、后端、网络依赖或 WKWebView。

## 建议实现

- 修改 `swift/RustwarCore/Sources/RustwarCore/GameEngine.swift`。
- 在 `updateEnemyAI()` 中保留现有顺序，并建议在 `updateEnemyFactoryConstruction(rebuildMissingFactoryOnly: true)` 之后、`updateEnemyExpansion()` 之前调用 `updateEnemyRepair()`：
  - 缺少 Land Factory 时，仍先尝试补建。
  - 若 Builder 空闲且有受损友军目标，先维修，再考虑扩张、第二工厂、炮塔、生产和攻击。
- 新增私有 helper，例如：
  - `updateEnemyRepair()`
  - `enemyRepairTarget(for builder: UnitSnapshot) -> RepairTarget?`
- 目标选择应确定性，建议按“受损建筑优先于单位、剩余 HP 比例更低优先、距离更近作为平局”的轻量策略；至少必须保证测试稳定，不使用随机数。
- 可复用已有 `RepairTarget` 私有结构；若需要排序，避免扩大公开 API。
- 不要扣金属；保持现有玩家维修行为不消耗金属的一致性。

## 测试要求

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加 Swift tests，至少覆盖：

- enemy AI 在有空闲 enemy Builder 和受损 enemy 建筑时写入 `.repair(targetID:)`，并不改变玩家选择。
- enemy repair order 推进后能按现有 18 HP/s 修复受损 enemy 单位或建筑，满血后清除订单。
- enemy AI 不维修满血目标、不维修敌方/玩家目标、不让忙碌 Builder 改单。
- enemy AI 在缺少 Land Factory 且金属/点位允许补建时，优先 `.build` 补建，而不是维修。
- enemy repair target 选择确定性：建议覆盖建筑优先于单位，或低 HP 比例目标优先。

## 验收标准

- 红方 Builder 能在原生 Swift core 中自动维修受损红方单位或建筑。

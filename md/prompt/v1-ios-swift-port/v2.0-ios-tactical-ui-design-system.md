# v2.0 / iOS tactical UI design system

## 目标

在 v1.99 独立 HUD ownership 上建立统一、安静、工作型的原生战术视觉系统，提高资源、选择对象、升级状态和等待命令的扫描效率，为继续超越 Rusted Warfare 的视觉精修提供稳定 token。

## 实现要求

- 新建 `TacticalHUDTheme`，集中 4/6/8/14pt spacing、10pt content padding、6pt corner radius、44pt minimum hit target，以及 accent/attention/neutral status colors。
- 状态栏四个资源指标分别增加稳定 SF Symbols，同时保留 Dynamic Type、monospaced digits 和原 VoiceOver label/value。
- 新建纯 value `TacticalSelectionSummaryView`，显示 Selection 标识、selected summary，以及可选 stance、Radar upgrade、Extractor upgrade；不同语义同时使用不同图标和文字，不只依赖颜色。
- command dock header 组合 Selection Summary、现有 command status 和 selection mode，不新增状态。
- 状态栏、dock、六个 section、button styles、command status 和 Tactical Map chrome 消费共享 token；保持布局尺寸矩阵和 Tactical Map 手势。
- 两个新 Swift 文件必须显式加入 Xcode target。

## 非目标

- 不修改 controller/Core、action、disabled 条件、快捷键、战斗、AI、存档、SpriteKit 或 Web。
- 不引入渐变、装饰卡片堆叠、第三方图标、UIKit、timer 或网络依赖。
- 不运行任何本地测试、build、parse、Simulator、Preview 或浏览器验证。

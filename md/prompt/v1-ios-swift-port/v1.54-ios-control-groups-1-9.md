# v1.54 / iOS native control groups 1-9 HUD

## 目标

把 v1.52 已在 Swift core 支持的 1-9 号控制编队完整暴露到原生 iOS HUD。当前 iOS 只显示 1-3；v1.54 要让玩家可以在触屏 HUD 中保存和召回 1-9 号编队，进一步贴近 Web `Ctrl + 1-9` / `1-9` 的控制范围。

## 非目标

- 不实现外接键盘快捷键。
- 不改变 `GameState.controlGroups` 数据结构。
- 不改变 `GameEngine.storeControlGroup(_:)` / `recallControlGroup(_:)` 的语义。
- 不新增编队追加、toggle、remove 或队形保持。
- 不重做 HUD 导航、滚动容器或按钮体系。
- 不修改 Web `app.js` 行为。
- 不新增第三方依赖、后端、构建工具或网络依赖。
- 不用 `WKWebView` 包装 Web 版。

## 实现边界

- Core 已支持 slot `1...9`，本轮只需让 iOS 可见 slot 覆盖 1-9。
- Save / Recall 仍在执行前清除 Move / Attack / Build / Rally / Select Area 等等待命令。
- Recall 空组按钮继续禁用。
- Save 在当前无有效己方选择时继续禁用。
- 每个按钮保留 44x44 触摸目标、文本 label 和 VoiceOver hint/value。
- 保持 `LazyVGrid` 自适应布局，允许小屏换行；不为本轮引入横向滚动或新弹层。

## 建议改动

- `ios/RustwarIOS/RustwarIOS/GameController.swift`
  - 将 `visibleControlGroupSlots` 从 `[1, 2, 3]` 扩展到 `Array(1...9)`。
- `ios/RustwarIOS/RustwarIOS/GameHUDView.swift`
  - 继续从 `GameController.visibleControlGroupSlots` 渲染 Groups。
  - 如有必要，只做很小的 grid 尺寸调整；不要牺牲 44x44 按钮目标。
- `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift`
  - 增加一个 slot 9 store/recall 或 JSON roundtrip 断言，明确上界受保护。
- 文档同步：
  - `README.md` 写入 iOS Save / Group 1-9。
  - `md/flow/flow.md`、`md/flow/flowchart.md` 写入 iOS HUD 1-9。
  - `md/test/test.md` 写入 iOS HUD 1-9 基线。
  - `update_log.md` 追加 v1.54 记录。

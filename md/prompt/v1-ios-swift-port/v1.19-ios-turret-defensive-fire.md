# v1.19 / iOS native turret defensive fire MVP

## Agent B 任务

在原生 Swift/iOS 迁移地基中补齐最小炮塔防御火力。三张原生地图已经放置 enemy Turret，但当前建筑没有自动开火。目标是让完成状态的 Turret 能在射程内自动攻击敌方单位，复用现有伤害、死亡清理、残骸生成和 SpriteKit 战场反馈，形成可测试的防御建筑闭环。

## 背景依据

- Web 版炮塔、防空、激光防御等建筑是阵地防御核心。
- 原生 v1.3 已有单位基础攻击、伤害和死亡清理；v1.4-v1.18 已有红方生产、扩张和进攻 AI。
- 原生地图已有 enemy Turret，SpriteKit 会显示建筑和血条，但炮塔目前不会自动索敌、不会造成伤害，也没有建筑武器冷却状态。

## 目标

1. 在 `RustwarCore` 给建筑定义增加最小武器参数：
   - `attackRange`
   - `damage`
   - `reloadTime`
   - 非战斗建筑默认 0 或无效，不开火。
   - Turret 使用小步可测试数值，例如射程约 230、伤害约 28、装填约 1.2 秒。
2. 在 `BuildingSnapshot` 增加建筑武器冷却字段：
   - 建议 `weaponCooldown: Double = 0`。
   - 必须保持旧 JSON 兼容：旧存档缺少该字段时解码为 0。
3. 在 `GameEngine.update(deltaTime:)` 中推进建筑武器：
   - 只让 `hitPoints > 0`、`buildProgress >= 1`、`damage > 0`、`attackRange > 0` 的建筑开火。
   - 自动选择射程内最近敌方单位作为目标；本轮不要求攻击建筑目标。
   - 按 `weaponCooldown` / `reloadTime` 控制射速。
   - 命中后调用现有 `applyDamage`，死亡清理由现有 `removeDestroyedEntities()` 完成并生成残骸。
   - 未完成、摧毁、非战斗建筑不得开火。
4. iOS SpriteKit 战场反馈：
   - 可在炮塔冷却刚重置后短暂显示攻击线，或基于非零冷却显示一条淡红线到当前射程内最近敌方单位。
   - 不引入粒子系统或正式弹道。
5. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不迁移完整 Web 防御系统。
- 不做炮弹实体、命中延迟、范围伤害、防空、激光拦截、护盾、升级或目标优先级矩阵。
- 不让炮塔攻击空中/海军分类；当前原生还没有完整运动类型分类。
- 不新增玩家建造炮塔 UI。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不引入第三方依赖，不使用 `WKWebView`。

## 测试要求

Swift tests 至少覆盖：

- Turret 会攻击射程内敌方单位并降低 HP。
- Turret 有冷却，冷却未归零时不会连续每 tick 都造成伤害。
- 射程外单位不受伤。
- 未完成 Turret 不开火。
- 被摧毁 Turret 不开火。
- 非战斗建筑不自动开火。
- Turret 可摧毁单位，并通过现有清理生成残骸。
- `GameState` JSON 往返保留建筑 `weaponCooldown`。
- 旧 JSON 缺少 `weaponCooldown` 时可解码，默认值为 0。

本地轻量检查：

```sh
git diff --check
node --check app.js
swiftc -module-cache-path /private/tmp/rustwar-swift-module-cache-v119 -typecheck swift/RustwarCore/Sources/RustwarCore/*.swift

xcodebuild -list -project ios/RustwarIOS/RustwarIOS.xcodeproj
xcodebuild -project ios/RustwarIOS/RustwarIOS.xcodeproj -scheme RustwarIOS -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build
```

若本机 SwiftPM 或 Xcode 工具链阻塞，必须记录真实错误，并至少保留 `swiftc -typecheck` 结果。云端 GitHub Actions artifact 是最终验收依据。

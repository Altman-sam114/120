# v2.43.1 iOS artillery breech recoil-layer fix

## 背景

v2.43 把 Artillery 炮闩作为 presentation 细节加入 `unitBody`，但初始实现将炮闩挂到 `weaponMount`。`recoilMount` 会在开火时沿炮塔朝向产生后坐位移，因此炮闩必须与炮管共享该挂点，避免动态开火时两者脱节。

## 目标

1. 仅将 Artillery 炮闩从 `weaponMount` 移到同一单位的 `recoilMount`。
2. 同步流程图和版本记录，明确炮闩属于后坐层。
3. 保持炮塔 heading、炮管后坐、履带模型、命中、伤害、弹道、选择、雾、HUD、Core/JSON 和存档语义不变。

## 非目标

- 不新增动画、计时器、随机数、texture、shader 或第三方依赖。
- 不修改 `RustwarCore`、`GameController`、生产 fixture、地图、单位尺寸或节点数量策略。
- 不运行本地测试、格式检查、Swift/Xcode build、Simulator、Preview、截图或 `git diff --check`。

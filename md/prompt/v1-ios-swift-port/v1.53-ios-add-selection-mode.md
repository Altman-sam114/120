# v1.53 / iOS native Add Selection mode MVP

## 目标

把 Web 版 `Shift` 点选、框选和双击同类的追加选择语义迁移到原生 Swift/iOS。v1.53 做触屏 MVP：Swift core 增加可复用的 replace/add selection mutation；iOS HUD 增加 `Replace / Add` 选择模式分段控件；Add 模式下主战场 tap、Select Area、Same Type 和双击附近同类会把新命中的己方有效选择追加到当前多选集合。

## Web 对齐语义

- Web `selectEntities(entities, additive = false)` 在 additive=false 时清空后替换选择。
- Web Shift 点选、框选、双击同类使用 additive=true，只追加 union，不 toggle、不移除。
- Shift 点空地和 Shift 框空区域不会清空旧选择。
- 控制编队召回仍是替换选择，不受 Shift 追加影响。

## 非目标

- 不实现移除、反选、toggle selection。
- 不实现外接键盘 Shift 快捷键。
- 不把 Tactical Map 普通点按改成选择入口。
- 不迁移 Web 框选建筑 fallback；iOS Select Area 仍只框选己方单位。
- 不改变控制编队 Recall 的替换语义。
- 不修改 Web `app.js` 行为。
- 不新增第三方依赖、后端、构建工具或网络依赖。
- 不用 `WKWebView` 包装 Web 版。

## 实现边界

- `SelectionMutation.replace` 是默认行为，必须保持既有 API 和测试兼容。
- `SelectionMutation.add` 只把存活己方单位或建筑追加到当前有效选择，保持旧 primary，按现有顺序去重。
- Add 模式空输入不清空选择。
- 普通 tap 在 Add 模式下点敌方或空地不清空旧选择；Replace 模式保留当前可点选敌方/空地清空的旧行为。
- Same Type 和双击附近同类在 Add 模式下追加己方同类单位；无有效来源时保留旧选择。
- Idle Builders、Combat Units 和 Control Group Recall 本轮仍保持替换选择。

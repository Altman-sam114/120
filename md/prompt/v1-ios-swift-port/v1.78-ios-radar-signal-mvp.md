# v1.78 / iOS radar signal MVP

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.78。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

为原生 Swift core 和 iOS App 增加最小雷达信号地基，让当前不可见但处于玩家雷达范围内的敌方单位/建筑以“雷达接触点”显示，而不是完整显示真实实体。

验收语义：

- `BuildingDefinition` 应支持 `radarRange`，默认值为 `0`，只由完成状态、存活、同队建筑贡献。
- 本轮先给原生 Command Center 一个有限 `radarRange`，作为 Radar Station 建筑迁移前的 MVP 雷达来源；不要新增建造菜单、AI 建造或 Radar Station 建筑类型。
- `GameState` 应提供玩家可读的 radar contact snapshot：只包含敌方单位/建筑位置和轻量 kind 信息；排除当前可见敌方，排除死亡实体，排除己方实体。
- Radar contact 不应改变 `visibility(for:)`、`exploredVisibility(for:)`、`selectionTargetVisibleToPlayer`、`selectVisibleToPlayer` 或任何 Attack / Guard / Repair 命中合法性。
- iOS 主战场在 fog 层之上绘制雷达接触点：当前不可见但 radar 检测到的敌方显示青色脉冲/十字，不显示单位图标、建筑矩形、血条或选择轮廓。
- iOS 战术小地图同样绘制 radar contact 小点；当前可见敌方仍按真实敌方标记绘制。

## 非目标

- 不新增 Web 改动，不新增 Radar Station 原生建筑，不迁移升级，不修改建造菜单，不修改敌方 AI，不实现雷达范围 HUD 圈。
- 不显示雾内敌方类型、生命值、选择状态、攻击线或最后已知位置。
- 不允许玩家 tap、长按、Attack、Guard 或 Repair 精确命中 radar-only 敌方。
- 不改变 v1.77 explored fog memory 的存档形状和渲染语义。

## 实现建议

- `BuildingDefinition.swift` / `GameDefinitions.swift`
  - 为 `BuildingDefinition` 增加 `radarRange: Double = 0`。
  - 给 `.command` 设置 `radarRange`，范围可取 Web 雷达站 T1 的 `920` 或略小值；本轮建议 `920` 以匹配 Web 雷达站 T1 信号范围。
- 新增或扩展 core snapshot
  - 可新增 `RadarContactSnapshot.swift`，包含 `id`、`kind`、`team`、`position`，kind 至少区分 `.unit` / `.building`。
  - 在 `GameStateVisibility.swift` 增加 `radarContacts(for:) -> [RadarContactSnapshot]`。
  - 只扫描 `GameDefinitions.building(type).radarRange > 0` 的完成存活同队建筑作为 radar source。
  - 对敌方单位/建筑，若当前视野不可见但处于任一 radar source range 内，则返回 contact。
- `BattlefieldScene.swift`
  - `renderNow` 读取 `state.radarContacts(for: .player)`。
  - 在真实实体绘制后、fog 绘制后绘制 radar contact，确保信号可透过浅/深雾看见。
  - 单位 contact 比建筑 contact 小；都用青色描边和低透明填充，不显示真实图标。
- `TacticalMapView.swift`
  - Canvas snapshot 读取 radar contacts。
  - 在 fog 后、真实可见实体前或后绘制青色 radar 小点；避免遮住视口框和 pending command indicator。

## 测试

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加覆盖：

- Command Center definition 暴露非零 `radarRange`。
- 当前不可见但处于玩家 radar range 内的敌方单位会出现在 `radarContacts(for: .player)`。
- 当前可见敌方不会作为 radar contact 重复出现。
- 不在 radar range 内的不可见敌方不会出现。
- 未完成或已摧毁的 radar source 不贡献 contacts。

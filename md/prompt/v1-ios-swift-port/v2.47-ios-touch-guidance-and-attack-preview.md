## 目标

让原生 iOS 主战场更接近 Rusted Warfare 的低摩擦触控回路，并把关键意图直接呈现在 HUD/战场上：

1. 修复 context `DragGesture` 迟到/错序 `onEnded` 在起点差异超过容差时直接返回、遗留旧 context location 和 gesture lifecycle 的问题；旧 sequence 的结束回调只能 teardown，不能重新获得 long-press/tap/pan owner。
2. 修复 `SpatialEventGesture.onEnded` 对普通单指也推进 sequence、清空 touch ID 和 owner 的竞态；只有真实双指/多指序列才由该回调收尾。触点取消也必须同步取消 context owner，避免后续 context end 把取消触点写回 `.possible`。
3. 保持现有 `BattlefieldTouchIntent` 单一 owner、12pt 普通 pan 阈值、第二/第三指抢占、取消 epoch、pinch-only zoom、Select Area drag-end 独占提交和 pending command 优先级。
4. 当玩家有己方单位选择且没有离散 command status 时，在固定 dock header 显示简短高对比操作提示：点空地会 Attack-Move/自动接敌，点可见敌人会 Attack；两指同向拖动框选、拖动平移、捏合缩放也要有可访问文字提示。选中生产建筑时保留 Production / Factory Tech 的直接首屏，不额外插入会挤压生产卡片的 hint。
5. 进入显式 Attack target mode 时，在主战场只为 primary 已选己方作战单位绘制 presentation-only 攻击范围预览圈；预览位于实体和战争迷雾之下，不改 Core、命中半径、命令、存档或战斗数值。

## 非目标与不可改变的旧行为

- 不新增 Core/JSON/存档字段，不改变 `GameEngine` 命令、攻击姿态、自动索敌、真实视野、雷达、生产、升级或战斗数值。
- 不把普通 tap 改成 context command：无等待态下己方单位/建筑仍是选择；已有己方单位选择时，可见敌方 tap 仍直接 Attack，空地点按仍直接 Attack-Move；己方建筑仍强制 Replace 并立即派生 Production / Build & Upgrade dock。
- 不削弱或绕过 `battlefieldTouchSequenceCancelled`、被取消 Spatial ID 集合、context seed、第三指/cancel/ID replacement 拒绝。
- 不添加 UIKit、WKWebView、第三方依赖、纹理资源、随机数、timer、Task 或新的常驻战斗状态；继续使用 SwiftUI/SpriteKit 程序化 presentation。
- 保留用户未跟踪 `.wp`，不覆盖、回滚或删除其他用户/Agent 改动；不修改 Web 版。

## 预期改动

- `ios/RustwarIOS/RustwarIOS/BattlefieldView.swift`
  - 把 stale context end 视为当前/旧序列的取消收尾：清理 context location、start/end 时间、sequence/generation；若仍属于当前 touch sequence，保持 `.cancelled`、清理 active owner 并推进 sequence，确保下一次 fresh touch 可正常 seed。旧 sequence 只 teardown，不修改当前 owner。
  - 普通单指的 `SpatialEventGesture.onEnded` 不得推进 sequence 或清空 `battlefieldTouchID`；只有真实多指序列才由 `finishMultitouchSelection` 收尾。
  - Spatial touch cancel 要同步标记 context cancelled；tap/long press 需拒绝 cancelled epoch 和不匹配的 context sequence。
  - 保持 area selection 活动起点由 drag end 独占；stale context end 不提交区域选择，也不清除有效 area preview。
- `ios/RustwarIOS/RustwarIOS/GameController.swift`
  - 暴露纯派生的 battlefield interaction hint 文案/图标，不添加第二套输入状态；hint 必须按 pending command、己方单位、生产建筑、普通选择/无选择优先级生成。

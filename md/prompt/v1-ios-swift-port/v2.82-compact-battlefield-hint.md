# v2.82 原生 iOS 紧凑战场提示层级

## 轮次定位

- 版本：`v2.82`
- 基线：`origin/main` 的 `5076a5fd9c16a3d831c46af17b8274e9d13da192`（v2.81 文档验收记录）
- 目标：借鉴 Rusted Warfare 移动端“选中后立即发令”的清晰节奏，在普通 compact dock 中缩短视觉触控提示，让高频 Quick Orders 更早进入首屏，同时保留完整辅助功能说明。

## 目标

1. 普通 compact（`compactTrailing` / `compactBottom`，非 accessibility Dynamic Type）下，`TacticalBattlefieldHintView` 显示短的可见触控说明，最多两行的紧凑语义：
   - 无选择：提示点选、拖动平移、双指框选/捏合缩放；
   - 选中单位：提示点敌人攻击、点空地移动或 Attack-Move；
   - 等待目标：提示当前应点击的目标或位置；
   - 等待区域选择：提示拖动框选。
2. 完整的 `battlefieldInteractionHintDetail` 继续作为 VoiceOver 的 `.accessibilityValue`，不因为视觉短文案而丢失双指框选、拖动平移、捏合缩放、Attack-Move 或生产提示语义。
3. regular trailing、accessibility Dynamic Type 和所有非 compact 路径继续显示完整可见文案；不通过缩小字体、隐藏控件或改变 dock breakpoint 换空间。
4. 普通 compact Combat 首屏中，Selection / target guidance、Quick Orders 的 Move / A-Move / Attack / Stop 以及 Commands 的既有顺序更早可见；按钮 action、Cancel 状态和快捷键保持。
5. 生产建筑场景继续由 compact producer header 直接提供 Production / 建筑 / 科技 / 速度和既有生产内容；本轮不改变生产排序或生产控件。

## 实现要求

### Presentation 与语义分离

- 在 `GameController` 增加只读 presentation 派生值（推荐命名 `battlefieldInteractionHintCompactDetail`），按现有 hint 状态返回短视觉文案；不得新增可变状态、Core 字段或存档字段。
- `TacticalCommandDockView` 使用现有 `isCompactNormalContext` 作为单一 compact gate，并把 gate 传给 `TacticalCommandDockHeaderView`；不要在多个 View 中复制不同的 Dynamic Type / layout 判断。
- `TacticalCommandDockHeaderView` 只在既有 `shouldShowBattlefieldInteractionHint` 且 `commandStatus == nil` 时显示提示；等待态 CommandStatus、Selection summary、Production header、Quick Orders 上下顺序保持。
- `TacticalBattlefieldHintView` 可接收可见短文案和完整 spoken detail：普通 compact 使用短文案渲染，`.accessibilityValue` 始终读取完整 detail；regular/accessibility 传入完整 detail作为可见文案。
- 短文案不得使用颜色作为唯一状态编码，不得依赖截断来“压缩”；通过稳定短语和已有 `.caption` 层级控制高度。

### 必须保持

- `battlefieldInteractionHintTitle`、system image、完整 detail 的状态优先级保持：Area、Attack target、Move target、Attack-move target、Factory、selected units、selection ready、default。
- Quick Orders 的 Move / A-Move / Attack / Stop 顺序、44pt 最小触控尺寸、Cancel / waiting 状态、A/S 快捷键、VoiceOver label/value/hint 保持。
- Selection mode Replace/Add、Selection summary、target mode attention border、Tactical Map、生产管理 rail、NOW/QUEUE/UPGRADE、Factory Tech、生产卡、队列、升级、Rally、Core、存档/JSON、战斗模型、特效、触控 owner 和 Web 版不变。
- `TacticalBattlefieldHintView` 继续是独立可访问元素，`.accessibilityLabel` 保持标题，`.accessibilityValue` 为完整说明，`.accessibilityHint` 继续说明这是 battlefield touch controls。

## 非目标与证据边界

- 不在本轮收敛 `SpatialTapGesture`、零距离 `DragGesture`、pan gesture 或 `TouchSequenceOwner`；单指 gesture 路由死区作为下一轮专门任务。
- 不改 `TacticalHUDLayoutMetrics`、dock 宽高、字体大小、控件最小高度、滚动策略或 fixture。
- 不声称固定 PNG 证明真实 VoiceOver、Dynamic Type、滚动、点击、双指框选、真机触控手感或所有设备尺寸；这些仍是源码合同和后续真机/XCUITest 证据边界。

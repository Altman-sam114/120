# v2.6 / iOS command confirmation contrast

## 版本

- 版本号：`v2.6`
- 分配依据：Agent A 自动递增；接续 v2.5 后收紧命令确认落点可见度。

## 目标

1. 主战场与 Tactical Map 的 command confirmation 标记更高对比：更大外环、更粗描边、更明显填充，Reduce Motion 仍短淡出。
2. 不改 `CommandConfirmation` 事件模型、kind 语义、可见性门控。
3. 云端 v1.2 visual smoke 验收（首屏通常无 marker，靠编译 + 代码路径）。

## 非目标

- 不改 Core 命令、AI、存档、Web、HUD layout metrics。
- 不跑本机 Xcode/Simulator。

## 实现

1. `BattlefieldScene.showCommandConfirmationIfNeeded`：双环/更粗线宽/更高透明度，保持 zoom-inverse 缩放。
2. `TacticalMapView.drawCommandConfirmation`：更大半径、双环、更粗 stroke。
3. 文档同步。

## 验收

- CI success；`CommandConfirmation` 相关文件进入 arm64/x86_64 编译。
- 不改变 revision/visibility/kind 行为。

# v1.91 / iOS layered combat effects

## 基线与目标

本轮基于已通过最新云端 artifact 验收的 v1.90 `main`，继续改善原生 iOS 战场表现。Steam 官方 Rusted Warfare 页面提供 10 张战场截图和 2 段视频；可见的核心视觉语言是短促高亮弹道、武器颜色区分、炮口焰、多层爆炸、烟尘和地面灼痕共同构成战斗反馈。只分析并借鉴这种信息层级，不复制、下载到仓库或提交原作素材。

当前 `BattlefieldScene` 已能根据 cooldown/HP 跃迁生成简单圆形炮口闪光、弹丸和受击圆环，但不同武器仍接近同一种表现，实体摧毁没有独立爆炸和地表反馈。本轮在不新增 Core projectile/event 模型的前提下，把现有只读快照反馈升级为有界、雾约束、Reduce Motion 兼容的分层战斗特效。

## 实现要求

1. `GameState` 继续是唯一玩法事实来源；Scene 只比较连续快照，不推进伤害、弹道、命中或死亡模拟。
2. 保留 cooldown 上跳门控，同一快照重复 `renderNow()` 不得重复生成开火效果。
3. 为 7 类单位和 Turret 建立可辨识武器反馈：至少区分轻型 tracer、坦克炮弹、Hover 青色能量束、AA 双联弹道、Artillery 重炮弹与 Gunboat 炮弹；颜色、尺寸、尾迹和持续时间可以不同，但不能改变攻击结果。
4. 显式 Attack 目标和自动索敌目标都只能从当前玩家可见实体中取得；不可见目标时只允许源点炮口反馈，禁止跨雾绘制精确弹道或目标闪光。
5. HP 下降生成多层受击反馈：高亮核心、扩散环和少量确定性火花/烟尘；不得使用随机数、无限粒子或 Core Image filter。
6. 连续快照中实体消失时，仅在玩家实体或当前位置仍属于玩家当前可见 tile 时生成摧毁反馈；地图切换、Restart、Load 的既有 history reset 不得误报整图爆炸。
7. 摧毁反馈按单位/建筑尺寸产生更强的火球、冲击环、碎片和烟尘，并在地表留下短寿命灼痕；灼痕位于实体下、地形上，并由 fog 覆盖。
8. 瞬态 effect 与 decal 都必须有顶层节点硬上限和自动移除时间，避免大规模战斗无限增长；超过上限时优先移除最旧节点。
9. `accessibilityReduceMotion` 开启时清理正在播放的大幅移动效果，弹道不跨屏移动，爆炸/受击只保留短透明度反馈；静态短寿命灼痕可以保留。
10. `effectNode` 和 decal 层必须继续位于 `fogNode` / `radarNode` 下方，不能泄露浅雾或深雾中的精确敌方位置。

## 性能与视觉边界

- 不新增每帧全图扫描之外的高阶复杂度；实体历史使用 id 字典，死亡检测使用当前/上一帧 id 集合。
- 每个触发事件只创建一个有界顶层容器；容器内部只使用少量 `SKShapeNode` 和有限 `SKAction`。
- 不使用 `SKEmitterNode` 无限粒子、动态 shader、blur、shadow filter 或每帧纹理生成。
- 火焰、烟尘和光束的亮度必须高于地形细节但低于选择环和 HUD，不遮住 HP/进度条与命令线。
- 颜色之外还要通过双联、尾迹、光束、尺寸和冲击波轮廓区分武器，兼顾 Differentiate Without Color。

## 必须保持

- v1.88 的单位/建筑程序化剪影、朝向、阵营非颜色标识与可见性过滤。
- v1.89 的 safe-area HUD、响应式 command dock、Tactical Map 避让和全部输入。
- v1.90 的聚合地形节点、材质边界和地图重建性能。
- Core 数值、战斗 tick、命令、AI、雾、雷达、存档和三张地图状态完全不变。
- Web 版直接打开 `index.html` 可运行。

## 验收标准

1. 不同单位武器不再只有同构圆点，至少有 tracer/beam/heavy shell/twin shot 的几何差异。
2. 受击具有核心、冲击环和受限火花/烟尘，摧毁具有更强爆炸和灼痕。
3. map revision reset 不触发死亡爆炸；重复 render 不重复生成 cooldown/HP 效果。
4. 所有精确弹道、受击和死亡效果都符合当前可见性边界，并被 fog 覆盖。
5. Reduce Motion 下没有跨屏弹丸、扩张冲击波或碎片飞散，只保留短透明度反馈。
6. active effect 和 decal 节点数量有固定上限，生命周期结束后自动清理。
7. Swift Core、HUD、Tactical Map、Web、资源和 Xcode project 无 diff。
8. Swift parse 和云端 iOS build 通过；若本机只有 Command Line Tools，记录原始阻塞并由最新 Actions artifact 复验。

有完整 Xcode/Simulator 时，额外观察 Coast / Islands / Lava 的小规模与密集战斗：单位类型能从弹道区分、爆炸不遮挡选择/HP、灼痕不压过地形、地图切换和 Load 不残留旧效果。环境不可用时明确记录未运行视觉 smoke、像素对比和性能采样。

# v1.29 / iOS native enemy Land Factory build MVP

## 角色

本提示词交给 Agent B 执行。Agent B 必须遵守 `AGENTS.md` 的 main 直推、轻量本地检查、GitHub Actions artifact 和 Agent C 复判流程。

## 背景

v1.27 已让玩家 Builder 可以建造未完成 Land Factory，v1.28 已把原生 Land Factory T1 生产列表扩展为 Scout / Light Tank / Hover Tank / Artillery / AA Tank。当前红方 AI 会用 Builder 建造 Extractor、用已有 Land Factory 生产单位并进攻，但不会补建或扩建 Land Factory。Web 版红方 AI 已具备建厂扩张方向，原生 iOS 迁移应补一个最小、可测试的红方建厂 MVP。

## 目标

- 在 `RustwarCore` 的红方 AI 中新增 Land Factory 建造 MVP。
- 当红方有空闲 Builder、金属足够、Land Factory 数量未达小上限、且能找到合法陆地点时，AI 应创建未完成的 enemy Land Factory，并给该 Builder 写入 `.build(targetID:)`。
- 新建 enemy Land Factory 必须复用现有点位建筑创建语义：扣除金属、`buildProgress = 0`、初始 HP 为 10%、`nodeID = nil`、`rally = position`。
- 未完成 enemy Land Factory 必须继续受现有完成度门控保护：不能生产、不能推进遗留生产队列；完成后才能被现有 enemy production AI 使用。
- 不得改变玩家当前选择。
- 同步 README、flow、flowchart、test 和 update_log。

## 非目标

- 不新增玩家 UI、SwiftUI HUD 按钮或战术小地图交互。
- 不修改 Web `index.html` / `styles.css` / `app.js`。
- 不新增 Fabricator、Command Center 生产 Builder、红方 Turret 建造、取消未完成建筑退款、建造幽灵、多 Builder 协同或完整 Web AI parity。
- 不引入新框架、后端、网络依赖或 WKWebView。

## 建议实现

- 修改 `swift/RustwarCore/Sources/RustwarCore/GameEngine.swift`。
- 在 `updateEnemyAI()` 里保留现有顺序，但让红方 AI 在 Extractor 扩张之后、生产/进攻之前尝试 Land Factory 建造。
- 新增私有 helper，例如：
  - 统计 enemy 存活 Land Factory 数量，包含未完成建筑，避免重复堆叠。
  - 检查 enemy 金属是否至少达到 `GameDefinitions.building(.landFactory).metalCost`。
  - 查找空闲 enemy Builder。
  - 在 enemy command / enemy builder / enemy base 周边用确定性候选点搜索 `canPlaceBuilding(.landFactory, at:)`。
  - 成功后调用现有 `startPointBuildingBuild(.landFactory, builderIndex:position:)`。
- 建议设置小上限为 2 座 enemy Land Factory，保持 MVP 小范围且避免过快刷工厂。
- 候选点搜索必须确定性，不要用随机数；如果没有合法点，AI 不应扣资源、不应改 Builder order。

## 测试要求

在 `swift/RustwarCore/Tests/RustwarCoreTests/RustwarCoreTests.swift` 增加 Swift tests，至少覆盖：

- enemy AI 在没有足够 Land Factory、金属足够、Builder 空闲、有合法点时建造未完成 Land Factory，并不改变玩家选择。
- 新建 enemy Land Factory 进入 `.build` 订单，扣除 enemy 金属，初始进度和 HP 正确，`nodeID == nil`，`rally == position`。
- 未完成 enemy Land Factory 不生产；完成后现有 enemy production AI 能从它排队造兵。
- AI 在金属不足、Builder 忙、Land Factory 数量达到上限或无合法点时不建厂。

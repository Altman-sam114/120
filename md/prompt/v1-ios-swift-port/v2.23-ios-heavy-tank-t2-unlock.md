# v2.23 iOS Heavy Tank T2 unlock

## 目标

- 为原生 Swift/iOS Land Factory T2 增加首个专属单位 `Heavy Tank`，让 v2.22 的工厂升级产生明确的新战斗能力。
- Heavy Tank 必须具有独立的核心数值、生产门槛、程序化履带模型、炮塔转向/后坐和重炮弹道，不得只是 Light Tank 改名或放大。
- 生产面板只在选中已完成 T2 Land Factory 时显示 Heavy Tank；T1 直接下单和 Repeat 都必须拒绝。
- 云端 production fixture 展示 T2 工厂、Heavy Tank 队列和完整四项队列；combat fixture 展示 Heavy Tank 模型与冻结重炮弹道。

## 非目标

- 不增加 T3、空军工厂、护盾、范围伤害、Core projectile entity、音效、震屏或外部 sprite/模型资源。
- 不改变 Web 原型、现有存档版本、现有 T1 单位数值、玩家输入语义或工厂升级费用。
- 不让敌方 AI 自动升级工厂；敌方 T1 工厂不得绕过门槛生产 Heavy Tank。

## 实现边界

- `UnitType` 新增 `.heavyTank`；`UnitDefinition` 新增向后兼容默认值为 1 的 `requiredProducerUpgradeLevel`。
- `GameDefinitions` 定义 Heavy Tank，并提供按建筑快照过滤的可生产单位 helper。Land Factory 的完整产品表保留 T1 顺序，并将 Heavy Tank 放在末尾。
- `GameEngine` 的玩家 queue、Repeat 和敌方生产候选都必须使用同一 tech gate；既有队列完成、退款、supply 和存档语义保持。
- SwiftUI 生产图标与两行短标签必须完整；SpriteKit 新模型需有宽履带、厚重分层车体、独立低矮炮塔、长炮管/炮口制退器、阵营标记，并接入现有转向、后坐、开火、impact 和 typed wreck 路径。
- 更新 `README.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 建议数值

- Heavy Tank：520 HP、19 radius、48 speed、300 vision、4 supply、420 metal、14 秒基础建造时间、205 range、82 damage、1.75 秒 reload、需要 producer T2。
- T2 1.25x 生产倍率下新排队 Heavy Tank 的捕获时间为 11.2 秒。

## 验收标准

- T1 Land Factory 不暴露 Heavy Tank，直接 queue / Repeat 均拒绝；T2 暴露并可排队、扣费、捕获 11.2 秒 buildTime、完成后生成正确单位。
- 全部 `UnitType` switch 完整，旧 JSON 不受新增 definition 字段影响。
- production PNG 清楚显示 T2/MAX TECH、Heavy Tank 队首和四项完整队列；combat PNG 清楚显示 Heavy Tank 模型和重炮弹道，且 HUD、战术地图、既有阵型无重叠回退。
- 按用户制度禁止本地测试、build、Simulator、Preview、截图、浏览器游戏验证和测试脚本。
- Agent B 只提交本轮相关文件到 `main`，确认目标为 `origin/main` 后直接 push。
- GitHub Actions 必须生成未加密结果包；Agent C 只下载最新 `origin/main` commit 对应 artifact，并核对 manifest、JUnit、build log、failure summary、双截图指标与双 PNG。

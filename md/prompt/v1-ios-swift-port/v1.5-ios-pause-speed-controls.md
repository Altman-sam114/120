# v1.5 / iOS native pause and speed controls

## Agent A brief

Version: `v1.5`

Goal: add native iOS simulation pause and speed controls so the SwiftUI/SpriteKit app can stop or accelerate the `RustwarCore` simulation after v1.4 enemy AI starts producing and attacking. The control must be native SwiftUI state, not a Web wrapper.

## Background

- Web Rustwar already supports pause and speed changes.
- iOS currently advances `GameEngine` every SpriteKit frame through `GameController.advance(deltaTime:)`.
- v1.4 made enemy AI active by default, so the player needs a basic way to pause the native match and inspect or resume it.

## Scope

Touch only the files needed for this small iOS control increment:

- `ios/RustwarIOS/RustwarIOS/GameController.swift`
- `ios/RustwarIOS/RustwarIOS/GameHUDView.swift`
- `README.md`
- `md/flow/flow.md`
- `md/flow/flowchart.md`
- `md/test/test.md` only if validation wording changes
- `update_log.md`

Do not change `app.js`, `index.html`, or `styles.css`.

## Functional requirements

1. Add `isPaused` state to `GameController`.
2. Add simulation speed state to `GameController`, with a small fixed set of native speeds such as `0.5x`, `1x`, and `2x`.
3. `advance(deltaTime:)` must:
   - keep clamping unsafe deltas;
   - return without calling `engine.update` while paused;
   - multiply the clamped delta by the selected speed while running;
   - still update rendering state enough for HUD controls and camera interactions to remain responsive.
4. Add HUD controls:
   - a Pause/Play button with system icon and accessible text label;
   - a compact speed control using the fixed speed set;
   - controls must fit alongside the existing Reset / Move / Attack controls without overlapping on small screens.
5. Changing pause or speed must cancel pending Move/Attack target modes only if needed for clarity; if not needed, preserve pending command modes.
6. Reset camera must keep its current behavior; this round is not a map restart feature.

## Non-goals

- No Web gameplay changes.
- No new Xcode target, package dependency, UIKit wrapper, or `WKWebView`.
- No map switching, minimap, save/load, stop command, rally command, or production cancel in this round.
- No full game balance changes.

## SwiftUI guidance

- Keep shared state in the existing `@MainActor @Observable GameController`.
- Use native SwiftUI `Button` and `Picker`/segmented control style where practical.
- Use text-bearing `Button(_:systemImage:action:)` labels for accessibility.
- Keep 44 pt minimum touch targets.
- Avoid hard-coded small fonts beyond the existing HUD style.

## Expected behavior

- While paused, metal totals, production progress, enemy AI orders, unit positions, combat damage, and deaths do not advance.
- While running at `0.5x`, simulation advances slower than default.
- While running at `2x`, simulation advances faster than default.
- Camera pan/zoom, selection, HUD state, and render refresh remain usable while paused.
- The Web prototype remains directly openable through `index.html`.

# v1.72 / iOS tactical map visibility

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.72。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

在 v1.70 玩家当前视野 tile 和 v1.71 主战场隐藏不可见敌方实体的基础上，把同一视野规则扩展到原生 iOS 战术小地图。

- 战术小地图不再绘制当前玩家视野外的敌方单位和敌方建筑。
- 己方单位和建筑仍始终绘制，选择高亮、相机中心和等待命令角标保持可见。
- 战术小地图绘制轻量当前视野雾层，覆盖不可见 tile，避免小地图继续呈现为全图情报视图。
- 小地图点按命令、主战场雾层、SpriteKit 主战场实体过滤和 core `GameState.visibility(for:)` 语义保持不变。

## 非目标

- 不修改 Web `app.js`。
- 不实现已探索记忆、雷达信号、雷达点、雾内点选/命中限制、AI 情报限制、弹道/粒子隐藏或存档 explored grid。
- 不改变 `GameState`、`VisibilitySnapshot`、命令、选择、多选、控制编队、保存读取或敌方 AI 状态形状。
- 不新增 iOS HUD 按钮，不改变战术小地图点按下令语义；本轮只改变小地图渲染可见性。

## 实现建议

- `ios/RustwarIOS/RustwarIOS/TacticalMapView.swift`
  - 在 `body` 中从 `state.visibility(for: .player)` 取得 `VisibilitySnapshot`，传入 `drawMap`。
  - 为单位和建筑增加私有 helper，例如 `isVisibleToPlayer(_:visibility:)`：己方直接 true，敌方需要 `visibility.isVisible(at: position)`。
  - 绘制建筑和单位时用 helper 过滤敌方实体；己方选择高亮不受影响。
  - 增加 `drawFog(_:in:size:)`，按 `VisibilitySnapshot` 的 rows/columns 将不可见 tile 映射到小地图坐标，用单个 `Path` 或轻量批处理绘制暗色覆盖层。
  - 保持 `drawCameraCenter` 和 `drawPendingCommandIndicator` 在雾层之后绘制，确保操作反馈不会被遮挡。

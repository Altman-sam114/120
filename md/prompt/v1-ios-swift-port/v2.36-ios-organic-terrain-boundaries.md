# v2.36 iOS organic terrain boundaries

## 目标

消除 v2.35 云端 PNG 中 dirt/sand/rock patch、海岸和深浅水仍沿完整水平/垂直 tile edge 排列的原型感；只在 SpriteKit 表现层生成连续、有机且可复现的材质边界。

## 实现

- 保留原 tile edge 端点，用稳定 hash 为两个三次曲线控制点生成最多 2.6 world pt 的法向偏移。
- 不同 land surface family 按 grass < dirt < sand < rock 选择覆盖材质，先画 8.5pt 同材质底带遮住原接缝，再画 1.15pt 极低对比 accent。
- coast、water/deep 和 lava bank 复用同一曲线 helper，并使用 6.5-7pt 实色底带保证原直线不会从曲线旁露出，同时避免 round cap 透明叠色圆点。
- 所有 land boundary 按 family 聚合为固定 compound path；coast/depth/lava 继续各用固定 path，不创建逐 edge node。

## 非目标

- 不修改 Core tile、地图生成、通行、建造、命中、AI、战斗、雾、存档、Web 或 Tactical Map 数据。
- 不新增 texture、shader、随机状态、动画、timer、Task、依赖或每 tile/edge SpriteKit node。
- 不宣称固定 Coast PNG 已覆盖 Islands、Lava、全部 zoom 或真机 scale。

- 只提交本轮 SpriteKit 源码、提示词和同步文档，直接 push `origin/main`。

- Home/Combat 必须与 v2.35 并排复看：主要 dirt/grass 与水岸边界不再是完整直角折线，曲线连接无裂缝/尖刺；绿色棋盘、水面 hairline、HUD、模型、选择和战斗效果不得回退。

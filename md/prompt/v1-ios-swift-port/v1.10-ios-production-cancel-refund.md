# v1.10 / iOS native production cancel and refund

## Agent A brief

Version: `v1.10`

Goal: add a native iOS production cancel command so the SwiftUI/SpriteKit app can cancel the selected player factory's last queued production item through `RustwarCore` and refund metal based on unfinished progress.

## Background

- Web Rustwar already supports cancelling production and refunding part of the resource cost.
- Native iOS production currently supports queueing Scout / Light Tank from a selected player land factory.
- `ProductionQueueItem` already stores `unitType`, `progress`, and `buildTime`.
- `GameEngine.updateProduction(deltaTime:)` advances only the front queue item and removes it when complete.
- v1.9 added factory Rally; this round should only fill the next production-control gap.

## Functional requirements

1. Add a public `GameEngine.cancelLastProduction()` command that:
   - requires an active selection;
   - only succeeds for selected player buildings that can produce units;
   - cancels the selected building's last queued `ProductionQueueItem`;
   - refunds metal to the building's team using `unit.metalCost * (1 - item.progressFraction)`;
   - leaves the current selection unchanged;
   - does not refund a completed item that has already been removed by `updateProduction`;
   - does not move units, alter rally points, or affect other factories.
2. Add a dedicated `ProductionCancelResult` enum with:
   - cancelled result carrying refunded metal;
   - no selection;
   - selected building cannot cancel production;
   - empty queue.
3. Add Swift tests covering:
   - no selection rejection;
   - selected player unit rejection;
   - selected non-producer building rejection;
   - selected enemy producer rejection;
   - empty queue rejection without metal changes;
   - cancelling a partially progressed single queue item refunds only unfinished metal, clears the queue, preserves selection, and does not spawn after later updates;
   - cancelling the last item in a multi-item queue preserves the front item and its progress;
   - cancelling releases queued supply so a later queue request can succeed.
4. Add native iOS controller support:
   - expose whether production can currently be cancelled;
   - add a `cancelProduction()` action that calls `engine.cancelLastProduction()`;
   - set concise status text including refunded metal for successful cancellation;
   - increment `renderRevision`.
5. Add a native HUD `Cancel Production` button near the queue summary when the selected player producer has at least one queued item.
6. Preserve existing Move, Attack, Stop, Rally, queue unit, enemy AI, map switch/restart, pause/speed, tactical minimap, and camera controls.

## Non-goals

- No Web behavior change.
- No `WKWebView`.
- No cancelling arbitrary queue indices.
- No repeat production toggle.
- No multi-factory queue panel.
- No production pause.
- No build queue UI redesign.
- No save/load, fog, sandbox, or browser regression.
- No new third-party dependency or build system.

## SwiftUI guidance

- Keep shared state in `@MainActor @Observable GameController`.
- Use a text-labeled SwiftUI button, for example `Button("Cancel Production", systemImage: "minus.circle", action: controller.cancelProduction)`.
- Keep the 44 pt minimum tap target and a clear accessibility label.
- Keep command logic in `GameController` / `RustwarCore`, not inline in `GameHUDView.body`.

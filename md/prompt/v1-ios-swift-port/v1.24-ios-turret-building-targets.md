# v1.24 / iOS native turret building targets

## Agent B 任务

在 v1.19 原生 Turret 自动防御开火 MVP 基础上，补齐炮塔攻击敌方建筑的最小 gameplay parity：完成状态 Turret 不再只扫描射程内敌方单位，也应能攻击射程内敌方建筑，并继续复用现有伤害、死亡清理、残骸生成和 SpriteKit 火力线显示。

## 背景依据

- v1.19 已让 `BuildingDefinition` 保存建筑武器参数，并让完成状态 Turret 自动攻击射程内敌方单位。
- v1.19 遗留事项明确仍无“炮塔攻击建筑”。
- `GameEngine.applyDamage(_:,to:)`、`combatTarget(id:)` 和 `removeDestroyedEntities()` 已支持建筑受伤、摧毁、残骸生成和资源点释放。
- SpriteKit `BattlefieldScene` 当前火力线目标查找也只扫描单位，需要与 core 行为同步。

## 目标

1. 扩展 `GameEngine.nearestBuildingWeaponTarget(for:definition:)`：
   - 保持完成状态、冷却、武器参数门控不变。
   - 扫描敌方单位和敌方建筑。
   - 用现有半径/尺寸计算有效射程。
   - 选择射程内最近目标。
2. 扩展 `BattlefieldScene.nearestBuildingWeaponTargetPosition(for:definition:in:)`：
   - 火力线能指向炮塔实际可能攻击的敌方单位或建筑。
   - 不新增弹丸、范围伤害或目标锁定状态。
3. 补 Swift tests：
   - Turret 能伤害射程内敌方建筑并进入冷却。
   - Turret 在单位和建筑都在射程内时选择最近目标。
   - Turret 摧毁建筑后生成建筑残骸并移除目标。
4. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不新增炮弹实体、范围伤害、溅射、防空、激光拦截、护盾、升级或目标优先级矩阵。
- 不改变单位攻击目标规则、AI 战术或 Builder 建造/维修/回收规则。
- 不新增 iOS UI 自动化测试。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不引入第三方依赖，不使用 `WKWebView`。

# v1.50 / iOS native same-type selection

## Agent B 任务

在原生 Swift/iOS 迁移地基中新增 `Same Type` 选择能力，使 iOS 版继续靠近 Web RTS 的 Alt+A / 同类选择操作。

本轮按 v1.50 执行，提交信息使用：

```text
v1.50: add iOS same-type selection
```

## 目标

- 在 `RustwarCore` 增加“按当前选择的己方单位类型选择所有同类型己方单位”的 API。
- 在 iOS HUD 增加 `Same Type` 控制。
- 选中一个己方单位后，点按 `Same Type` 会选择全图所有同类型己方单位。
- 多选时以当前 primary selection 或当前选择集合中的第一个己方单位作为类型来源。
- 同类型选择结果必须同步 `selectedEntityIDs` 和 `selectedEntityID`，继续复用现有多单位 Move / Stop / Attack / Attack Move / Patrol / Guard / Builder 命令。

## 非目标

- 不修改 Web `app.js`。
- 不实现 iOS 双击同类选择、附近半径同类选择、Shift 追加/反选或控制编队。
- 不选择敌方单位、建筑、残骸或资源点。
- 不新增第三方依赖、后端、构建链或资源文件。
- 不改变 Select Area、Idle Builders、Combat Units、普通 tap 选择或拖拽平移语义。

## 建议实现方案

### Swift core

在 `GameStateSelection.swift` 增加：

- `func playerUnitSelectionTargets(matching type: UnitType) -> [SelectionTarget]`
- 按 `state.units` 顺序返回所有 `team == .player`、`hitPoints > 0`、`type == type` 的单位。

在 `GameEngine.swift` 增加：

- `@discardableResult public mutating func selectPlayerUnitsMatchingPrimarySelection() -> [String]`
- 类型来源优先使用 `state.selectedEntityID` 指向的己方单位。
- 若 primary 不是己方单位，则从 `selectedEntityIDs` 中按顺序找第一个己方单位。
- 若没有可用己方单位类型，返回 `[]`，并清空选择以匹配 Web Alt+A 无可选同类时的“没有可选择”语义。
- 找到类型后，选择全图所有该类型己方存活单位，写入 `state.selectedEntityIDs`，`state.selectedEntityID = ids.first`，返回 IDs。

### iOS controller/HUD

在 `GameController.swift` 增加：

- `var canSelectSameTypeUnits: Bool`
- `var sameTypeUnitsButtonTitle: String`，例如 `Same Type` 或 `Same Scout (3)`；保持短文本，避免 HUD 挤压。
- `func selectSameTypeUnits()`：调用 core API，设置 `commandStatus` 为 `"\(count) \(unitName) selected"` 或 `"No same-type units"`，并递增 `renderRevision`。
- 执行同类型选择前调用 `clearPendingTargetCommands()`，避免 Move/Attack/Build/Select Area 等等待态残留。

在 `GameHUDView.swift` 中：

- 推荐把按钮放在 Idle Builders / Combat Units / Select Area 同一组附近。
- 使用 `Button(..., systemImage: ..., action: controller.selectSameTypeUnits)`，保留 VoiceOver 文本。
- 按钮在没有当前己方单位类型时 disabled 或隐藏；推荐 disabled，保持选择工具稳定可发现。
- 添加 accessibility label/hint，例如 “Select same type” / “Selects all player units matching the current selected unit type.”

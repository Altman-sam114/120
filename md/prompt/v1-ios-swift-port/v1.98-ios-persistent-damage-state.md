# v1.98 / iOS persistent damage state

## 目标

参考 Rusted Warfare 官方 Steam 战斗截图中可远距识别的持续黑烟和危急火点，为原生 SpriteKit 单位与完成状态建筑增加分级损伤外观。

## 实现要求

- 只修改 presentation layer；从当前 `hitPoints/maxHitPoints` snapshot 派生，不修改 Core、战斗数值、AI、命令、存档或 Web。
- HP 低于 55% 显示紧凑烟柱；HP 低于 25% 叠加独立火焰形状并加重烟柱。
- 单位和完成状态建筑复用同一 helper；施工中建筑跳过，避免把施工进度误表现为战损。
- 每个受损实体最多两个额外 compound path 节点；禁止 timer、随机数、每实体 emitter、常驻 SKAction 或新的全局状态。
- 继续依赖既有 `drawEntities` visibility filter；不得让雾外敌方留下烟火情报。
- 颜色不能是唯一差异：受损和危急状态必须通过烟柱数量与火焰几何区分。

## 非目标

- 不新增正式 sprite atlas、音效、粒子贴图、damage event model 或 Core projectile。
- 不重构实体 renderer，不改变瞬态效果 64 节点与 decal 32 节点上限。
- 不运行本地测试、build、parse、Simulator、Preview 或浏览器验证。

# v1.92 / iOS short landscape tactical layout

## 基线与证据

本轮基于已通过最新 `origin/main` artifact 验收的 v1.91。使用 Xcode 26.6 在独立 iPhone 17 Pro、iOS 26.5 Simulator 启动真实原生 App，并保存首屏截图到 `/private/tmp/rustwar-v191-iphone17pro-initial.png`。设备可用容器约为 874x402pt；当前 `TacticalHUDLayoutRole` 只先判断 `width >= 700`，因此把短高度手机横屏误判为 `.regularTrailing`。

真实截图显示：320pt regular command dock、176x118 Tactical Map 和双列命令按钮同时占用，使战场只剩约六成横向空间，`Idle Builders`、`Combat Units` 等按钮标题出现截断。Rusted Warfare 的移动端战场优先保留大视野，命令区应紧凑、持续可达。本轮只修复容器驱动布局分类和 compact trailing 尺寸，不改变命令、手势或玩法。

## 实现要求

1. `TacticalHUDLayoutRole.init(containerSize:)` 必须先识别 `width > height && height < 520pt` 的短高度横屏，并返回 `.compactTrailing`；不能让 `width >= 700` 抢先判为 regular。
2. `width >= 700 && height >= 520` 继续使用 `.regularTrailing`，保证 1024x768 iPad 和常规大容器保持现有布局。
3. 560-699pt 的横屏继续使用 `.compactTrailing`；其余继续 `.compactBottom`。
4. compact trailing dock 宽度目标改为容器宽度约 30%，clamp 到 224-260pt；874pt 手机横屏应得到 260pt，650pt 横屏应得到 224pt。
5. `.compactTrailing` 继续通过现有 `GameHUDView.commandColumnCount` 使用单列命令网格，避免长标题在双列中截断；不得复制或修改按钮列表。
6. 短高 compact trailing 继续使用 120x80 Tactical Map；regular trailing 继续 176x118，compact bottom 规则不变。
7. 顶栏、safe area、44pt 触控目标、连续滚动 dock、VoiceOver、Dynamic Type、快捷键与所有动作/disabled 条件保持。
8. 不读取 `UIScreen`、设备型号、方向通知或 Preview 名称；仍只使用真实 `GeometryReader` 容器宽高。
9. 更新 Phone Landscape Preview 名称并增加与真实 Simulator 接近的 874x402 preview，作为断点文档证据；Preview 不参与运行时判断。

## 验收矩阵

- 390x844：compact bottom，bottom dock 行为不变。
- 650x390：compact trailing，224pt 单列 dock，120x80 Tactical Map。
- 844x390：compact trailing，约 253pt 单列 dock，120x80 Tactical Map。
- 874x402：compact trailing，260pt 单列 dock，120x80 Tactical Map。
- 700x520：regular trailing，268pt 起 regular dock。
- 1024x768：regular trailing，约 287pt 双列 dock，176x118 Tactical Map。
- accessibility Dynamic Type portrait：compact bottom，原高度规则不变。

有完整 Simulator 时，重新构建、安装并截取 iPhone 17 Pro 横屏：确认战场宽度增加、dock 不超过 260pt、小地图缩小、Selection 区长标题不再双列截断，并确认 top bar / dock / map 无重叠。实际触摸滚动、VoiceOver、旋转状态保持和性能未运行时必须明确记录。

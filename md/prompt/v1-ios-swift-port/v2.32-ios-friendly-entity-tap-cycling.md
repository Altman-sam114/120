# v2.32 iOS friendly entity tap cycling

## 目标

补齐 v2.31 只循环单位的重叠选择缺口，让单位压在 Factory / Command Center 等建筑附近时仍能用同一战场点按路径稳定进入 Production、升级和建筑详情。

## 实现

- Swift Core 新增纯 `RepeatTapCycleResolver`，统一处理候选一致性、上一实体、`0.38...1.4s`、44pt、有限数值与末尾环回。
- iOS 慢速重复点按候选包含全部存活己方单位和建筑，继续沿用 v2.31 的可见排序与按 ID 精确选择。
- Replace 切到建筑后立即派生 Production/Upgrade；Add 只追加并保留既有 primary，同时在状态文本区分 added 与 already selected。
- 快速 `<=0.32s` 双击附近同类保持优先，且仍只作用于同一存活己方单位。
- 命令、区域选择、地图重置、读档、候选变化和超时继续清除 controller 私有瞬态。
- 三项 Core tests 覆盖混合候选前进/环回、上下文拒绝和阈值边界，suite 预期至少 322 tests。

## 非目标

- 不修改敌方直接 Attack、空地 Attack Move、Tactical Map、双指框选、战斗数值、AI、Core state/JSON、存档或建筑生产规则。
- 不新增教程 UI、timer、Task、UIKit recognizer、第三方依赖或 XCUITest。

## 验证

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 只提交本轮源码、测试、提示词和同步文档，直接 push `origin/main`。

# v1.76 / iOS tactical map drag camera

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.76。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

为原生 iOS 战术小地图增加拖拽/按住移动相机能力，让玩家可以像 Web 迷你地图一样通过小地图快速连续调整主战场视口位置。v1.75 已经能显示当前视口矩形，本轮让该视口框可随着小地图拖动实时移动。

验收语义：

- 无等待命令时，在战术小地图上拖动超过阈值后，应连续把主战场相机中心移动到触点对应的世界坐标。
- 拖动过程中 v1.75 的主战场视口矩形和相机中心十字应跟随更新。
- 短点按小地图仍保持旧行为：无等待命令时居中相机，等待命令时下达对应点位、Builder 目标或实体目标命令。
- 小地图长按上下文命令仍保持旧行为；拖动阈值应避免有效长按被提前当成相机拖动。
- 等待 Move / Attack Move / Patrol / Rally / Turret / Factory / Reclaim / Build Extractor / Attack / Guard / Repair / Select Area 等命令时，不启用小地图拖动相机，避免覆盖既有小地图命令入口。
- 不改变 `RustwarCore` 状态、存档结构、相机 zoom/clamp 规则、可见性过滤或 Web 原型。

## 非目标

- 不实现拖动视口矩形边缘缩放、战略缩放、鼠标右键 parity、Shift 队列、雷达信号、已探索记忆、触觉反馈、UI 自动化或截图测试。
- 不新增第三方依赖，不引入 UIKit overlay，不使用 `WKWebView`。
- 不修改 Web `app.js`、`index.html` 或 `styles.css`。

## 实现建议

- `GameController.swift`
  - 新增一个专门给小地图拖动使用的相机居中方法，例如 `dragTacticalMapCamera(to:)`。
  - 该方法只更新 `camera.center` 和 `renderRevision`，不要在每个拖动 tick 写入会刷屏的 `commandStatus`。
  - 保留 `centerCamera(on:)` 给普通点按、Base 和其它离散动作使用。
- `TacticalMapView.swift`
  - 在现有 `DragGesture(minimumDistance: 0)` 上增加拖动状态，例如起点、是否已经触发相机拖动。
  - 只有当 `controller.isAwaitingTargetCommand == false` 且触点移动距离超过阈值时，才进入小地图相机拖动。
  - 阈值应大于当前长按 `maximumDistance: 18`，避免有效长按同时触发拖动相机。
  - 一旦本次手势触发相机拖动，`onEnded` 不再调用 `handleTap`。
  - 保持长按后 suppress tap 逻辑。

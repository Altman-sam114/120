## 用户目标与当前证据缺口

人工首要痛点是 iOS 难以操作，要求点单位、双指框选、点地移动与自动攻击、点建筑直接生产和升级。当前 CI 只跑 Core 状态测试、iOS build、固定 production/combat launch/PNG；从未执行真实 SwiftUI 点击和拖动。即使 v2.88 的纯释放状态测试通过，也不能证明 SpatialEventGesture/DragGesture callback 接线可用。本轮增加 XCUITest 作为正式云端 gate，真实操作失败必须修复生产路径或如实不通过。

## 实现方案

1. Xcode project 新增 `RustwarIOSUITests` UI test target、依赖 App 的 target dependency，以及可共享的 `RustwarIOS` scheme/TestAction。不引入 SwiftPM 远程依赖或第三方自动化工具。
2. 新增 deterministic interaction launch fixture：暂停模拟、关闭 AI、明确己方 tank/Builder/完成工厂、足够资源与稳定相机，方便真实手指点击。仅通过专用 cloud launch argument 启用；正常启动、存档、既有 production/combat fixture 不改。优先复用既有 state 构造路径，禁止通过测试按钮直接调用 controller action 代替战场手势。
3. 为 battlefield 和必要控件增加稳定 accessibilityIdentifier。若 SpriteKit 实体不在 accessibility tree，测试按 battlefield 元素的真实 frame 与 fixture 的世界点映射计算坐标。可在专用测试启动模式下暴露只读的 selection/order/queue/camera 摘要用于断言；该摘要必须从真实 controller/engine 派生，不能把测试预期写入摘要或创建可以修改游戏状态的测试后门。
4. XCUITest 分别覆盖以下真实操作，每项独立启动避免状态串扰：
   - 点己方 tank 后只选中该实体；再点空地，通过真实 DragGesture/SpatialEventGesture 路由产生 Attack-Move；Builder 对应 Move。
   - 已选单位单指拖动只改变相机，不产生移动/攻击命令；随后新点按仍能选择。
   - 点工厂自动看到生产入口；点击可生产卡真实增加一项队列并扣费；不可用卡不入队；升级按钮按实际工厂状态可见（若 fixture 分场景覆盖，明确记录）。
   - 点 Groups/Select/Game/Orders 导航，验证对应控件实际可点击；从 Game/Groups 返回选中工厂后自动回到生产顶部。
   - 点击 Select Area 再实际拖动，确认多个己方单位被选中；正常释放后下一次点地可以发令。
5. XCTest 公共 `pinch` 可覆盖缩放竞争，但 `twoFingerTap` 不能代替现有 0.22s settle 或双指框选拖动，也不能声称证明精确先后抬指。明确保留该证据缺口；禁止只让测试调用 Core tracker 冒充实际多指 UI 事件。

## 云端 workflow

在 `.github/workflows/ci-results.yml` 现有 Simulator 清理之前，对同一 pinned Simulator 执行 xcodebuild test（iPhone 17 Pro、Xcode 26.5/iOS 26.5、code signing off、单设备、禁并行避免资源争用）。设置有限测试超时并关闭自动重试，不吞掉失败。UI test exit、真实 tests passed/failed/count 必须进入 build.log、manifest、JUnit 独立 testcase、failure summary 和 overall；零测试、未发现 target、失败或不预期 skip 不能算通过。manifest 的 aggregate testOutcome 同时考虑 Core 与 UI gate。

用 xcresulttool 在云端提取必要 summary/tests JSON 或 JUnit；artifact 仅上传 manifest、JUnit、日志、失败摘要、测试摘要和最多必要的失败截图。DerivedData、整个 test runner、巨型 xcresult、视频/重复包不得上传。既有 Home/Combat PNG 保留作为静态基线；新增 gate 必须证明实际 interaction tests 执行，而不仅是 build-for-testing。

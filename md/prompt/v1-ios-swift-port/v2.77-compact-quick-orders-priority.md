## 公开参考与问题

Steam 官方 Rusted Warfare 页面强调大规模战斗、无限缩放和跨全战场快速下令；对应到手机横屏，常用 Move / Attack Move / Attack / Stop 应优先于低频选择模式设置。媒体资源受用户既有浏览安全偏好限制，本轮不绕过访问；判断依据为官方公开说明、Rustwar 当前 SwiftUI 层级与最新云端 Combat PNG。

v2.76 固定 combat fixture 使用约 `204...224pt` 的 compact trailing dock。当前固定顺序是 Selection summary / target guidance / `Replace / Add`，然后才是 Quick Orders；picker 本身使用至少 44pt 的 segmented control，使 Quick Orders 与滚动 Commands 整体下移。v2.69 已证明 compact producer 可把同一个 picker binding 放入滚动 Selection section，不需要复制状态或删除能力。

## 目标

1. `layoutRole != .regularTrailing && !dynamicTypeSize.isAccessibilitySize` 时，固定 header 不再渲染 Selection mode picker。
2. 同一 compact normal predicate 下，滚动 `TacticalSelectionSectionView` 显示现有 `TacticalSelectionModePicker`；继续绑定同一个 `$controller.selectionMutation`。
3. Regular trailing 与所有 accessibility Dynamic Type 路径继续在固定 header 显示 picker，滚动 Selection section 不重复显示。
4. Compact producer 继续保持 v2.69 已有行为；本轮把同一迁移规则扩展到 combat、Builder、mixed 与无生产建筑的 compact context。
5. Quick Orders 的固定顺序、Move / A-Move / Attack-or-Cancel / Stop、两列 normal / 单列 accessibility、44pt、快捷键和 VoiceOver 语义保持；只通过移走固定 picker 让 rail 与后续 Commands 上移。

## 实现要求

### 单一 relocation predicate

- `TacticalCommandDockView` 派生一个只由 `layoutRole` 与 `dynamicTypeSize.isAccessibilitySize` 决定的 compact normal predicate。
- 该 predicate 同时驱动 header 与滚动 Selection section，保证 picker 恰好出现一次；禁止在两个 View 中复制不同条件。
- `isCompactProducerContext` 可以复用该 predicate，但 production focus 条件、producer header 和 v2.76 summary gate 不得改变。

### Header 与滚动区

- `TacticalCommandDockHeaderView` 使用显式参数控制是否显示 Selection mode picker，不再把 picker 可见性只隐含绑定到 producer context。
- Selection summary、attack stance、radar/extractor summary、battlefield hint、command status 和 target-mode 外框全部保持原顺序与内容。
- `TacticalSelectionSectionView` 继续使用现有 `showsSelectionModePicker` 参数和 `TacticalSelectionModePicker`；picker label/value/hint、segmented style、control size 与 binding 不变。
- 不在进入/取消 Attack target 时动态交换 Header 与 Quick Orders 的上下顺序，避免 target mode 造成固定区布局跳变。

### 保持项

- `TacticalQuickCommandRail`、`TacticalCommandsSectionView`、`GameController` 不修改。
- Replace/Add 的选择 mutation、单位/建筑选择、双击/重复点按、多指框选、Select Area、Same Type、控制编队和直接点按路由不变。
- Move、Attack Move、Attack、Stop、Patrol、Guard、stance、Repair、Reclaim、Build、Production、Rally、Tactical Map、Core、AI、战斗、存档/JSON 与 Web 版不变。
- 不缩小字体、间距、picker、Quick Orders 或 44pt 触控目标；不新增图标、动画、持久化字段、UIKit、第三方依赖或 HUD breakpoint。
- `.wp` 保持未跟踪，不得编辑、暂存或提交。

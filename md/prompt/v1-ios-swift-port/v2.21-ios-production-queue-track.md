# v2.21 iOS Production Queue Track

## 目标

本轮由 Agent X 主线程直接执行，不调用子 Agent。精修原生 iOS 建筑生产体验：玩家点开己方 Command Center 或 Land Factory 后，立即看清当前生产、完整队列顺序、真实进度和后续项目，同时保留所有既有 Core 命令语义。

## 实现边界

- `GameController` 只读暴露当前选中玩家 producer 的 `[ProductionQueueItem]`，不复制或改写 Core 队列状态。
- `TacticalProductionSectionView` 在单位生产按钮之前显示独立 Build Queue 视图；当前项包含类型图标、名称、百分比、剩余秒数和真实 `progressFraction`，后续项包含队列位置、名称和 buildTime。
- 后续队列允许横向滚动，每项至少 44pt 高；使用 Dynamic Type、monospaced digits、完整 VoiceOver label/value，文本不可截断或遮挡。
- 取消按钮文案改为 `Cancel Last` 以准确表达现有行为，但 action 仍为 `cancelLastProduction`；Repeat、Rally、Shift+1-9/C/P/R、生产费用、人口、退款、队列推进和存档不变。
- production cloud scenario 为 Land Factory 预置 Scout / Tank / AA Tank / Artillery，队首固定 46%；只用于暂停截图，普通启动、combat fixture、Core 初始地图、AI 和经济不变。
- 不新增 Core 模型、网络资源、第三方依赖、WKWebView、timer、Task 或本地 UI 状态。

- Agent C 下载到 `/private/tmp/rustwar-c-review-<run_id>/`，核对 manifest、JUnit、build log、failure summary、metrics 和双 PNG；`ios-home.png` 必须在 Production 首屏显示 4 orders、Scout 46%、进度条与 Tank / AA Tank / Artillery 后续顺序，且与生产按钮无重叠；`ios-combat.png` 不得回退。

# v1.59 / iOS native screen combat selection

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.59。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

为原生 iOS 版补齐 Web 的“选择当前屏幕内作战单位”能力，对齐 Web `F` 快捷键：

- 在 `RustwarCore` 增加按 `WorldRect` 选择己方作战单位的 API。
- iOS 端根据当前 `CameraState` 和主战场 viewport 计算可见世界矩形。
- HUD 增加 `Screen Combat` 选择入口，并绑定外接键盘 `F`。
- 该选择只选择存活己方非 Builder 单位，排除 Builder、敌方、建筑和视口外单位。

## 非目标

- 不修改 Web `app.js` 行为。
- 不新增框选建筑 fallback、队形移动、攻击姿态、命令队列或上下文命令。
- 不改变现有 `Combat Units` 全图选择语义，也不改变 `Control+A`。
- 不改 `RustwarCore` 存档结构、单位订单、AI、战斗、生产或地图预设。

## 实现建议

- `GameStateSelection.swift`：新增可复用选择目标查询，例如 `playerCombatUnitSelectionTargets(in:)`。
- `GameEngine.swift`：新增 `selectPlayerCombatUnits(in:mutation:)`，复用既有 `applySelection`，默认 `.replace`。
- `CameraState.swift`：新增 `visibleWorldRect(for:)`，用当前相机中心、zoom 和 viewport 尺寸计算世界矩形，屏幕边界转换为地图边界内的世界范围。
- `GameController.swift`：记录最近主战场 viewport 尺寸，提供 `selectScreenCombatUnits()`、`canSelectScreenCombatUnits` 和按钮标题；选择前清除等待命令，Replace/Add 选择模式应与其它触屏选择一致。
- `BattlefieldView.swift`：在 GeometryReader 尺寸变化和显示时把主战场 viewport 尺寸同步给 controller。
- `GameHUDView.swift`：在批量选择区域加入 `Screen Combat` 按钮，使用 `scope` 或相近系统图标，绑定裸 `F` 快捷键，保留无可选目标时禁用。
- Swift tests：覆盖视口内/外、Builder 排除、敌方排除、Add 模式合并和空屏幕 Add 保留旧选择。

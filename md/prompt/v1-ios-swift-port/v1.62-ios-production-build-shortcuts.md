# v1.62 / iOS native production and build shortcuts

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.62。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

补齐原生 iOS 已有生产、建造和生产建筑管理按钮的外接键盘入口，让键盘玩家不必触屏点击 HUD：

- 为 `productionOptions` 中显示的生产按钮绑定 `Shift + 1` 到 `Shift + 9`，按当前 HUD 顺序队列生产单位。
- 为 Builder 建造按钮绑定 `Shift + E` / `Shift + T` / `Shift + F`，分别进入 Build Extractor / Build Turret / Build Factory 等待态。
- 为生产建筑管理按钮绑定 `Shift + C` / `Shift + P` / `Shift + R`，分别执行 Cancel Production / Repeat / Rally。
- 所有快捷键必须复用现有 `GameController` action、现有条件渲染、现有 disabled/合法性判断和状态文案。

## 非目标

- 不修改 Web `app.js`，不声明 Web 已有生产热键；Web 当前键盘入口仍以选择、战术命令、姿态、编队和相机为主。
- 不新增 Swift core 状态、命令类型、生产规则、建造规则、队列规则或存档字段。
- 不实现 Shift 队列、右键上下文命令、队形保持、完整建筑菜单、iOS UI 自动化或命令重映射设置。
- 不改变现有外接键盘 `P / R / E / F / Control+A / Option+A / A / G / H / C / S / Z / X / V / Space / 1-9 / Control+1-9 / WASD` 行为。
- 不让 `RootGameView` 吞掉非相机快捷键。

## 实现建议

- `ios/RustwarIOS/RustwarIOS/GameHUDView.swift`
  - 在已有按钮上声明 SwiftUI `.keyboardShortcut`，不要新增并行命令分发器。
  - 生产按钮可按 `productionOptions` 的 `ForEach` 顺序枚举索引，只对前 9 个选项声明 `Shift + 数字`。
  - 建造按钮新增 `Shift + E` / `Shift + T` / `Shift + F`。
  - `Cancel Production` 新增 `Shift + C`，`Repeat` 新增 `Shift + P`，`Rally` 新增 `Shift + R`。
  - 保持按钮 44pt 触摸目标、自适应网格、VoiceOver label/hint 和现有视觉层级。
  - 如有必要，可新增很小的 private helper，例如 `productionKey(for:)`，但不要抽象过度。
- `ios/RustwarIOS/RustwarIOS/RootGameView.swift`
  - 只有在验证发现 `Shift + A/S/W/D` 或其它组合被相机输入吞掉时才改；本轮预期不需要修改。
- `swift/RustwarCore/`
  - 本轮预期不改。生产、建造、取消、重复、集结点语义已有 tests 覆盖。

## 验收标准

- 选中完成状态 Command Center 时，`Shift + 1` 能触发 Builder 生产按钮。
- 选中完成状态 Land Factory 时，`Shift + 1...5` 能按 HUD 顺序触发 Scout / Light Tank / Hover Tank / Artillery / AA Tank 生产按钮。
- 选中 Builder 时，`Shift + E/T/F` 复用 Build Extractor / Turret / Factory 按钮进入对应等待态。
- 选中生产建筑时，`Shift + C/P/R` 复用 Cancel Production / Repeat / Rally 按钮。
- 既有裸键和组合键行为保持：例如裸 `F` 仍是 Screen Combat，裸 `R` 仍是 Restart，裸 `C` 仍是 Reclaim，裸 `P` 仍是 Pause，裸数字仍是召回编队，`Control+数字` 仍是保存编队。

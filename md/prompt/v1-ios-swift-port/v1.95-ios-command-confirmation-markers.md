# v1.95 / iOS battlefield command confirmation markers

## 目标

在 v1.94 原生触觉确认之上，为成功的世界坐标命令增加短生命周期可视目标环。参考 Rusted Warfare 官方截图/视频中高可读的命令落点语言，但全部使用项目自有程序化 SpriteKit 几何，不复制原作素材。

## 实现范围

- 新增 `CommandConfirmation.swift`，定义 presentation-only 命令类型、世界坐标和 revision。
- `GameController` 仅在成功的 Move、Attack、Attack Move、Patrol、Guard、Repair、Reclaim、Build 和 Rally 结果处分发一次确认事件。
- `BattlefieldScene` 在 `effectNode` 绘制类型化目标环，并按战争迷雾、Reduce Motion、节点上限和相机 zoom 处理。
- 更新 Xcode project 和项目文档。

## 必须满足

1. 确认事件只属于 iOS presentation，不进入 RustwarCore、命令 order、SavePayload 或 Web。
2. 事件包含单调 revision、`CommandConfirmationKind` 和 `WorldPoint`；失败结果不能发布 marker。
3. Move 使用绿色四向落点；Attack 使用红色准星；Attack Move 使用橙色准星箭头；Patrol 使用青色循环箭头；Guard 使用蓝色盾形；Repair 使用绿色十字；Reclaim 使用黄色框；Build 使用橙色施工框；Rally 使用浅色旗形。
4. marker 位于实体之上、雾层之下；只有目标点处于玩家当前真实视野时才生成，不能显示隐藏敌人或在稍后开视野时重放旧事件。
5. marker 使用逆 camera zoom 保持稳定屏幕尺寸，不随战略缩放变得过大或过小。
6. 普通模式可执行一次轻微扩张淡出，生命周期不超过 0.8 秒；Reduce Motion 禁止缩放/移动，只保留不超过 0.3 秒静态淡出。
7. 复用 `effectNode` 64 节点硬上限和自动移除，不新增每帧常驻节点、Timer 或网络资源。
8. Stop、生产、升级、保存等没有世界坐标的成功操作只保留 v1.94 触觉，不伪造落点。
9. 不改变命令结果、触觉 revision、Core 数值、AI、存档、HUD 布局、触摸映射或雾语义。

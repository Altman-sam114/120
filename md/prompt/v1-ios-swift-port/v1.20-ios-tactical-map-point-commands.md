# v1.20 / iOS tactical map point commands

## Agent B 任务

把原生 iOS 战术小地图从“只能点按居中相机”推进到“可在等待点位命令时直接下达点位命令”。本轮只复用已经存在的点位型命令，不新增 core 规则，不做小地图实体命中。

## 背景依据

- Web 版迷你地图支持作为移动、攻击移动、巡逻等点位命令入口。
- 原生 iOS v1.7 已有 `TacticalMapView` 坐标换算和相机居中。
- 原生 iOS v1.9 / v1.12 / v1.13 已有 Rally、Attack Move、Patrol 等点位命令状态机，但小地图尚未复用。

## 目标

1. 在 `GameController` 中抽出可复用的世界坐标点位命令派发：
   - Move -> `engine.issueMove(to:)`
   - Attack Move -> `engine.issueAttackMove(to:)`
   - Patrol -> `engine.issuePatrol(to:)`
   - Rally -> `engine.setRally(to:)`
2. `handleBattlefieldTap` 继续保持旧行为，但内部复用同一个点位命令 helper。
3. `TacticalMapView` 点按换算为 `WorldPoint` 后：
   - 若当前处于 Move / Attack Move / Patrol / Rally 等待状态，直接下达对应命令并清除等待态。
   - 若没有可消费的点位命令，保持旧行为：居中相机。
4. 不让小地图处理 Attack / Guard / Repair / Reclaim / Build Extractor 这类需要实体或资源点精确命中的命令。
5. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不修改 `RustwarCore` 规则。
- 不新增 iOS test target。
- 不做多单位命令、队形、右键上下文命令或实体命中。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不引入第三方依赖，不使用 `WKWebView`。

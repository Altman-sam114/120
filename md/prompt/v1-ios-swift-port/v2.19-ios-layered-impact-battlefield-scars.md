# v2.19 iOS Layered Impact And Battlefield Scars

## 目标

本轮由 Agent X 主线程直接执行，不调用子 Agent。精修原生 SpriteKit 战斗命中反馈，使普通受击和云端冻结战斗场景拥有更清楚的贴地冲击、非同心火焰轮廓、烟尘、碎片与短寿命地表战损，同时保持 Core 只读、fog、Reduce Motion 和既有效果上限。

公开图片搜索结果实际显示 Rusted Warfare 高密度战场常用亮色爆点、黑烟和地表痕迹分离单位与火力层级；YouTube gameplay 条目可定位，但播放器画面捕获超时，禁止声称已查看视频帧。只借鉴通用 RTS 可读性原则，不复制图像、模型或素材，全部几何保持 Rustwar 原创。

## 实现要求

- `spawnImpactEffect` 每次调用只创建一个顶层 effect container；在既有 core/fire/ring、sparks、debris、smoke 基础上增加贴地椭圆 bloom 与两层齿数、角度不同的 radial corona。
- 普通 impact 必须通过 `addScorchMark` 留下一个短寿命 decal；焦坑保留 outer/inner，并增加低透明余烬 rim 和确定性放射裂纹。不得使用随机数、纹理、网络资源或第三方依赖。
- effect/decal 继续位于 fog 下层；顶层瞬态最多 64、decal 最多 32，超限淘汰最旧节点，map reset 清空。
- Reduce Motion 只能短透明度淡出，不移动烟、火花、碎片，不旋转或扩张 corona/bloom/ring；普通动态分支可使用短生命周期 `SKAction`，禁止 timer、Task、常驻 action 或 Core/JSON 状态。
- HP diff、可见性、死亡门控、伤害、射程、冷却、AI、命令、输入与存档完全不变。
- combat frozen tableau 复用同一 impact 函数，并在双方阵型中央增加一个不遮挡模型、Tactical Map 或 command dock 的固定落弹点；保留双方 Turret、单位后坐、全部 frozen shots 和三个既有目标 impact。

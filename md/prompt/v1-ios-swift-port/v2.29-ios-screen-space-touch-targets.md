# v2.29 iOS screen-space touch targets

## 角色与目标

本轮按 Agent A -> Agent B -> Agent C 的职责边界推进，由 Agent X 主线串行执行，不调用子 Agent。

v2.11 已实现点己方选择、点可见敌方直接 Attack、点空地直接 Attack Move；v2.12 已实现双指直接框选。当前最大操作摩擦不再是命令入口缺失，而是缩放后实体很难点中：`GameStateSelection` 的 Scout 默认命中半径为 `10 + 7 = 17` world units，在最小 `0.34x` zoom 下只有约 `5.8pt`。

本轮将原生 iOS 主战场实体点选提升为稳定的屏幕空间触控目标：无论相机 zoom，单位和建筑的实体命中直径至少为 44pt，同时保持可见性、最近中心、选择、直接 Attack / Attack Move、长按上下文和 pending target 的现有语义。

## 实现范围

### `swift/RustwarCore/Sources/RustwarCore/GameStateSelection.swift`

1. 为 `selectionTarget(at:includeEnemies:)` 和 `selectionTargetVisibleToPlayer(at:includeEnemies:)` 新增默认为 `0` 的 `minimumHitRadius` 参数。
2. 单位实际命中半径为 `max(definition.radius + 7, minimumHitRadius)`，建筑为 `max(definition.size / 2 + 4, minimumHitRadius)`。
3. 非有限或负数的 minimum 必须退化为 `0`，不得导致 NaN 命中或无限范围。
4. 保持现有最近实体中心打平、`includeEnemies` 和真实视野过滤；雷达 contact 不得因扩大命中而变成可点选敌方。

### `swift/RustwarCore/Sources/RustwarCore/GameEngine.swift`

1. 为 `select` 和 `selectVisibleToPlayer` 增加同样默认参数，仅透传给 `GameState`。
2. 旧调用者不传参时行为必须保持，不修改 Core 默认选择半径、命令、战斗或存档。

### `ios/RustwarIOS/RustwarIOS/GameController.swift`

1. 集中定义 44pt 最小触控直径，把 22pt 半径按 `camera.zoom` 转换为 world radius。
2. 主战场普通 tap 的己方选择、可见敌方直接 Attack 和空地 Attack Move 判定必须共用同一扩大实体命中结果。
3. 主战场长按上下文以及 Attack / Guard / Repair pending 实体目标也使用同一触控半径。
4. Tactical Map 继续使用旧的 world-space marker 命中，不把主战场 44pt 规则误套到整张地图。
5. 保持 pending point command 优先、builder wreck/resource target、双击同类、Replace/Add、选择不清空、指令确认、触觉与 render revision 语义。

### Core tests

1. 证明查询点在旧几何半径外时默认仍不命中，传入较大 `minimumHitRadius` 后命中正确的最近实体。
2. 证明扩大半径仍不能命中真实视野外或仅雷达可见的敌人。
3. 证明 `GameEngine.selectVisibleToPlayer` 使用 minimum 时正确更新 primary 和 selection array，默认 API 保持。
4. Core suite 预期从 311 增长到至少 313 tests。

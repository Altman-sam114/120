## 问题与目标

`TacticalCompactProducerHeaderView` 在 compact producer context 已经把 `Production` 作为固定上下文标题，并朗读建筑、科技与生产速度；`TacticalProductionSectionView` 紧接着仍无条件渲染 `TacticalSectionHeader(section: .production)`。两层标题相邻，既重复 `Production` 文案，也把 management rail、NOW / QUEUE / UPGRADE 和首排生产入口向下推。

本轮目标：

1. 只在 `isCompact && !dynamicTypeSize.isAccessibilitySize && controller.productionFocusBuildingName != nil` 时隐藏 Production section 的可见 `TacticalSectionHeader`。
2. 紧凑 producer header 继续显示 `Production`、当前建筑、tech 和 speed，并保留已有 accessibility label/value/hint；section card、Production focus、management rail 和其余控件继续可访问。
3. regular trailing、compact 下的 accessibility Dynamic Type，以及没有 producer focus 的生产 section 继续显示 `TacticalSectionHeader(.production)`，不让 section 失去独立身份。
4. 不改变 production section 内部顺序、按钮 action、queue/upgrade/rally/repeat 状态、快捷键、VoiceOver value/hint、44pt 触控目标、Core、存档或 Web 版。
5. 只通过去掉重复标题释放垂直空间；不缩小字体、图标、卡片、间距或 dock breakpoint。

## 实现要求

### 唯一 presentation gate

- 在 `TacticalProductionSectionView` 内集中表达 compact producer 的 section-title gate；推荐新增只读派生布尔值，避免把条件散落到 production actions。
- `TacticalSectionHeader(section: .production)` 的可见渲染只由该 gate 控制；不要隐藏整个 `TacticalProductionSectionView`、management rail、focus summary、Factory Tech、production options、queue 或 session section。
- gate 必须与 dock header 的 producer context 对齐：compact + 非 accessibility Dynamic Type + `productionFocusBuildingName != nil` 才省略；普通 compact bottom 和 compact trailing 都适用。
- regular 或 accessibility Dynamic Type 不省略；如果将来 section 在无 producer focus 的情况下出现，也必须保留 Production section title。
- 当 compact producer 省略 section title 时，固定 `TacticalCompactProducerHeaderView` 必须继续保留独立 accessibility element 的 `Production / building / tech / speed` label/value/hint，并补足 `.isHeader` trait，避免 VoiceOver heading/rotor 语义因可见标题省略而回退。
- 不新增 controller/Core 状态，不改 `isCompact` 的调用契约，不重排其他 section。

### 保持项

- `TacticalCompactProducerHeaderView` 的 `Production / building / tech / speed` 文案与独立 accessibility label/value/hint 不变。
- `TacticalProductionManagementRail` 的 Cancel / Repeat / Rally 顺序、disabled/active 状态、菜单、Shift 快捷键、44pt 和 VoiceOver 不变。
- `TacticalProductionFocusSummaryView` 的 compact `NOW / QUEUE / UPGRADE` strip、完整 summary accessibility value、regular/accessibility identity 保持。
- Factory Tech 的 T1/T2/upgrade/cancel/max 逻辑、生产按钮的 icon/name/metal/supply/time、队列顺序与退款保持。
- 不改 GameController、RustwarCore、TouchSequenceOwner、BattlefieldView/BattlefieldScene、AI、命令、战斗数值、模型、存档/JSON、CI workflow 或 Web 版。

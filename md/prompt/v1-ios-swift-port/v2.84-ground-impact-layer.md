# v2.84 原生 iOS 地面受击层级分离

## 轮次定位

- 版本：`v2.84`
- 基线：`origin/main` 的 v2.83 文档验收 commit `26d735362ad4293eea21783be0ddacf96a44ef2a`
- 目标：让陆地/水面 generic HP-hit impact 位于单位实体下方，避免受击 bloom、环、火花和水花盖住 hull、炮塔/发射器、selection、HP 与 v2.78 阵营标记；同时把前景战斗反馈与地面反馈的效果预算统一管理。
- 非目标：不改变 Core 伤害、命中、单位/建筑状态、攻击者关联、武器 profile、炮口/弹道、生产、命令、触控、AI、存档/JSON、fog/visibility、Tactical Map、HUD 或 Web 版。

## 实现要求

1. 在 `BattlefieldScene` 的 `worldNode` 中新增 `groundImpactNode`，顺序必须位于 `decalNode` 之后、`entityNode` 之前；陆地与水面 `spawnImpactEffect` 的 bounded/persistent container 进入该层，现有 scorch mark 仍进入 `decalNode`。
2. 保持前景 `effectNode`：unit/building fire、projectile、terminal flash、muzzle/tracer、command confirmation 与非水面 destruction explosion 不得被移动到地面层。水面 destruction 也必须显式进入 `effectNode`，不能因为复用水面 impact helper 而改变死亡反馈层级。
3. 保持 impact 的几何、颜色、动画、frozen 和 Reduce Motion 语义；只改变 root container 所在层。ground impact root 在实体下面，但内部 zPosition 仍可维持既有相对层级。
4. `effectNode` 与 `groundImpactNode` 共用 `maximumActiveEffects = 64`。新效果按 attach 顺序记录，达到上限时跨两层淘汰最早仍存活的 root；临时 action 自行移除后的记录必须在下一次 attach 前清理，不能误删新效果。persistent frozen effect 也必须受同一上限约束。
5. 地图 reset 和 `accessibilityReduceMotion` 清理必须同时移除两层效果及其创建顺序记录；32 个 `maximumActiveDecals` 的 scorch budget 与淡出语义保持。不要引入新的 Core/GameController 状态或修改固定 combat fixture。
6. 只修改 `ios/RustwarIOS/RustwarIOS/BattlefieldScene.swift` 与必要文档；不修改 `.wp`、CI workflow、Core fixture 或无关 UI/模型代码。

# v1.75 / iOS tactical map viewport frame

## 角色

你是 Agent B，负责在 `main` 上实现本轮 v1.75。开始前必须阅读 `README.md`、`AGENTS.md`、`update_log.md`、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和本提示词，并先执行 `git fetch origin`、`git switch main`、`git pull --ff-only origin main`、`git status --short --branch`。

## 目标

为原生 iOS 战术小地图增加当前主战场视口矩形显示，让小地图除了相机中心十字外，也能显示玩家当前屏幕覆盖的地图范围，更接近 Web 迷你地图的视野反馈。

验收语义：

- 战术小地图应根据 `GameController` 当前相机和主战场 viewport size 绘制可见世界矩形。
- 视口矩形应随拖拽平移、键盘平移、Base、Reset、切图、Save/Load 和缩放变化更新。
- 保留现有相机中心十字、等待命令角标、多选高亮、雾层和敌方可见性过滤。
- 视口矩形是视觉反馈，不改变小地图点按、长按上下文命令、等待态命令或 core 状态。

## 非目标

- 不修改 Web `app.js`。
- 不新增 Swift core 状态、存档字段或测试-only API。
- 不实现 Web 战略缩放、拖拽小地图框移动相机、雷达信号、已探索记忆、视口拖拽调整 zoom、UI 自动化或截图测试。
- 不改变 `CameraState` 的 zoom/pan clamp 规则。
- 不用 `WKWebView`、UIKit overlay 或第三方依赖。

## 实现建议

- `GameController.swift`
  - 暴露一个只读派生属性，例如 `visibleBattlefieldWorldRect`，复用现有 private `battlefieldViewportSize` 和 `camera.visibleWorldRect(for:)`。
  - 不暴露或修改 `battlefieldViewportSize` 的写入路径。
- `TacticalMapView.swift`
  - 在 Canvas snapshot 中读取 controller 的可见世界矩形。
  - 新增 `drawVisibleWorldRect`，把 `WorldRect` 转成小地图坐标，绘制轻量填充和描边。
  - 绘制顺序建议放在单位/建筑之后、相机中心十字之前，避免遮挡关键标记。

# v1.79 / iOS Radar Station build MVP

## 目标

把 v1.78 的 Command Center MVP 雷达信号推进为原生可建造 Radar Station 地基。

本轮必须：

- 在 `RustwarCore` 中新增 `BuildingType.radar` 和 `GameDefinitions.building(.radar)`。
- Radar Station 必须是 Builder 可在清晰陆地点建造的点位建筑，复用现有多 Builder Build 分散接近点语义。
- Radar Station 完成且存活后贡献非零 `radarRange`，未完成或摧毁时不贡献雷达 contact。
- iOS HUD 在选中 Builder 时提供 Radar 建造按钮，并支持主战场 tap 和战术小地图 tap 放置。
- iOS 主战场和战术小地图用现有建筑渲染路径显示 Radar Station。
- 保持 v1.78 雷达 contact 边界：雷达信号不写入 `VisibilitySnapshot.visibleTileIndices`，不写入 explored，不能让 radar-only 敌方被 tap、Attack、Guard 或 Repair 精确命中。

## 非目标

- 不实现 Web 版 Radar Station 升级。
- 不实现 AI 建造 Radar Station。
- 不实现雷达范围 HUD 圈。
- 不实现雾内敌方残影、最后已知位置或雷达目标记忆。
- 不新增 Web 改动，不修改 `app.js` 的玩法。
- 不新增第三方依赖、XCUITest 或 headless browser CI。

## 建议实现

1. Swift core
   - `BuildingType.swift`：新增 `case radar`。
   - `GameDefinitions.swift`：新增 Radar Station 定义，建议 `icon: "RD"`、`metalCost` 约 `430`、`buildTime` 约 `15`、`vision` 约 `260`、`radarRange: 920`，无生产、无武器、无收入、无 supply。
   - 将 Command Center 的 `radarRange` 调整为 `0`，让本轮后真正雷达来源来自 Radar Station。
   - `GameEngine.swift`：新增 `issueBuildRadar(at:)`，复用 `startPointBuildingBuild(.radar, ...)` 和 `canPlaceBuilding(.radar, ...)`。
   - 不改 `RadarContactSnapshot` 字段，不把 radar contact 合进 visible/explored。

2. Core tests
   - Radar Station definition 暴露非零 `radarRange`，Command Center 不再提供 radarRange。
   - `issueBuildRadar(at:)` 可创建未完成 Radar Station、扣一次金属、多 Builder 共同 build 同一目标。
   - 未完成 Radar Station 不提供 radar contacts；完成后可检测视野外、雷达范围内敌方。
   - `issueBuildRadar` 应拒绝无选择、非 Builder、非法地点、金属不足。
   - radar-only 敌方仍不能通过 `selectionTargetVisibleToPlayer` 或 `selectVisibleToPlayer` 命中。

3. iOS
   - `GameController.swift`：新增 `isAwaitingBuildRadarTarget`、`canIssueBuildRadar`、按钮标题、pending label/symbol/system image/accessibility hint、toggle、clear pending、point command dispatch 和状态文案。
   - `GameHUDView.swift`：在 Builder 建造按钮区增加 Radar 按钮，建议 SF Symbol `dot.radiowaves.left.and.right`，键盘快捷键可用 `Shift+D`，避免占用现有 `Shift+E/T/F/C/P/R`。
   - `BattlefieldScene.swift` / `TacticalMapView.swift` 应自然通过 `GameDefinitions.building(.radar)` 的 icon/size 绘制；只在必要时做微调。

## 验收标准

- 选中 Builder 后 iOS HUD 出现 Radar 建造按钮；再次点击可取消等待态。
- 主战场或战术小地图 Radar 等待态点按清晰陆地点后，创建一个未完成 Radar Station，所有选中 Builder 共同建造同一目标。
- Radar Station 完成前不产生 radar contacts；完成后产生 v1.78 同类青色雷达信号。
- Command Center 不再是 radar source。
- radar-only 敌方仍不可选、不可作为 Attack/Guard/Repair 精确目标。
- Web 原型直接打开行为不变。

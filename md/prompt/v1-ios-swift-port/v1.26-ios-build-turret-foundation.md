# v1.26 / iOS native Build Turret foundation

## Agent B 任务

在 v1.17 原生 Build Extractor 和 v1.19/v1.24 Turret 自动防御基础上，给原生 iOS Builder 增加最小 `Build Turret` 点位建造入口：选中己方 Builder 后进入 Turret 放置等待态，tap 主战场或战术小地图点位扣除金属、创建未完成 Turret，并复用现有 `.build(targetID:)` 订单推进建造，完成后 Turret 进入现有自动防御开火流程。

## 背景依据

- Web 原型支持工程单位建造防御建筑；当前 iOS Builder 只能建 Extractor。
- `BuildingDefinition`、`BuildingSnapshot.buildProgress`、`UnitOrder.build(targetID:)` 和 `GameEngine.updateBuildOrder` 已能推进未完成建筑。
- Turret 已有定义、渲染、HP/建造进度显示和自动攻击单位/建筑的行为。
- iOS Controller 已有 Build Extractor 等待态、Stop 清理等待态和战术小地图 pending command 反馈，可按现有模式扩展。

## 目标

1. Swift core：
   - 为 Turret 设置合理 `buildTime`，避免新建 Turret 近乎瞬间完成。
   - 新增 `GameEngine.issueBuildTurret(at:) -> UnitCommandResult`。
   - 只允许当前选中的己方 Builder 下令。
   - 扣除 `GameDefinitions.building(.turret).metalCost`，创建 `buildProgress = 0`、初始 HP 为最大 HP 10% 的己方 Turret，并给 Builder 写入 `.build(targetID:)`。
   - 建造点需要 clamp 到地图内，并做最小合法性校验：不得在水/深水/岩浆上，不得贴近现有存活建筑或资源点。
   - 建造完成后沿用现有 `updateBuildOrder`，Turret 自动开火沿用 v1.19/v1.24 行为。
2. iOS App：
   - 选中己方 Builder 时显示 `Turret` 按钮，使用文字 label、系统图标和 44pt 最小触控高度。
   - `Turret` 等待态与 Move / Attack Move / Patrol / Guard / Repair / Reclaim / Build Extractor / Attack / Rally 互斥。
   - 主战场 tap 和战术小地图 tap 均可作为 Turret 建造点位；成功或失败后清除等待态并显示状态文案。
   - Stop、Load、Restart 和切图应清除 Turret 等待态。
   - 战术小地图 pending command 标签、符号、图标和 VoiceOver hint 需要覆盖 Turret 等待态。
3. Tests：
   - 拒绝无选择、敌方 Builder、非 Builder、资源不足和非法点位。
   - 成功下令会扣金属、创建未完成 Turret、保留选择并给 Builder 写入 build 订单。
   - Builder 远距时会靠近 Turret 并保持订单。
   - Builder 在范围内会推进建造，完成后 Turret 满血并可按现有炮塔逻辑开火。
   - Stop 可清除 Turret build 订单。
4. 文档：
   - 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不新增完整建筑菜单、建造幽灵、拖拽放置、旋转、Shift 队列、多 Builder 协同或取消未完成建筑退款。
- 不实现 Land Factory / Command Center / Radar / Anti-Air 等其它建筑建造。
- 不让红方 AI 主动造 Turret。
- 不做完整 Web 版碰撞、地形、雾、资源和队列放置 parity。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不新增第三方依赖，不使用 `WKWebView`。

# v1.84 iOS Radar Upgrade Cancel

## Agent A Prompt

Role: Agent B implements this prompt on `main`, then Agent C validates the latest `origin/main` GitHub Actions artifact.

## Goal

Add the first native Swift/iOS upgrade-cancel slice: a player-owned Radar Station with an active T2 upgrade can cancel that upgrade, clear its upgrade progress, and refund metal based on remaining progress. This closes a small Web parity gap because the Web prototype supports cancelling production/upgrade queues with partial refunds.

## Non-goals

- Do not change Web Canvas behavior in `app.js`.
- Do not add a generic multi-upgrade queue or full building upgrade tree.
- Do not add enemy AI upgrade cancellation.
- Do not change Radar Station T2 balance values.
- Do not change production cancellation behavior.
- Do not use `WKWebView` or web wrapping.

## Required implementation

- Add a Core command result for upgrade cancellation, distinct from `ProductionCancelResult`, with:
  - cancelled(refundedMetal: Double)
  - noSelection
  - selectedBuildingCannotCancelUpgrade
  - noUpgradeQueued
- Add `GameEngine.cancelBuildingUpgrade()` for the current player selection.
- The command must require exactly one selected, living, completed, player-owned building.
- The command must only cancel when that building has an active `upgradeProgress` and a matching next upgrade definition.
- Refund `upgrade.metalCost * (1 - progress)` using the current stored progress clamped to `0...1`.
- Clear `upgradeProgress` without changing `upgradeLevel`, hit points, max hit points, rally, production queue, repeat setting, selected entity, selected entity IDs, or control groups.
- Keep enemy AI upgrades untouched: do not let the player cancel enemy upgrades, and do not add an AI cancellation path.
- Add iOS HUD support:
  - Show a `Cancel Upgrade` button only when the selected completed player Radar Station has active upgrade progress.
  - Call `GameEngine.cancelBuildingUpgrade()`.
  - Show a concise status string including the refunded metal.
  - Provide VoiceOver label/hint.
  - Do not add a keyboard shortcut that conflicts with existing Shift+C production cancellation.
- Existing upgrade progress bar rendering should naturally disappear when progress is cleared.

## Required tests

Add Swift core tests for:

- Missing selection, multiple selection, non-player building, incomplete building, completed but not upgrading building, and fully upgraded building with no active progress reject correctly.
- Active Radar Station upgrade cancellation refunds remaining metal based on stored progress and clears `upgradeProgress`.
- Cancelling preserves current selection and does not change `upgradeLevel`, hit points, max hit points, rally, production queue, repeat setting, or control groups.
- After cancellation, future `update(deltaTime:)` calls do not complete the cancelled upgrade.
- Player cancellation does not cancel enemy Radar Station upgrades.

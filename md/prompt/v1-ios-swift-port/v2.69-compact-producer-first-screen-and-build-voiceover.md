## 背景

最新云端 `ios-home.png` 显示，选中 Land Factory 时固定 command dock header 仍同时占用 Selection summary、`Replace/Add` 和状态空间；Production focus、Factory Tech 和生产卡又重复呈现信息，首屏只能稳定看到前两张生产卡。Rusted Warfare 的生产操作更接近高密度图标网格，单位图标和短名称优先，完整细节在辅助信息中提供。

当前 `TacticalBuildSectionView` 的四个建造按钮在进入 pending target 后视觉标题变为 `Cancel`，但 VoiceOver label 仍固定朗读 Build extractor/turret/factory/radar，无法表达当前正在等待放置或可取消。

## 目标

1. compact、普通 Dynamic Type、单一已完成己方生产建筑选择时，固定 header 改为紧凑 producer context，只显示建筑名、科技等级和生产倍率；生产 controls 仍由滚动 dock 展示。
2. compact 生产入口使用图标优先的三列高密度网格，每张卡仍至少保持 `44pt` 最小触控高度；保留生产 options 顺序、锁定/资源/人口状态、完整 VoiceOver 名称、金属、人口、建造时间、disabled 条件和 Shift+1–9 快捷键。
3. compact MAX Factory Tech 不重复渲染完整 tech 卡；T2 READY 必须保留升级 CTA，UPGRADING 必须保留进度与取消；regular 和 accessibility Dynamic Type 保留完整可读布局。
4. compact producer context 隐藏固定 header 内的 `Replace/Add` 后，将同一个绑定的 Selection mode picker 放到可滚动 Selection section，保证 Replace/Add 仍可达且语义不变。
5. Builder 的 Extractor、Turret、Land Factory、Radar 按钮在 pending target 时分别提供 `Cancel … placement` label、`Waiting for … placement` value 和取消 hint；非 pending 时提供 `Build …`、`Ready` 和位置选择 hint。按钮 action 与快捷键不变。

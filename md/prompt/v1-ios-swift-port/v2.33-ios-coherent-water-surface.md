# v2.33 iOS coherent water surface

## 目标

改善原生 SpriteKit 战场明显的逐格水面拼贴感，让 Coast 等地图的连续水域更接近 Rusted Warfare 公开战场画面的整体水面，同时保持单位、弹道、爆点和命令标记为最高视觉优先级。

## 实现

- `water` 与 `deep` 各自使用连续统一基底，不再应用逐 tile 三档明暗偏移；两种深度仍保留独立基础色和既有深度边界。
- 按每一行的连续水域 run 生成确定性的跨格长波纹与柔和高光带，路径留在水域内部，不覆盖陆地。
- 水面高光和波峰分别聚合为单一 compound path；不按 tile 或 run 创建 SpriteKit node，地形节点规模继续固定。
- 保留海岸暗边/泡沫、water/deep 深度线、地形层级、雾层覆盖和地图 revision 重建规则。

## 非目标

- 不修改 `RustwarCore` 地形数据、通行、地图 preset、战斗、AI、经济、命令、存档、Web 或 Tactical Map。
- 不新增动画、timer、Task、随机数、纹理资源、第三方依赖或逐实体状态。
- 不把 Rusted Warfare 的素材、商标或受版权保护资源直接复制进仓库。

## 参考与验收方向

- 参考 Rusted Warfare 官方 Steam 战场截图与公开移动版视频中的连续水域层级，只复刻低频整体感和战斗可读性，不复制原始素材。
- 云端 `ios-combat.png` 应显著减少相邻水格的棋盘式明暗差；浅水、深水、海岸和陆地仍可区分，单位、炮塔、弹道、命中和爆点不得被水纹抢占。

- 禁止所有本地测试、构建、格式检查、Simulator、Preview 和截图。
- 只提交本轮 SpriteKit 源码、提示词和同步文档，直接 push `origin/main`。
- Agent C 下载最新精确 SHA 的未加密 artifact，核对 manifest、JUnit 8/0/1、至少 322 Core tests、arm64/x86_64 build、双 launch/orientation/probe 与双 PNG。
- 人工复看云端 `ios-home.png` 与 `ios-combat.png`；静态截图不能宣称证明所有地图、缩放极限或真机帧率。

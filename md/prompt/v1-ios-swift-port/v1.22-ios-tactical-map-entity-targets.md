# v1.22 / iOS tactical map entity targets

## Agent B 任务

在 v1.20 / v1.21 战术小地图命令入口基础上，补齐剩余最小实体目标命令：当 iOS 正在等待 Attack / Guard / Repair 目标时，允许点按战术小地图，通过现有 `GameState.selectionTarget(at:includeEnemies:)` 命中单位或建筑并调用既有 `RustwarCore` 命令。

## 背景依据

- v1.20 已支持小地图 Move / Attack Move / Patrol / Rally 点位命令。
- v1.21 已支持小地图 Reclaim / Build Extractor Builder 目标命令。
- 主战场 tap 已经用 `selectionTarget(at:)` + `issueAttack` / `issueGuard` / `issueRepair` 处理这些命令；本轮只让小地图复用同一套校验。

## 目标

1. 在 `GameController` 中抽出并复用实体目标命令派发：
   - Attack 等待态：`selectionTarget(at:)` 命中后调用 `engine.issueAttack(targetID:)`。
   - Guard 等待态：`selectionTarget(at:)` 命中后调用 `engine.issueGuard(targetID:)`。
   - Repair 等待态：`selectionTarget(at:)` 命中后调用 `engine.issueRepair(targetID:)`。
2. 主战场 tap 和战术小地图 tap 共用同一套实体命令 helper，减少重复分支。
3. 小地图命令优先级保持：
   - Move / Attack Move / Patrol / Rally 点位命令优先。
   - Reclaim / Build Extractor Builder 目标命令次之。
   - Attack / Guard / Repair 实体目标命令随后。
   - 没有 pending 命令时仍居中相机。
4. 不修改 `RustwarCore` 命中半径、目标合法性、伤害、维修或护航规则。
5. 更新 README、`md/flow/flow.md`、`md/flow/flowchart.md`、`md/test/test.md` 和 `update_log.md`。

## 非目标

- 不新增小地图放大镜、目标吸附 UI、目标确认弹窗或高亮预览。
- 不新增多单位命令、队形命令或右键上下文命令。
- 不新增 iOS test target。
- 不改变 Web `index.html` / `app.js` 直接浏览器运行链路。
- 不引入第三方依赖，不使用 `WKWebView`。
